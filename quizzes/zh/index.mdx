## 概要
本目录用于记录所有课程的 quiz 完成情况,包括:
- Quiz 成绩记录
- 错题分析与知识点总结
- 复习计划追踪
- 知识薄弱点识别

## 目录结构
```
quizzes/
├── index.mdx                          # 本文件,总览
├── semester-1/                        # 第一学期
│   ├── index.mdx
│   ├── COMPSCI4084/
│   │   ├── index.mdx
│   │   ├── week1/                     # 按周次组织
│   │   │   └── <quiz-topic>.mdx
│   │   └── week2/
│   ├── COMPSCI5089/
│   │   ├── index.mdx
│   │   └── week1/
│   │       └── git-github-colab.mdx   # quiz 文件名不含周次
│   ├── COMPSCI5100/
│   └── research-professional-skills/
└── semester-2/                        # 第二学期
    └── index.mdx
```

**组织原则**:
- Quiz 按周次分目录存放 (`week1/`, `week2/`, ...)
- 文件名使用主题名称,不包含周次信息
- 周次信息在目录名和索引文件中体现

## 使用指南

### 记录新 quiz
1. 在对应课程目录创建新文件: `week-X-quiz-Y.mdx`
2. 使用 `/docs/templates/quiz-template.mdx` 作为模板
3. 重点记录错题和需要加强的知识点
4. 更新本页的统计表格

### 复习流程
1. 查看错题分析,识别知识薄弱点
2. 查阅相关课程笔记和材料
3. 完成相关练习题
4. 标记复习完成状态

### 统计更新
- 每完成一个 quiz 后更新对应课程的统计
- 定期(每周)更新整体学习分析
- 在复习后更新"待复习"数量
