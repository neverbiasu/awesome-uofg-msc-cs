### 3
**题目**: What does the git add command do?

**选项**:
- [x] a. It adds a new file to the repository.
- [ ] b. It deletes a file from the repository.
- [ ] c. It stages changes to be committed.
- [ ] d. It commits changes to the repository.

**你的答案**: a. It adds a new file to the repository.

**判定**: ❌

**Mark**: 0.00 / 1.00

**正确答案**: c. It stages changes to be committed.

**解析**: `git add` 用于把工作区的更改（新增/修改/删除）放入暂存区（staging area），准备下一次 `git commit`。它并不等同于提交。

### 10
**题目**: How can you access files stored in Google Drive from a Google Colab notebook?

**选项**:
- [ ] a. By copying files directly to Colab.
- [ ] b. By clicking "File > Open"
- [ ] c. By exporting the notebook to Google Drive.
- [ ] d. By connecting to Google Drive using `from google.colab import drive` and mounting the drive

**你的答案**: (未记录)

**判定**: ❌

**Mark**: 0.00 / 1.00

**正确答案**: d. By connecting to Google Drive using `from google.colab import drive` and mounting the drive

**解析**: 使用下面代码挂载 Drive：

```python
from google.colab import drive
drive.mount('/content/drive')
```

挂载后可通过 `/content/drive/MyDrive/` 访问个人 Google Drive 文件。
