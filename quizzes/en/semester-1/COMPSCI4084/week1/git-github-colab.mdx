- [ ] d. It commits changes to the repository.

**Verdict**: ❌

**Mark**: 0.00 / 1.00

**Correct Answer**: c. It stages changes to be committed.

**Explanation**: `git add` is used to put changes in the working directory (additions/modifications/deletions) into the staging area, preparing for the next `git commit`. It is not equivalent to committing.
