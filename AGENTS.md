# Agent Instructions

This document contains specific instructions and conventions for the Gemini agent to follow while working on this project.

- **Weekly Notes Structure**: For weekly course notes, the structure must be `notes/{lang}/{semester}/{course}/week<N>/`. This directory should contain:
    - An `index.mdx` file, generated from `templates/week-index-template.mdx`.
    -    One or more lecture note files, such as a descriptive name like `topic-name.mdx`, generated from `templates/note-template.mdx`.
- **Directory Naming**: The weekly directory name must not contain a hyphen (e.g., use `week2`, not `week-2`).
