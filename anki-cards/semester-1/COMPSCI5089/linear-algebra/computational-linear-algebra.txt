What is an adjacency matrix A used for?	To represent a finite graph G = (V, E)
In an unweighted adjacency matrix, what does A_ij = 1 mean?	There is an edge from vertex i to j
How is the out-degree of a vertex found from an adjacency matrix?	Sum of each row
How is the in-degree of a vertex found from an adjacency matrix?	Sum of each column
What property does the adjacency matrix of an undirected graph have?	It is symmetric (A = A^T)
How can the state of a system at time t+1 be calculated using a state vector x_t and adjacency matrix A?	x_{t+1} = A^T * x_t
What is an eigenvector of a linear transformation?	A non-zero vector that only changes by a scalar factor (eigenvalue)
What is the formula for an eigenvector v and eigenvalue lambda of a matrix A?	Av = lambda * v
What does the leading eigenvector of a transformation matrix represent in a flow network?	The steady state of the system
What is the Power Iteration method used for?	To find the leading eigenvector of a matrix
What is Eigendecomposition?	Factorization of a matrix into its eigenvalues and eigenvectors
What is the formula for Eigendecomposition of a square matrix A?	A = Q * Lambda * Q^-1
What are the principal components in PCA?	The eigenvectors of the data's covariance matrix
When does a matrix have an inverse?	Only if it is non-singular (determinant is non-zero)
What is Singular Value Decomposition (SVD)?	A generalization of eigendecomposition for any m x n matrix
What is the formula for SVD of a matrix A?	A = U * Sigma * V^T
What three operations does SVD break a matrix transformation into?	Rotate, scale, and rotate back
What does the pseudo-inverse A+ provide?	An approximate solution to linear systems for any matrix
What is data whitening?	A preprocessing step to make features uncorrelated with unit variance
