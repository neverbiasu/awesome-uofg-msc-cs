Git是什么？	一种分布式版本控制系统（VCS）
VCS代表什么？	版本控制系统
Git是谁发明的？	Linus Torvalds
`git config --global user.name`的作用是？	设置全局Git提交用户名
`git init`的作用是？	在当前目录初始化一个新的Git仓库
`.git`目录包含什么？	仓库的所有元数据和历史记录
`git status`的作用是？	显示工作目录和暂存区的状态
`git add [file]`的作用是？	将文件更改暂存以备下次提交
`git commit -m "message"`的作用是？	将暂存的更改记录到仓库
`git log`的作用是？	显示提交历史
`git diff`的作用是？	显示工作目录和暂存区之间的更改
如何撤销未暂存的更改？	`git checkout -- [file]`
如何取消暂存的文件？	`git reset [file]`
`git revert [commit_ID]`的作用是？	创建一个新提交来撤销指定提交的更改
为什么推荐使用`git revert`？	它保留项目历史，是更安全的回滚方式

什么是远程仓库？	托管在网络上用于团队共享和同步的项目版本
`git push`的作用是？	将本地提交的更改发布到远程仓库
`git pull`的作用是？	从远程仓库获取更改并合并到本地分支
设置SSH密钥的目的是？	为远程仓库提供比用户名/密码更安全的认证
如何生成SSH密钥对？	`ssh-keygen -t rsa`
公钥通常存放在哪个文件？	`~/.ssh/id_rsa.pub`
`git clone [URL]`的作用是？	将整个远程仓库复制到本地机器
`origin`在Git中通常指什么？	克隆的远程仓库的默认名称
`git pull`和`git push`前应该做什么？	先`git pull`以避免冲突
合并冲突何时发生？	当Git无法自动合并来自两个分支的更改时
Git如何标记合并冲突？	使用`<<<<<<<`, `=======`, `>>>>>>>`标记
解决合并冲突后需要做什么？	手动编辑文件，然后`git add`和`git commit`
`git tag -a v1.0`的作用是？	创建一个带注释的标签，通常用于版本发布
`git blame [file]`的作用是？	逐行显示文件的最后修改信息（作者、提交）

LaTeX是什么？	一种高质量的排版系统，用于专业文档准备
Overleaf是什么？	一个基于云的在线LaTeX编辑器和编译器
LaTeX文档的最小结构是什么？	`\documentclass{}`, `\begin{document}`, `\end{document}`
如何在LaTeX中创建新章节？	使用 `\section{章节名}`
如何在LaTeX中交叉引用章节？	使用 `\label{}` 和 `\ref{}`
如何在LaTeX中排版数学公式？	使用 `\begin{equation}` 环境或 `$...$`
如何将LaTeX编译为PDF？	使用 `pdflatex` 命令
Makefile在LaTeX中的作用是？	自动化编译过程，处理多次编译和清理
`\documentclass{article}`的作用是？	定义文档类型为文章
如何在LaTeX中写粗体字？	`\textbf{文本}`
如何在LaTeX中写斜体字？	`\textit{文本}`
De Morgan定律的一个例子是什么？	`\lnot (A \land B) \equiv \lnot A \lor \lnot B`

`pwd`命令的作用是？	打印当前工作目录
`cd`命令的作用是？	更改当前目录
`ls -l`的作用是？	以长列表格式显示目录内容
`ssh`命令的作用是？	安全地连接到远程Linux机器
Linux命令行是否区分大小写？	是
`~`在Linux中代表什么？	当前用户的主目录
`*`在Linux中是什么？	一个通配符，匹配任意字符序列
如何将`echo`的输出重定向到文件并覆盖？	`echo "text" > file.txt`
`mkdir`命令的作用是？	创建一个新目录
`mv`命令的作用是？	移动或重命名文件/目录
`rm`命令的作用是？	删除文件
`cat`命令的作用是？	显示文件内容
`head -n 5`的作用是？	显示文件的前5行
`tail -f`的作用是？	实时跟踪文件的新增内容
`ps`命令的作用是？	显示当前运行的进程
`kill [PID]`的作用是？	终止指定PID的进程
`man [command]`的作用是？	显示命令的手册页
Shell脚本的第一行通常是什么？	Shebang，例如 `#!/bin/bash`
如何使Shell脚本可执行？	`chmod +x script_name`
如何在Shell脚本中读取用户输入？	`read -p "Prompt: " variable`
如何在Shell脚本中访问第一个命令行参数？	使用 `$1`

`strcpy`函数的主要风险是什么？	不检查缓冲区大小，可能导致缓冲区溢出
`fgets`相比`gets`的优点是？	可以限制读入的字符数，防止溢出
`strncpy`和`strcpy`的主要区别是？	`strncpy`需要指定最大复制字符数
使用`strncpy`后需要注意什么？	可能需要手动添加空终止符`\0`
`-Wall`编译器标志的作用是？	启用一组常见的、重要的警告
`-Wextra`编译器标志的作用是？	启用一些`-Wall`未包含的额外警告
`-Werror`编译器标志的作用是？	将所有编译器警告视为错误，强制修复
为什么应始终启用编译器警告？	它们能帮助在早期发现潜在的bug和安全漏洞
C语言中`if (x = 0)`是什么问题？	这是赋值而非比较，通常是逻辑错误

`grep`命令的作用是？	在文件中搜索匹配指定模式的行
`grep -i`的作用是？	进行不区分大小写的搜索
`sort`命令的作用是？	对文件的行进行排序
`uniq`命令的作用是？	报告或省略重复的行
`uniq -c`的作用是？	在每行开头增加重复次数
使用`uniq`前通常需要做什么？	对文件进行排序 (`sort`)
`wc -l`的作用是？	计算文件的行数
`tr 'a-z' 'A-Z'`的作用是？	将文本从小写转换为大写
`sed 's/old/new/g'`的作用是？	全局替换每行中所有'old'为'new'
管道`|`在命令行中的作用是？	将一个命令的输出作为另一个命令的输入
`curl [URL]`的作用是？	获取并显示URL指向的内容

`whoami`命令的作用是？	显示当前有效用户名
`sudo`命令的作用是？	以超级用户（root）权限执行命令
`chmod 700 file`的含义是？	设置文件只有所有者有读、写、执行权限
`chown user:group file`的作用是？	更改文件的所有者和所属组
`ps aux`的作用是？	显示系统上所有正在运行的进程
`top`命令的作用是？	动态实时地查看系统进程和资源使用情况
`kill -9 [PID]`的含义是？	强制终止指定PID的进程
`jobs`命令的作用是？	列出当前shell会话中的后台作业
如何将后台作业切换到前台？	`fg %[job_id]`
`df -h`的作用是？	以人类可读格式显示磁盘空间使用情况
`tar -czvf archive.tar.gz dir/`的作用是？	创建`dir/`目录的压缩归档文件
`strings`命令对二进制文件的作用是？	提取并显示文件中的可打印字符序列
`hexdump -C`的作用是？	以十六进制和ASCII码形式显示文件内容
