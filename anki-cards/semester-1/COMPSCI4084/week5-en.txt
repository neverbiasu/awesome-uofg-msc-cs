What is Git?	A distributed version control system (VCS)
What does VCS stand for?	Version Control System
Who invented Git?	Linus Torvalds
What does `git config --global user.name` do?	Sets the global Git commit user name
What does `git init` do?	Initializes a new Git repository in the current directory
What does the `.git` directory contain?	All repository metadata and history
What does `git status` do?	Shows the state of the working directory and staging area
What does `git add [file]` do?	Stages file changes for the next commit
What does `git commit -m "message"` do?	Records staged changes to the repository
What does `git log` do?	Displays the commit history
What does `git diff` do?	Shows changes between the working directory and staging area
How do you undo unstaged changes?	`git checkout -- [file]`
How do you unstage a file?	`git reset [file]`
What does `git revert [commit_ID]` do?	Creates a new commit that undoes the changes of a specified commit
Why is `git revert` recommended?	It preserves project history, making it a safer way to undo

What is a remote repository?	A version of your project hosted online for team sharing and synchronization
What does `git push` do?	Publishes local committed changes to the remote repository
What does `git pull` do?	Fetches changes from the remote repository and merges them into the local branch
What is the purpose of setting up SSH keys?	To provide more secure authentication to remote repositories than username/password
How do you generate an SSH key pair?	`ssh-keygen -t rsa`
Where is the public key typically stored?	In the `~/.ssh/id_rsa.pub` file
What does `git clone [URL]` do?	Copies an entire remote repository to your local machine
What does 'origin' usually refer to in Git?	The default name for the remote repository you cloned from
What should you do before `git push`?	Always `git pull` first to avoid conflicts
When do merge conflicts occur?	When Git cannot automatically merge changes from two branches
How does Git mark merge conflicts?	Using `<<<<<<<`, `=======`, `>>>>>>>` markers
What should you do after resolving a merge conflict?	Manually edit the file, then `git add` and `git commit`
What does `git tag -a v1.0` do?	Creates an annotated tag, typically for a release version
What does `git blame [file]` do?	Shows the last modification information (author, commit) for each line of a file

How do you cross-reference sections in LaTeX?	Using `\label{}` and `\ref{}`
How do you typeset mathematical equations in LaTeX?	Using the `equation` environment or `$...$`
How do you compile LaTeX to PDF?	Using the `pdflatex` command
What is the role of a Makefile in LaTeX?	To automate the compilation process, handling multiple runs and cleanup
What does `\documentclass{article}` do?	Defines the document type as an article
How do you write bold text in LaTeX?	`\textbf{text}`
How do you write italic text in LaTeX?	`\textit{text}`
What is an example of a De Morgan's law?	`\lnot (A \land B) \equiv \lnot A \lor \lnot B`
