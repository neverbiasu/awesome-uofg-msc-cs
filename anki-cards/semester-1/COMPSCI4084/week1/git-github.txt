如何设置 Git 全局用户名和邮箱？	git config --global user.name "姓名"; git config --global user.email "邮箱"
如何初始化本地 Git 仓库？	git init
如何克隆远程仓库？	git clone <repo-url>
如何查看当前仓库状态？	git status
如何将文件添加到暂存区并提交？	git add <file>; git commit -m "消息"
如何查看提交历史？	git log
如何添加远程并首次推送设置上游？	git remote add origin <url>; git push -u origin main
如何拉取远程更新？	git pull origin <branch>
如何创建并切换到新分支？	git switch -c <branch> 或 git checkout -b <branch>
如何合并分支？	git merge <branch>
如何删除已合并的本地分支？	git branch -d <branch>
.gitignore 的作用是什么？	忽略不需跟踪的文件
如何停止跟踪已被跟踪的文件？	git rm --cached <file>
冲突标记的常见格式是什么？	<<<<<<< HEAD / ======= / >>>>>>> <branch>
如何标记冲突已解决？	git add <resolved-file>
为什么推荐使用 SSH 而非 HTTPS？	避免频繁输入密码，便于自动化
如何生成 SSH 密钥？	ssh-keygen -t ed25519
什么是 fast-forward 合并？	无需合并提交，直接移动分支指针
提交信息摘要行应满足什么要求？	≤50 字并使用祈使语
常见的分支命名约定有哪些？	feature/<name>, fix/<name>
