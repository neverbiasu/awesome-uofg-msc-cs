### Model Agnostic Approaches

-   Permutation Feature Importance
-   **Local Interpretable Model-agnostic Explanations (LIME)**
-   Shapley Additive Explanations (SHAP)

### LIME Overview

-   Provides locally faithful explanations.
-   Based on a surrogate (locally linear) model.
-   It works by approximating the underlying model locally with an interpretable one.

*(Image: A diagram illustrating how LIME approximates a complex model's decision boundary with a simpler, linear model in the vicinity of a specific prediction.)*

### LIME Formulation

The explanation is generated by the following formula:

`ξ(x) = argmin(g∈G) L(f, g, Πx) + Ω(g)`

-   **Explanation:** `ξ(x)`
-   **Model to explain:** `f: R^d → R`
-   **Proximity Measure:** `Πx`

*(Reference: Ribeiro et al. 'Model-Agnostic Interpretability of Machine Learning', 2016)*

### LIME Explanations Characteristics

-   Allow accurate explanations while retaining model flexibility.
-   The explanation should be accessible even to non-experts.
-   Small switching costs with relation to changes to the model.

*(Image: Comparison of LIME explanations for a logistic regression and an LSTM model, showing feature importance for a specific prediction.)*

### Packaging Data for LIME

LIME provides different explainers based on the data type:

-   `Lime Tabular Explainer`
-   `Lime Text Explainer`
-   `Lime Image Explainer`
-   `Recurrent Tabular Explainer`

*(Image: A diagram showing an ECG beat with 11 segments, illustrating how time-series data can be packaged for LIME.)*

### LIME for CNN / LSTM / MLP Explanations

-   LIME can be used to generate weights for different segments of input data (like an ECG signal) to explain the classification made by a complex model like a CNN, LSTM, or MLP.
-   The weights indicate how much each segment contributed to the final prediction.

*(Images: Bar charts and graphs showing LIME weights for different segments of an ECG signal for classifications made by CNN, LSTM, and MLP models.)*

### LIME Summary

-   Provides a qualitative understanding between input variables and the response.
-   Explanations are easily understood by non-experts.
-   Explanations are locally faithful to the model's behavior.
-   It is a model-agnostic approach, so model switching costs are small.

-   Ribeiro et al. '"Why Should I Trust You?": Explaining the Predictions of Any Classifier', Proceedings of the 22nd ACM SIGKDD International Conference on Knowledge Discovery and Data Mining, 2016.

## Shapley Additive Explanations (SHAP)

### SHAP Overview

-   Identifies a new way of estimating importance scores.
-   Each explanation is treated as a model itself (a surrogate model).
-   There is a unique solution in this class with a set of desirable properties.
-   Exploiting game theory guarantees a unique solution.

### Feature Attribution Methods

-   SHAP is a member of the **additive feature attribution** methods class:
    `g(z') = φ_0 + Σ(i=1 to M) φ_i * z'_i`

### KernelSHAP

-   Connects Linear LIME and Shapley values.
-   The formulation is similar to LIME but with specific definitions for the loss function `L`, proximity measure `Πx`, and complexity term `Ω(g)`.
    -   `Ω(g) = 0`
    -   The proximity measure `Πx'(z')` is defined based on combinations of features.
    -   The loss function `L(f, g, Πx')` measures the difference between the original model `f` and the explanation `g`.

### Uniqueness of Additive Feature Attributions

SHAP values uniquely satisfy three desirable properties:

1.  **Local accuracy**
2.  **Missingness** (features with zero value have zero impact)
3.  **Consistency**

### Feature Importance - Multicollinearity

-   The importance of a feature might be underestimated in the presence of multicollinearity.
-   SHAP estimates every possible combination of feature subsets.
-   The total score (**Shapley sampling value**) of a feature is a weighted average of all possible combinations with this feature included.

### Drawbacks of SHAP

-   Shapley sampling values require estimating the importance score for every possible subset combination of input features.
-   Even with KernelSHAP, computational complexity is high.
-   With local approximators, we may still have problems understanding the model's behavior.
-   Time-series dependencies are not taken into consideration.

### SHAP Summary

-   SHAP is an additive feature attribution method.
-   SHAP handles multicollinearity well.
-   SHAP improves over LIME because it finds a unique solution that satisfies the properties of local accuracy, consistency, and missingness.
