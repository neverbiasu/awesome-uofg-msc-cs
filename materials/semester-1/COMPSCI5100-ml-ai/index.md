# COMPSCI5100: Machine Learning & Artificial Intelligence for Data Scientists (2025-26)

This document provides a central index for the course materials, schedules, and resources for COMPSCI5100.

---

## 1. General Information

- **Teaching team**:
  - Dr. Ali Gooya (`ali.gooya@glasgow.ac.uk`)
  - Dr. Fani Deligianni (`Fani.Deligianni@glasgow.ac.uk`)

- **Course Aims**: This course introduces the theory of learning from data and popular Machine Learning methods. It focuses on the practical application of ML techniques using standard libraries like `scikit-learn` in various domains, and emphasizes good practice in model training and validation.
