1 General Information
This course provides a practical introduction to data science, which we define as the fundamental principles of
and practical skills for extracting information and knowledge from data. It will cover the theory and practice of
activities in the data science pipeline:
data collection, data wrangling, data storage, data analytics, and data visualisation.
It will also introduce the mathematical and statistical foundations of data science.
This course is a practical, skills-based course. It is programming intensive. You will be expected to write a
substantial amount of Python code, and to use a variety of programming tools and libraries. You will also be
expected to do a substantial amount of independent study and self-directed learning.

• Course name: Introduction to Data Science and Systems (M)

1.2 Intended Learning Outcomes
By the end of this course, you should be able to:
1. Explain the data science pipeline and the role of each of its stages.
2. Write Python code to collect, wrangle, and store data.
3. Use a variety of data storage and access methods, including files, and databases.
4. Use a range of data analysis techniques, including numerical optimisation, and machine learning, to extract
information from data.
5. Use a range of data visualisation techniques to present data and the information extracted from it.
6. Explain the mathematical and statistical foundations of data science, including linear algebra, calculus, and
probability.
7. Use a variety of programming tools and libraries, including Jupyter, NumPy, SciPy, Pandas, and Matplotlib.
8. Work independently and in a group to solve data science problems.

1.4 Syllabus
This course will cover the following topics:
• Introduction to data science: what is data science? the data science pipeline; the role of the data scientist;
etc.
• Data collection: web scraping; APIs; etc.
• Data wrangling: data cleaning; data transformation; data integration; etc.
• Data storage: files; databases; etc.
• Data analysis: numerical optimisation; machine learning; etc.
• Data visualisation: principles of data visualisation; tools for data visualisation; etc.
• Mathematical and statistical foundations: linear algebra; calculus; probability; etc.
• Programming tools and libraries: Jupyter; NumPy; SciPy; Pandas; Matplotlib; etc.

There will be two lectures per week, on Mondays and Thursdays at 11am. The lectures will be held in the
Boyd Orr Building, Lecture Theatre 1.
The lectures will be recorded and made available on Moodle.
2.2 Labs
There will be a 2-hour lab session each week, on Tuesdays at 2pm or 4pm. The labs will be held in the
Boyd Orr Building, Lab 507.
The labs are not assessed, but they are an essential part of the course. You will be expected to attend the labs
and to complete the lab exercises. The labs will provide you with an opportunity to practice the skills you have
learned in the lectures, and to get help from the teaching assistants.
