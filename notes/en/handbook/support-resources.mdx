## ✉️ Email Communication Tips

### 📝 Email Format
'''
Subject: [MSc CS] Brief Problem Description
From: Student email (@student.gla.ac.uk)
Body:
- Introduction (Name, Student ID, Course)
- Problem Description (Clear and specific)
- Expected Response Time (Optional)
- Thank you
'''

### ⏰ Expected Response Times
- **Urgent issues**: Same day
- **General questions**: 1-3 workdays
- **Complex issues**: Within 1 week
- **Holiday periods**: Up to 2 weeks

## 🚨 Handling Emergencies

### 🆘 Academic Emergencies
1. **Missed Exam/Deadline**: Contact the course coordinator immediately.
2. **Health Problem**: Apply for EC + provide medical evidence.
3. **Technical Failure**: Contact IT Services.
4. **Misunderstood Requirements**: Clarify as soon as possible to avoid escalation.

### 🏥 Personal Emergencies
1. **Medical Emergency**: 999 (UK emergency number).
2. **Mental Health Crisis**: Samaritans 116 123.
3. **Campus Safety**: Contact Campus Security.
4. **Visa Emergency**: Use the ISS emergency hotline.
*Don't face problems alone; seeking help promptly is a wise choice.*
