# 📌 Table 3: Academic Performance and Assessment System
| **📊 Academic Performance & Assessment** | **📌 Key Points at a Glance** |
||--|
| **Grading Scale** | 🎯 **22-Point Scale**: A1=22 points → H=0 points<br/>(50 marks = C3 = 12.0, passing grade) |
| **GPA Calculation** | 📈 Weighted average by course credits<br/>(e.g., 20 credits at B2=18 → contributes 20/120 × 18 = 3.0) |
| **Resit Policy** | 🔄 **August Resits**, grade capped at **C3 (12.0)**<br/>❗ **Does not affect** Merit/Distinction award (based on first attempt only) |
| **Late Submission Penalty** | ⏳ **-2 bands/day**, >5 days or work returned → **H (0 points)** |
| **Exceptional Circumstances (EC)** | 🆘 **EC Application**: Apply for deferred assessment/extension for illness/emergencies (proof required) |

## ⚠️ Important Reminders
- **12.0 is the progression threshold**, not a comfort zone.
- **Resits offer a second chance but have limitations**.
- **Late submission penalties are strict**; time management is crucial.
- **EC applications require sufficient evidence**.
*Grades are not the destination; continuous learning is the goal.*
