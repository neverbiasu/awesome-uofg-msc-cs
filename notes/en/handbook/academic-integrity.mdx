## 🚨 High-Risk Behavior Warning

### 💻 Programming Assignments
- **Directly copying code** = Academic misconduct
- **Making assignment code public** = Facilitating plagiarism for others
- **Using others' GitHub repositories** = Violation of originality requirements

### 📝 Essay Writing
- **Copying paragraphs** = Plagiarism
- **Failing to cite sources** = Plagiarism
- **Purchasing ghostwriting services** = Severe violation

### 🤖 AI Tool Usage
- **ChatGPT/Claude, etc.** = Permitted, but must be declared
- **Not declaring AI use** = Misleading conduct
- **Over-reliance on AI** = May hinder learning outcomes

## ✅ Guide to Good Practice

### 📚 Academic Integrity
1. **Complete work independently**: All assignments should be your own original work.
2. **Cite correctly**: Acknowledge all sources used.
3. **Declare assistance**: Including AI tools, discussions with peers, etc.

### 🤝 Reasonable Collaboration
1. **Discuss ideas**: It's okay to discuss concepts and methods.
2. **Share resources**: You can recommend reference materials.
3. **Avoid plagiarism**: Do not share answers or code directly.

### 📱 Attendance Management
1. **Check-in on time**: Use the SafeZone App to record attendance.
2. **Follow procedures for absence**: Apply for EC in case of illness or emergency.
3. **Maintain records**: Keep a good attendance record.

## 🆘 Consequences of Violations

| Severity of Violation | Possible Consequences |
|-----------------------|-----------------------|
| Minor Violation | Warning, re-do assignment |
| Moderate Violation | 0 marks for the course, formal record |
| Severe Violation | Suspension, expulsion |
| Visa Violation | Cancellation of sponsorship, deportation |
