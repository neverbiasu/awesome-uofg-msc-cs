## Overview

This week introduces fundamental concepts of Human-Computer Interaction, focusing on visual usability principles that form the foundation of effective interface design.

- **Format**: Lectures + Lab sessions
- **Topics**: Visual usability, consistency, hierarchy, layout

## Learning Objectives

1. Understand the importance of visual usability in interface design
2. Apply consistency principles across interface elements
3. Create effective visual hierarchies
4. Design layouts that enhance usability

## Key Concepts

### Visual Usability

Visual usability refers to how easily users can perceive and understand interface elements through visual design. Good visual usability reduces cognitive load and improves task completion efficiency.

### Consistency

- **Definition**: Maintaining uniform design patterns throughout an interface
- **Types of Consistency**:
  - **Internal consistency**: Same patterns within one product
  - **External consistency**: Alignment with platform conventions
  - **Real-world consistency**: Matching user mental models

- **Benefits**:
  - Reduces learning time
  - Increases predictability
  - Builds user confidence

### Hierarchy

- **Definition**: Organizing elements to show their relative importance
- **Visual Hierarchy Techniques**:
  - Size and scale
  - Color and contrast
  - Typography weight
  - Spacing and positioning

- **Purpose**: Guide users' attention to the most important elements first

### Layout Design

- **Principles**:
  - Grid systems for alignment
  - White space for readability
  - Grouping related elements
  - F-pattern and Z-pattern scanning

- **Considerations**:
  - Responsive design for different screen sizes
  - Accessibility requirements
  - Cultural reading patterns

## Practice Checklist

- [ ] Identify consistency issues in existing interfaces
- [ ] Analyze visual hierarchy in popular applications
- [ ] Create a basic layout using grid principles
- [ ] Evaluate a design for usability problems
