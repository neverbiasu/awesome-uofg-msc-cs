# COMPSCI 5103: Deep Learning

This course provides an in-depth introduction to deep learning theory and practice, covering core technologies such as neural network fundamentals, convolutional neural networks, and recurrent neural networks, as well as model development using PyTorch.

<Accordions>
  <Accordion title="Course Information">
    **Learning Objectives:**
    1. Understand the basic principles of neural networks
    2. Master backpropagation and gradient descent algorithms
    3. Learn deep learning architectures like CNN and RNN
    4. Implement deep learning models using PyTorch
    5. Understand training techniques such as regularization and optimization
  </Accordion>
  <Accordion title="Course Structure & Assessment">
    **Course Structure:**
    - Lectures: Theoretical knowledge
    - Labs: PyTorch programming practice
    - Project: Deep learning application development

    **Assessment:**
    - Coursework assignments
    - Final exam/project
  </Accordion>
