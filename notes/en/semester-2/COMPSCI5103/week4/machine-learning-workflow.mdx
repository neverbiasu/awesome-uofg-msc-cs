## Overview

- **Goal**: Understand the key steps in a machine learning workflow for deep learning.
- **Key Concepts**: Data Preparation, Evaluation Protocols, Overfitting/Underfitting, Hyperparameter Tuning.

## The 8-Step Workflow

<Steps>
### 1. Define the Problem & Assemble Dataset
- **Inputs & Outputs**: What are you trying to predict?
- **Problem Type**: Binary/Multiclass Classification? Regression? Clustering?
- **Hypothesis**: Can outputs be predicted from inputs? Do you have enough data?

### 2. Choose a Measure of Success
- **Metrics**: 
    - **Balanced Data**: Accuracy.
    - **Unbalanced Data**: Precision, Recall, F1 Score, AUC-ROC.
    - **Regression**: Mean Squared Error (MSE).
- **Goal Alignment**: Metrics should align with higher-level business goals (e.g., customer retention).

### 3. Prepare the Data
Deep learning requires specific data preprocessing:
- **Vectorization**: Turn data into tensors (e.g., One-hot encoding for categories).
- **Normalization**: Scale values to [0, 1] or [-1, 1] to stabilize learning.
- **Standardization**: Rescale to mean 0 and std dev 1 (Gaussian).
- **Missing Data**: Imputation or dropping samples.
- **Data Augmentation**: Generate new training samples by transforming existing ones (e.g., rotating images) to improve generalization.

### 4. Decide on an Evaluation Protocol
- **Hold-out Validation**: Split data into Training, Validation, and Test sets (e.g., 60/20/20).
- **K-Fold Cross-Validation**: Use when data is limited.
- **Test Set**: Use ONLY ONCE at the very end to estimate generalization error.

### 5. Monitor and Diagnose Issues
- **Underfitting**: Model is too simple (high bias). Fix: Increase capacity (layers/neurons).
- **Overfitting**: Model is too complex (high variance). Fix: Regularization, more data, early stopping.
- **Learning Curves**: Monitor Loss/Accuracy on Training vs Validation sets.

### 6. Create a Simple Baseline Model
- Establish a lower bound for performance.
- Verify that the network can actually learn something (beat random chance).

### 7. Scale Up: Develop an Over-Capacity Model
- Create a model that is powerful enough to **overfit**.
- Why? To ensure the model has enough capacity to capture the underlying patterns.
- "The porridge needs to be too hot before we cool it down."

### 8. Tune Hyperparameters & Regularize
Optimize the model to generalize better:
- **Hyperparameters**: Learning rate, batch size, network depth/width.
- **Regularization**: Dropout, L1/L2 Weight Decay.
- **Optimization Strategies**:
    - **Grid Search**: Exhaustive but slow.
    - **Random Search**: Often more effective.
    - **Bayesian Optimization**: Smart search using a surrogate model.
</Steps>

## Key Concepts

### Feature Engineering
- **One-hot Encoding**: For nominal categories (e.g., Blue=[1,0,0], Green=[0,1,0]).
- **Binning**: Converting continuous values into categorical bins (e.g., Age 0-5, 6-10).

### Loss Functions
- **Regression**: MSE, MAE.
- **Classification**: Cross-Entropy (Negative Log Likelihood).
- **Softmax**: Use for probability distribution output.

### Monitoring Training
- **Learning Rate**: The most important hyperparameter.
    - Too high: Diverges.
    - Too low: Slow convergence.
    - Just right: Steady decrease in loss.
