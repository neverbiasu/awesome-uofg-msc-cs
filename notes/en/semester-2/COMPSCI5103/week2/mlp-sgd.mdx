## Overview
- **Objective**: To understand the architecture of MLPs and the mechanics of SGD for training neural networks.
- **Scope**: Covers the components of an MLP (layers, neurons, activation functions) and the update rule for SGD.

## Learning Objectives
1. Design a simple MLP for a given problem.
2. Explain the role of non-linear activation functions.
3. Describe how SGD uses gradients to update model parameters.

## Key Concepts

### Multi-Layer Perceptron (MLP)
- **Motivation**: To model non-linear patterns that single-layer perceptrons cannot.
- **Core Concepts**:
    - **Input Layer**: Receives the feature vector.
    - **Hidden Layers**: One or more layers that transform the input non-linearly. Composed of neurons, each with a weight, a bias, and an activation function.
    - **Output Layer**: Produces the final output (e.g., class probabilities).
    - **Activation Functions**: Introduces non-linearity (e.g., ReLU, Sigmoid, Tanh).

### Stochastic Gradient Descent (SGD)
- **Motivation**: An efficient way to train models on large datasets by approximating the true gradient.
- **Core Concepts**:
    - **Loss Function**: Measures the error between the model's prediction and the true label.
    - **Gradient**: The derivative of the loss function with respect to the model parameters. It points in the direction of the steepest ascent.
    - **Update Rule**: Parameters are adjusted in the opposite direction of the gradient.
- **Formula**: `θ = θ - η * ∇J(θ; x^(i); y^(i))`, where `η` is the learning rate.
