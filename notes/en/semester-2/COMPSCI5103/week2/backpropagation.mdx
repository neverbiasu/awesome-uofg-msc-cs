## Overview
- **Objective**: To understand the mechanics of the backpropagation algorithm for efficient gradient computation.
- **Scope**: Covers computational graphs, the chain rule, and the forward and backward passes.

## Learning Objectives
1. Represent a function as a computational graph.
2. Apply the chain rule to compute gradients in a simple graph.
3. Describe the forward and backward passes of backpropagation.

## Key Concepts

### Computational Graphs
- **Motivation**: To provide a clear and explicit representation of a function, making it easier to manage and compute derivatives.
- **Core Concepts**:
    - **Nodes**: Represent variables or operations.
    - **Edges**: Represent the flow of data.
- **Example**: The function `f(x, y, z) = (x + y) * z` can be broken down into `q = x + y` and `f = q * z`.

### Backpropagation Algorithm
- **Motivation**: An efficient algorithm to compute the gradients of a complex function (like a neural network's loss) with respect to its parameters.
- **Core Concepts**:
    - **Chain Rule**: The core mathematical rule used to find the derivative of a composite function. `∂f/∂x = (∂f/∂q) * (∂q/∂x)`.
    - **Forward Pass**: The inputs are fed through the network, and the output of each node in the computational graph is calculated, culminating in the final loss.
    - **Backward Pass**: Starts from the output node (the loss). The gradient of the loss with respect to itself is 1. It then recursively applies the chain rule to compute the gradient of the loss with respect to each input node (parameters, weights, etc.).
