## Key Takeaway
Backpropagation is an efficient application of the chain rule from calculus, allowing us to calculate gradients for every parameter in a deep network by traversing the computational graph in reverse.

## 1. Multi-Layer Perceptrons (MLP)
An MLP consists of an input layer, one or more hidden layers, and an output layer.
-   **Fully Connected**: Each neuron in one layer is connected to all neurons in the next.
-   **Forward Pass**: Data flows from input to output to compute the loss.

## 2. Gradient Descent Optimization
To minimize the **Loss Function** (e.g., Mean Squared Error, Cross-Entropy), we update weights in the opposite direction of the gradient.
$$w_{new} = w_{old} - \eta \cdot \frac{\partial L}{\partial w}$$
-   **Learning Rate ($\eta$)**: Determines the size of the step. Too high causes oscillation; too low causes slow convergence.

## 3. The Backpropagation Algorithm
Backpropagation uses the **Chain Rule** to compute the gradient of the loss with respect to each weight.
<Steps>

### Steps in Backpropagation
1.  **Forward Pass**: Calculate activations and the final loss.
2.  **Loss Derivative**: Calculate the gradient at the output layer.
3.  **Backward Pass**: Propagate gradients backward through the layers using the chain rule.
4.  **Weight Update**: Apply SGD or other optimizers to update parameters.
</Steps>

## 4. Examiner's Perspective: Technical Nuances

### Vanishing and Exploding Gradients
-   **Vanishing**: Gradients become extremely small in early layers (common with Sigmoid), preventing learning.
-   **Exploding**: Gradients become extremely large, leading to numerical instability.
- *Exam Tip*: Use **ReLU** and **Batch Normalization** to mitigate these issues.

### Computational Complexity
-   Backpropagation is roughly the same complexity as the forward pass ($O(W)$ where $W$ is the number of weights), making it highly efficient for training massive models.
