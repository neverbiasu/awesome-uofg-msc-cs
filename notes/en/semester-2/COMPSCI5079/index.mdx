# COMPSCI 5079: Cryptography and Secure Development

This course covers the fundamentals of cryptography and secure software development, including symmetric and asymmetric encryption, hash functions, digital signatures, and secure coding practices.

<Accordions>
  <Accordion title="Course Information">
    **Learning Objectives:**
    1. Understand fundamental cryptographic concepts and algorithms
    2. Implement encryption and decryption systems
    3. Apply secure coding practices
    4. Analyze security vulnerabilities and threats
    5. Design secure software systems
  </Accordion>
  <Accordion title="Course Structure & Assessment">
    **Course Structure:**
    - Lectures: Cryptographic theory and security concepts
    - Labs: Implementation exercises
    - Assignments: Practical security tasks

    **Assessment:**
    - Midterm assignment
    - Coursework
    - Final exam
  </Accordion>
</Accordions>
