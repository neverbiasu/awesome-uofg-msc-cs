This week's lecture focuses on two critical areas of modern cryptography: ensuring data integrity via message digests and distributing trust via secret sharing.

## Message Digests (Hashing)
A **Message Digest (MD)** is a small, fixed-size "fingerprint" of a larger document. It is used to uniquely identify a message and ensure it has not been tampered with.
![Message Digest Concept](/images/COMPSCI5079/week4/S41_COMPSCI5079_Message_Digests-012.png)

### Requirements of Message Digest
1. **Efficiency**: Easy to compute $h(M)$.
2. **Pre-image Resistance**: Given $h$, hard to find $M$.
3. **Second Pre-image Resistance**: Given $M$, hard to find $M'
eq M$ such that $h(M) = h(M')$.
4. **Collision Resistance**: Hard to find *any* two $M, M'$ such that $h(M) = h(M')$.

### Birthday Attacks
The **Birthday Paradox** shows that the probability of collisions is much higher than intuition suggests. For an $m$-bit hash, finding a collision requires only $\approx 2^{m/2}$ attempts, not $2^m$.
![Birthday Paradox](/images/COMPSCI5079/week4/S41_COMPSCI5079_Message_Digests-017.png)
- **Vulnerability**: A 64-bit hash is vulnerable because a collision can be found in $2^{32}$ attempts (feasible on modern hardware).
- **Security**: Current standards use at least 256 bits (SHA-256).

## Random Number Generators
Cryptography relies on unpredictability.
- **PRNG**: Repeatable, based on a seed (e.g., LCG).
- **CSPRNG**: Unpredictable; even if part of the sequence is known, the rest cannot be derived.
- **TRNG**: True random, based on physical noise.

### Historical Failures
- **Netscape's PRNG**: Seeded with process IDs and millisecond time, making it easily breakable via brute force.
- **Dual_EC_DRBG**: A NIST standard with a suspected "backdoor" from secret parameters.

## Secret Sharing (Threshold Schemes)
How do we split a secret so that multiple parties are required to reconstruct it?

### Secret Splitting (XOR)
Divide $M$ into $n$ pieces using XOR. All $n$ pieces are required. If one is lost, the secret is gone.

### Shamir's Secret Sharing ($m, n$ Threshold)
Allows reconstruction if any $m$ out of $n$ participants provide their "shadows".
- **Mechanism**: Based on **Lagrange Interpolation**. A polynomial of degree $m-1$ is created where the constant term is the secret.
- **Example**: For $m=2$, a straight line $y = ax + b$ is used. Any two points on the line can reconstruct the equation.

## Key Takeaway
- **Integrity vs. Authentication**: A hash provides integrity; a MAC (Message Authentication Code) provides both integrity and authentication via a shared secret key.
- **Collision Resistance**: Always use hash functions with large output sizes (e.g., 256 bits) to defend against Birthday Attacks.
- **Fault Tolerance**: Threshold schemes provide both security and availability by requiring a quorum of participants.
