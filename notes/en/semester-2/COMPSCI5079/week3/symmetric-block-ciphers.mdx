Symmetric key cryptography uses the same key for both encryption and decryption. Block ciphers process data in fixed-size blocks (e.g., 64 or 128 bits).

## Feistel Cipher Structure

Many older block ciphers, including DES, are based on the **Feistel Structure**.

- **Mechanism**:
    1.  Split the plaintext block into two halves: Left ($L_0$) and Right ($R_0$).
    2.  For each round $i$:
        - $L_{i+1} = R_i$
        - $R_{i+1} = L_i \oplus f(R_i, K_i)$
    3.  Where $f$ is the round function and $K_i$ is the subkey for that round.
- **Advantage**: Encryption and decryption are structurally identical, requiring only the reversal of the key schedule.

## DES (Data Encryption Standard)

Adopted in 1977, DES was the standard for decades.

- **Block Size**: 64 bits.
- **Key Size**: 56 bits (effective).
- **Structure**: 16-round Feistel network.
- **Security**: Now insecure due to the short key size. A modern GPU cluster can brute-force DES in hours.

## AES (Advanced Encryption Standard)

Adopted in 2001 to replace DES. Based on the **Rijndael** algorithm.

- **Block Size**: 128 bits.
- **Key Size**: 128, 192, or 256 bits.
- **Structure**: Substitution-Permutation Network (SPN). It is **NOT** a Feistel network.

### AES Transformations
AES operates on a $4 	imes 4$ matrix of bytes called the **State**.

1.  **SubBytes**: Non-linear substitution using an S-box. Provides **Confusion**.
2.  **ShiftRows**: Cyclically shifts rows of the State. Provides **Diffusion**.
3.  **MixColumns**: Mixes data within each column. Provides **Diffusion**.
4.  **AddRoundKey**: XORs the State with the round key.

## Confusion vs. Diffusion

Claude Shannon identified two primitive operations for secure ciphers:

- **Confusion**: The relationship between the key and the ciphertext should be complex (e.g., Substitution).
- **Diffusion**: A small change in the plaintext should result in a massive change in the ciphertext (Avalanche Effect) (e.g., Permutation/Transposition).

## Key Takeaway

- **Feistel Reversibility**: The Feistel structure allows the same hardware/software to perform encryption and decryption.
- **AES Robustness**: AES's security comes from the combination of its four transformations, providing strong confusion and diffusion.
- **Key Length Matters**: DES failed primarily because 56 bits is too small for modern computing power.
