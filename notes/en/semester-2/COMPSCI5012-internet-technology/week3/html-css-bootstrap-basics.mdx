## Key Takeaways
- **HTML (HyperText Markup Language)** provides the fundamental structure of web pages using a system of tags and elements.
- **CSS (Cascading Style Sheets)** is used to control the presentation, styling, and layout of HTML elements, enabling the separation of content from design.
- **Bootstrap** is a popular frontend framework that provides pre-built components and a powerful grid system to facilitate rapid, responsive, and mobile-first web development.
- **Web Sustainability** is an important consideration in modern web development, focusing on minimizing the carbon footprint by optimizing code, reducing data transfer, and using resources efficiently.
- **Best Practices**: Use semantic HTML, external CSS stylesheets for maintainability, and follow principles like "Mobile First" to create efficient and accessible websites.

## Introduction to HTML

HTML, or **HyperText Markup Language**, is the standard language used to create and structure the content of web pages. It uses a system of "mark-up" tags to describe different elements within a document.

### Basic HTML Document Structure

An HTML document is a plain text file containing tags. The basic structure is as follows:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>This is a Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```

- **`<!DOCTYPE html>`**: Declares the document type.
- **`<html>`**: The root element of the page.
- **`<head>`**: Contains meta-information about the document, such as the title.
- **`<body>`**: Contains the visible page content that is displayed in the browser.

### Common HTML Elements

- **Headings**: `<h1>` to `<h6>` define headings, with `<h1>` being the most important. Search engines use these to index the page content.
- **Paragraphs**: `<p>` defines a paragraph. Browsers automatically add margins around paragraphs.
- **Line Breaks**: `<br>` is an empty element (no closing tag) that forces a line break.
- **Lists**: `<ul>` (unordered list) and `<ol>` (ordered list) are used with `<li>` (list item) to create lists.
- **Divisions**: `<div>` is a block-level container used to group and section content, often for styling with CSS.

<Callout title="Development Philosophy: HTML First">
  A common guideline in web development:
  1. If you can do it with HTML, use HTML.
  2. If you can’t do it with HTML, use CSS.
  3. If you can’t do it with HTML or CSS, use JavaScript.
</Callout>

## Styling with Cascading Style Sheets (CSS)

CSS is a stylesheet language used to describe the presentation of a document written in HTML. It allows developers to separate content structure (HTML) from visual styling, which improves maintainability, performance, and flexibility.

### CSS Rule Syntax

A CSS rule consists of a **selector** and a **declaration block**.

```css
/* selector { property: value; } */

p {
  color: blue;
  font-size: 16px;
}

h1, h2, h3 {
  color: red;
}

/* The ID selector targets a unique element */
#main-header {
  border-bottom: 1px solid black;
}

/* The class selector targets all elements with a specific class */
.warning {
  font-weight: bold;
}
```

### Applying CSS to HTML

There are three ways to apply CSS to an HTML document:

1.  **Inline CSS**: Using the `style` attribute directly on an HTML element. (Breaks separation of concerns, generally avoided).
    ```html
    <p style="color: red;">This is a red paragraph.</p>
    ```
2.  **Embedded CSS**: Placing CSS rules within a `<style>` tag in the `<head>` section of the HTML document.
3.  **External CSS**: Placing CSS rules in a separate `.css` file, which is linked from the HTML document. **This is the best practice.**
    ```html
    <head>
      <link rel="stylesheet" href="styles.css" type="text/css">
    </head>
    ```

### The Box Model, Cascade, and Specificity

- **The Box Model**: Every HTML element is a rectangular box. This box consists of the **content**, surrounded by **padding**, a **border**, and a **margin**. CSS properties control the size and appearance of each of these parts.
- **Inheritance**: Descendant elements inherit style properties from their parent elements.
- **Specificity**: When multiple CSS rules apply to the same element, the browser uses a specificity score to decide which rule wins. ID selectors (`#id`) are more specific than class selectors (`.class`), which are more specific than element selectors (`p`).
- **Cascade**: If rules have the same specificity, the one that appears last in the stylesheet wins. This "cascading" nature gives CSS its name.

### Page Layout with CSS

Historically, HTML tables were used for page layout, but this is now considered bad practice. The modern approach uses CSS properties like `float`, `position`, and newer layout systems like **Flexbox** and **Grid** to create complex and responsive layouts using `<div>` elements.

## Introduction to Bootstrap

Bootstrap is a popular, free, and open-source frontend framework for developing responsive, mobile-first websites. It includes pre-styled CSS components and JavaScript plugins.

**Advantages of Bootstrap:**
- **Ease of Use**: Quickly build layouts with pre-defined classes.
- **Responsive Features**: Its grid system automatically adapts layouts to different screen sizes (desktops, tablets, phones).
- **Mobile-First Approach**: Core styles are designed for small screens first, then scaled up.
- **Cross-Browser Compatibility**: Ensures a consistent look and feel across modern browsers.

To get started, you can visit the official website at [getbootstrap.com](https://getbootstrap.com/) and follow their tutorials.

## Web Sustainability in Frontend Development

The internet contributes to a significant portion of global emissions (~4%). As developers, we can adopt practices to create more sustainable, energy-efficient websites.

<Callout title="Sustainable Web Design Principles">
  According to the [Sustainable Web Manifesto](https://www.sustainablewebmanifesto.com/), products and services should use clean energy, use the least amount of energy, and be accessible to all.
</Callout>

### Key Guidelines

<Steps>
  <Step title="Optimize and Minify">
    Minify your HTML, CSS, and JavaScript files to remove unnecessary whitespace and comments. This reduces file size and improves loading times.
  </Step>
  <Step title="Use HTML Correctly">
    Write valid, semantic HTML. Bloated or deprecated markup wastes data and increases energy consumption during transfer and rendering. Avoid using deprecated elements like `<center>` or `<font>`; use CSS instead.
  </Step>
  <Step title="Avoid Code Duplication">
    Use CSS classes to apply reusable styles instead of repeating inline styles. This improves maintainability and reduces file size.
  </Step>
  <Step title="Adapt to User Preferences and Devices">
    Use CSS media queries to create responsive layouts that adapt to different devices. Also, respect user preferences like `prefers-reduced-data` or `prefers-color-scheme` (dark mode) to save energy.
  </Step>
</Steps>

<Callout title="Development Guideline: Mobile First">
  A sustainable approach to design is "Mobile First". Start by designing for the smallest screen size, which forces you to prioritize essential content and optimize performance. Then, progressively enhance the design for larger screens. A key aspect is setting a **page weight budget** to keep your pages light and fast.
</Callout>
