## Overview

- **Goal**: To provide a comprehensive introduction to COMPSCI5012 Internet Technology (ITECH), clarifying learning objectives, the teaching team, course structure, and assessment methods.
- **Scope**: Course syllabus, schedule, assessment criteria (individual coursework, group project, exam), and academic integrity requirements.

## Learning Objectives

1. **Understand** the core aims of the course: Designing, developing, and deploying distributed Web applications.
2. **Familiarize** with the course structure: Lectures, Labs, and self-study.
3. **Clarify** assessment methods: Lab Quizzes (30%), Group Coursework (50%), and Final Exam (20%).
4. **Know** communication channels and code of conduct.

## Key Knowledge Points

### 1. Course Aims

- **Keyword**: Web Application Development.
- **Main Content**:
  - Overview of ongoing developments in web app development.
  - Promoting **disciplined design** and development of distributed web applications.
  - Understanding the context and rationale of distributed systems.
  - Explaining **messaging and protocols** used in web applications.
  - Developing the ability to **implement and deploy** distributed web applications.
  - Promoting the design of **accessible and sustainable** web applications.

### 3. Assessments

- **Individual Coursework (30%)**:
  - 3 x Lab Quizzes (10% each).
  - Format: 15 minutes, one-shot.
  - Timing: Open on Thursdays, deadline next Tuesday.
- **Group Coursework (50%)**:
  - Content: Design, develop, and deploy a web application using Django.
  - **Phase 1 (15%)**: Design Specification.
  - **Phase 2 (35%)**: Implementation + Video Presentation (5%) + Application (30%).
  - **Groups**: Teams of 3, must register on Moodle.
- **Individual Exam (20%)**:
  - Timing: April/May.

### 4. Communication & Support

- **One-way**: Moodle (Announcements).
- **Two-way**:
  - In-person during Lectures and Labs.
  - Offline via **Padlet**.
  - **Do not** DM/Email lecturers or TAs directly (unless for personal issues or serious group conflicts).

![Padlet for Q&A](/images/COMPSCI5012/L0-Welcome_to_the_course-007.jpg)

## Best Practices

- **Engage Actively**: Attend lectures and use labs for 1-1 support from TAs.
- **Start Early**: The group project is significant; plan design and development early.
- **Academic Integrity**: Plagiarism and cheating are strictly prohibited. GenAI usage must be acknowledged and cannot replace original work.
- **Use Resources**: Use Padlet or Labs for help when stuck; don't struggle alone.
