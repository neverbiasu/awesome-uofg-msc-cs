## Summary

This week explores how computers communicate over the internet. It covers the theoretical models (OSI, TCP/IP), the practical details of the HTTP protocol (Requests, Responses, Methods), and how distributed systems exchange data via Inter-Process Communication (IPC) using technologies like REST and gRPC.

<Accordions>
  <Accordion title="Network Models">
    The 7-layer **OSI Model** vs. the 4-layer **TCP/IP Model**. Understanding how data moves from the Physical layer up to the Application layer.
  </Accordion>
  <Accordion title="HTTP Fundamentals">
    The request-response cycle. Key methods (**GET** vs **POST**), status codes, headers, and the stateless nature of HTTP (and how Cookies/Sessions fix this).
  </Accordion>
  <Accordion title="Inter-Process Communication (IPC)">
    Protocols for systems to talk to each other: **REST** (Representational State Transfer) APIs using JSON, compared to legacy **SOAP** (XML) and modern **gRPC** (Protocol Buffers).
  </Accordion>
</Accordions>
