## Database Modeling - ER Model

- **ER Model (Entity-Relationship Model)**: Abstract representation of data and relationships
- **Three Core Components**:
  1. **Entity**: Data objects, e.g., users, orders
  2. **Relationship**: Connections between entities
  3. **Attribute**: Characteristics of entities

- **Relationship Types**:
  - **One-to-One (1:1)**: e.g., one user to one profile
  - **One-to-Many (1:N)**: e.g., one author to many articles
  - **Many-to-Many (M:N)**: e.g., students and courses

## Information Architecture (IA)

- **Definition**: Structural design of shared information environments
- **Core Focus**:
  - Organization systems
  - Labeling systems
  - Search systems
  - Navigation systems

- **Three Key Elements**:
  - **Context**: Business goals, technical constraints
  - **Content**: Information structure, data types
  - **Users**: Target users, usage scenarios

- **Key Deliverables**:
  - **User Requirements**: User Stories, Personas
  - **Site Map**: Page hierarchy structure
  - **User Flow**: User navigation paths
  - **Wireframe**: Page layout sketches
