## Summary

This week lays the foundation for web development by covering the core technologies of the frontend: HTML for structure, CSS for presentation, and Bootstrap for responsive layout.

<Accordions>
  <Accordion title="HTML5 Semantics">
    Understanding the document object model (DOM) and semantic tags (`<nav>`, `<header>`, `<article>`) for better accessibility and SEO.
  </Accordion>
  <Accordion title="CSS Layouts">
    Mastering the **Box Model** (margin, border, padding, content). Introduction to modern layout systems like **Flexbox** and **Grid**.
  </Accordion>
  <Accordion title="Bootstrap Framework">
    Using a component-based framework to speed up development. The **12-column grid system**, utility classes, and pre-built components like navbars and cards.
  </Accordion>
</Accordions>
