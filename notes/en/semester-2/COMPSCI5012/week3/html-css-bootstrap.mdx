## Key Takeaway
HTML provides the semantic structure, CSS defines the presentation, and frameworks like Bootstrap enable rapid creation of responsive, mobile-first interfaces.

## HTML5: Semantic Structure
HTML (HyperText Markup Language) is the backbone of web content.

### Core Principles
-   **Separation of Content and Presentation**: Use HTML for what it *is* (semantics), CSS for what it *looks like*.
-   **Document Object Model (DOM)**: The browser's hierarchical representation of the HTML page.
![DOM Tree Representation](/images/COMPSCI5012/week3/L3-HTMLCSSBootstrap-012.png)

## CSS: Styling & Layout
CSS (Cascading Style Sheets) describes how HTML elements are to be displayed.

### The Box Model
Every HTML element is considered a box.
-   **Content**: The text/images.
-   **Padding**: Clear area around the content (inside border).
-   **Border**: Area around padding and content.
-   **Margin**: Clear area outside the border.
<Callout type="info">
**Specific Nuance**: `box-sizing: border-box` makes layout math much easier by including padding and border in the element's total width/height.
</Callout>

## Responsive Design with Bootstrap
Bootstrap is a front-end framework that provides a grid system and pre-styled components.

### The Grid System
-   Uses a **12-column system**.
-   **Containers** house rows, and **Rows** house columns (`col-*`).
-   **Breakpoints** (sm, md, lg, xl) allow for different layouts on different screen sizes.

## Examiner's Perspective: Technical Nuances

### CSS Selector Specificity
-   Inline styles > IDs > Classes/Attributes > Elements.
-   *Exam Tip*: If multiple rules apply to the same element, the most "specific" one wins, regardless of order.

### Responsive vs. Adaptive
-   **Responsive**: Fluid layout that changes as the screen size changes (CSS Media Queries).
-   **Adaptive**: Fixed layouts for specific device categories (e.g., one layout for mobile, one for desktop).
