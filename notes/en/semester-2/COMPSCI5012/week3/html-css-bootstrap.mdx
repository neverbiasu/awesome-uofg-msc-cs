## Overview

- **Goal**: Master building structured HTML documents; Apply CSS for styling and layout; Understand the role of frontend frameworks like Bootstrap; Recognize Web Accessibility and Sustainability principles.
- **Scope**: HTML5 basics, CSS selectors & box model, Layout techniques (Float, Flexbox, Grid), Bootstrap framework, Web Carbon Footprint.

## Learning Objectives

1. **Construct** structured HTML documents.
2. **Apply** CSS for styling and layout (Separation of Concerns).
3. **Understand** how frontend frameworks (e.g., Bootstrap) accelerate development.
4. **Learn** best practices for Web Sustainability and Accessibility.

## Key Knowledge Points

### 1. HTML (HyperText Markup Language)

- **Core Concepts**:
  - **Tags**: E.g., `<h1>`, `<p>`, `<div>`, defining document structure.
  - **Elements**: Consist of opening tag, content, and closing tag.
  - **Structure**: `<html>` -> `<head>` (metadata) + `<body>` (visible content).
- **Web Sustainability**:
  - The internet accounts for ~4% of global greenhouse gas emissions.
  - **Strategies**: Minify HTML/CSS/JS, remove deprecated code, reduce data transfer.
  - **Mobile First**: Design for mobile first to set a Page Weight Budget and remove unnecessary elements.

---

### 2. CSS (Cascading Style Sheets)

- **Motivation**: To separate content (HTML) from presentation (CSS). Improves maintainability, load speed, and reusability.
- **Core Concepts**:
  - **Selectors**:
    - Element (`p`)
    - Class (`.classname`) - Reusable
    - ID (`#idname`) - Unique
  - **Cascading**: Styles are applied based on Specificity and Order. Specificity: ID > Class > Element.
  - **Box Model**: Every element is a rectangular box containing Content, Padding, Border, and Margin.

- **Layout**:
  - **Legacy**: `float`, `position` (static, relative, absolute, fixed).
  - **Modern**: Flexbox (1D), Grid (2D) — Solve legacy layout complexity, support responsive design.

---

### 3. Bootstrap Framework

- **Motivation**: To rapidly build responsive, cross-browser compatible web applications.
- **Core Concepts**:
  - **Grid System**: 12-column layout adapting to screen sizes (Mobile, Tablet, Desktop).
  - **Components**: Pre-built Navbars, Buttons, Forms, Cards.
  - **Utility Classes**: Quick setting of margins, padding, colors.
- **Benefits**:
  - Mobile-first approach.
  - Consistent visual style.
  - Extensive community and documentation.

## Best Practices

- **Semantic HTML**: Use correct tags (e.g., `<header>`, `<nav>`, `<article>` instead of just `<div>`) for SEO and Accessibility.
- **External CSS**: Prefer external stylesheets over inline styles to maintain Separation of Concerns.
- **Responsive Design**: Use Media Queries or Bootstrap Grid to ensure pages look good on all devices.
- **Optimize Resources**: Compress images and code to reduce HTTP requests and lower the Web Carbon Footprint.
