## Summary

This week introduces the tools used to build scalable web applications. It defines what a web framework is (vs. a library) and dives into Django, a high-level Python web framework, explaining its specific architectural pattern (MVT).

<Accordions>
  <Accordion title="Frameworks vs. Libraries">
    **Inversion of Control**: The key difference. A library is a tool you call; a framework calls your code. Why frameworks are essential for complex web apps (security, scalability, speed).
  </Accordion>
  <Accordion title="Architectural Patterns">
    **MVC (Model-View-Controller)**: The industry standard pattern.
    **MVT (Model-View-Template)**: Django's variation.
    - **Model**: Data Access Layer.
    - **View**: Business Logic (Controller).
    - **Template**: Presentation Layer (View).
  </Accordion>
  <Accordion title="Django Fundamentals">
    The request lifecycle in Django: `URLconf` -> `View` -> `Model` -> `Template` -> `Response`. Setting up a project, creating apps, and mapping URLs.
  </Accordion>
</Accordions>
