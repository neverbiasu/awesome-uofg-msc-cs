## Overview
This week covers the complexity of web development, the role of WAFs, MVC architecture, and introduces the Django framework.
- Pace: tAPP + Lab (if applicable)
- Topics: Web Application Frameworks, Django, MVC Architecture, Framework vs. Library

## Weekly Schedule (in order)
| Session | Topic | Description |
|---|---|---|
| Lecture 1 | Web Development Complexity | Understanding the challenges of modern web development. |
| Lecture 2 | Frameworks & Libraries | Distinguishing between frameworks and libraries, and their characteristics. |
| Lecture 3 | MVC Architecture | Exploring the Model-View-Controller design pattern. |
| Lecture 4 | Introduction to Django | A deep dive into the Django framework, its philosophy, and architecture. |

## Learning Objectives
1. Understand the complexity of web development and why we need frameworks.
2. Map the elements of your architecture design to Django modules.
