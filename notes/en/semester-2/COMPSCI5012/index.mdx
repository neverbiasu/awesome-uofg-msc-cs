# COMPSCI 5012: Internet Technology

This course introduces web application design and development, covering core concepts such as system architecture, database modeling, and information architecture, as well as practical development using the Django framework.

<Accordions>
  <Accordion title="Course Information">
    **Learning Objectives:**
    1. Understand system architecture design for web applications
    2. Master database modeling and ER diagram design
    3. Learn information architecture and user experience design
    4. Develop web applications using Django framework
    5. Understand frontend-backend separation and API design
  </Accordion>
  <Accordion title="Course Structure & Assessment">
    **Course Structure:**
    - Lectures: Theoretical knowledge and design concepts
    - Labs: Django framework practical development
    - Group Project: Team collaboration on web application development

    **Assessment:**
    - Group project assignment
    - Individual report
  </Accordion>
</Accordions>
