## What is Big Data?

- **Definition**: Data that cannot be captured, stored, managed, and processed by traditional tools within an acceptable timeframe
- **Key Factors**:
  - **Storage and Access**: How to store and retrieve data
  - **Processing**: How to extract value from data
  - **Tools**: Available software tools
  - **Time**: Hardware processing capability

- **Why Big Data Exploded**:
  - Massive increase in data production and storage capacity
  - Organizations started storing "potentially useful" data
  - Explosive growth of internet-connected devices

## Big Data Use Cases

- **Three Operation Types**:
  1. **Extraction/Filtering**: Extract subsets matching specific criteria from large datasets
  2. **Transformation**: Apply functions to each data item and save results
  3. **Aggregation**: Merge and transform sets of data items

- **Batch vs Stream Processing**:
  | Feature | Batch | Stream |
  |---------|-------|--------|
  | Data | Static data | Continuously arriving new data |
  | Focus | Completion time | Per-item processing latency |
  | Examples | SQL queries, search indexing | Real-time filtering, stream aggregation |
