## Key Takeaway
Apache Spark overcomes MapReduce's limitations by keeping data in memory and using a Directed Acyclic Graph (DAG) for task scheduling, making it ideal for low-latency and iterative workloads.

## 1. Why Spark?
MapReduce's "Input-Map-Reduce-Output" cycle forces every stage to persist to disk. This is inefficient for:
-   **Iterative Jobs**: (e.g., Machine Learning training loops).
-   **Interactive Queries**: Real-time data exploration.

### The Spark Solution: In-Memory Computing
Spark allows data to be cached in RAM across the cluster, reducing Disk I/O significantly.
![Spark vs MapReduce Iteration](/images/COMPSCI5088/week3/03-04-ApacheSpark-005.png)

## 2. Resilient Distributed Datasets (RDDs)
RDD is the fundamental data structure of Spark.
-   **Resilient**: If a partition is lost, it can be recomputed from lineage.
-   **Distributed**: Data is spread across the cluster.
-   **Immutable**: Once created, an RDD cannot be changed; you transform it into a new RDD.

## 3. The Execution Model: DAG
Spark does not execute code immediately. It builds a **Directed Acyclic Graph (DAG)** of operations.
-   **Lazy Evaluation**: Transformations are only executed when an **Action** (like `collect()` or `save()`) is called.
-   **Pipelining**: Spark can collapse multiple transformations into a single stage to minimize data movement.
<Callout type="info">
**DAG Advantage**: Allows Spark to optimize the execution plan (e.g., reordering filters to reduce data size early).
</Callout>

## 4. Examiner's Perspective: Technical Nuances

### Fault Tolerance via Lineage
-   **Concept**: Instead of replicating data, RDDs keep track of how they were derived (Lineage).
-   **Nuance**: This saves disk space and network bandwidth, but recomputing a long lineage chain can be costly if a failure occurs late in the job.

### Transformation vs. Action
-   **Transformation**: Returns a new RDD (e.g., `map`, `filter`). Always lazy.
-   **Action**: Returns a value to the Driver or writes to storage (e.g., `count`, `collect`). Triggers execution.
