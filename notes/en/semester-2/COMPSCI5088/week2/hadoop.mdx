# Apache Hadoop

Hadoop is an open-source framework for distributed storage and processing of large datasets. Originally created by Doug Cutting and Mike Cafarella in 2005, inspired by Google's MapReduce and GFS papers.

## Hadoop Ecosystem Overview

```
┌─────────────────────────────────────────────────────────────┐
│                    HADOOP ECOSYSTEM                         │
├─────────────────────────────────────────────────────────────┤
```

## Core Components

### 1. HDFS (Hadoop Distributed File System)

Distributed storage layer designed for:
- Large files (GB to TB)
- Streaming data access
- Commodity hardware
- Write-once, read-many pattern

**Architecture**:
- **NameNode**: Manages filesystem metadata
- **DataNode**: Stores actual data blocks

### 2. MapReduce

Processing framework (covered in previous section):
- Batch processing paradigm
- Map and Reduce phases
- Automatic parallelization

### 3. YARN (Yet Another Resource Negotiator)

Resource management layer:
- **ResourceManager**: Global resource scheduler
- **NodeManager**: Per-node resource manager
- **ApplicationMaster**: Per-application coordinator

## Hadoop 1.x vs 2.x Architecture

### Hadoop 1.x

```
┌─────────────────────────────────┐
│          JobTracker             │  ← Single point of failure
│   (Job scheduling + Resources)  │
├─────────────────────────────────┤
│  TaskTracker  │  TaskTracker    │
│   (Map/Reduce tasks)            │
├─────────────────────────────────┤
│             HDFS                │
└─────────────────────────────────┘
```

**Problems**:
- JobTracker overloaded (scheduling + monitoring)
- Limited scalability (~4,000 nodes)
- Only supports MapReduce

### Hadoop 2.x (with YARN)

```
┌─────────────────────────────────────────────┐
│              ResourceManager                │
│          (Global scheduling)                │
├─────────────────────────────────────────────┤
│ NodeManager  │ NodeManager  │ NodeManager   │
│   Container  │   Container  │   Container   │
├─────────────────────────────────────────────┤
│                   HDFS                      │
└─────────────────────────────────────────────┘

Applications: MapReduce, Spark, Tez, Storm...
```

**Improvements**:
- Separation of resource management and job scheduling
- Supports multiple processing frameworks
- Better scalability (~10,000 nodes)

## How a Hadoop Job Runs

### Step-by-Step Execution

1. **Job Submission**
   - Client submits job to ResourceManager
   - Job includes: JAR, configuration, input paths

2. **Resource Allocation**
   - ResourceManager allocates container for ApplicationMaster
   - ApplicationMaster requests containers for tasks

3. **Task Execution**
   - Map tasks run on nodes with data (locality)
   - Intermediate output written to local disk
   - Shuffle transfers data to reducers

4. **Output Writing**
   - Reduce tasks write to HDFS
   - Job completion reported to client

### Execution Timeline

```
Time →
├── Input Splits ──→ Map Phase ──→ Shuffle ──→ Reduce Phase ──→ Output
│
│   [Split 1] ──→ [Map 1] ──┐
│   [Split 2] ──→ [Map 2] ──┼──→ [Shuffle/Sort] ──→ [Reduce 1] ──→ [Part 1]
│   [Split 3] ──→ [Map 3] ──┘                   └──→ [Reduce 2] ──→ [Part 2]
```

## Input and Output

### InputFormat

Defines how to read input data:

| Format | Description |
|--------|-------------|
| TextInputFormat | Line-by-line text files |
| KeyValueTextInputFormat | Tab-separated key-value |
| SequenceFileInputFormat | Binary key-value format |
| NLineInputFormat | N lines per split |

### OutputFormat

Defines how to write output:

| Format | Description |
|--------|-------------|
| TextOutputFormat | Tab-separated text |
| SequenceFileOutputFormat | Binary sequence file |
| MultipleOutputs | Multiple output files |

## Writing a Hadoop Job (Java)

```java
public class WordCount {

    public static class TokenizerMapper
            extends Mapper<LongWritable, Text, Text, IntWritable> {

        private final static IntWritable one = new IntWritable(1);
        private Text word = new Text();

        public void map(LongWritable key, Text value, Context context)
                throws IOException, InterruptedException {
            StringTokenizer itr = new StringTokenizer(value.toString());
            while (itr.hasMoreTokens()) {
                word.set(itr.nextToken());
                context.write(word, one);
            }
        }
    }

    public static class IntSumReducer
            extends Reducer<Text, IntWritable, Text, IntWritable> {

        public void reduce(Text key, Iterable<IntWritable> values, Context context)
                throws IOException, InterruptedException {
            int sum = 0;
            for (IntWritable val : values) {
                sum += val.get();
            }
            context.write(key, new IntWritable(sum));
        }
    }

    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "word count");

        job.setJarByClass(WordCount.class);
        job.setMapperClass(TokenizerMapper.class);
        job.setCombinerClass(IntSumReducer.class);
        job.setReducerClass(IntSumReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

## Hadoop Streaming

Run MapReduce with any language:

```bash
hadoop jar hadoop-streaming.jar \
    -input /input/path \
    -output /output/path \
    -mapper mapper.py \
    -reducer reducer.py
```

**Python Mapper**:
```python
#!/usr/bin/env python
import sys
for line in sys.stdin:
    for word in line.strip().split():
        print(f"{word}\t1")
```

**Python Reducer**:
```python
#!/usr/bin/env python
import sys
from collections import defaultdict

counts = defaultdict(int)
for line in sys.stdin:
    word, count = line.strip().split('\t')
    counts[word] += int(count)

for word, count in counts.items():
    print(f"{word}\t{count}")
```

## Hadoop Commands

```bash
# HDFS commands
hdfs dfs -ls /path              # List files
hdfs dfs -put local remote      # Upload file
hdfs dfs -get remote local      # Download file
hdfs dfs -cat /path/file        # View file
hdfs dfs -rm -r /path           # Delete

# Run MapReduce job
hadoop jar myapp.jar MainClass /input /output

# Check job status
mapred job -list
mapred job -status job_id
```

## Advantages and Limitations

### Advantages

| Advantage | Description |
|-----------|-------------|
| Scalability | Scales to thousands of nodes |
| Fault Tolerance | Automatic recovery from failures |
| Cost Effective | Runs on commodity hardware |
| Flexibility | Handles any data type |
| Ecosystem | Rich set of tools and integrations |

### Limitations

| Limitation | Description |
|------------|-------------|
| Batch Only | High latency, not real-time |
| Disk I/O | Heavy disk usage slows processing |
| Complexity | Steep learning curve |
| Java-centric | Streaming workaround for other languages |

<Callout type="info">
Many limitations of Hadoop MapReduce are addressed by Apache Spark, which provides in-memory processing and a more flexible programming model.
</Callout>
