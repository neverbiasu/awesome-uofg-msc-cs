## Summary

This week dives into the solution for processing big data: the MapReduce programming model and its open-source implementation, Apache Hadoop. It addresses core distributed computing challenges like fault tolerance and data locality.

<Accordions>
  <Accordion title="Distributed Challenges">
    How to handle partial failures, network latency, and synchronization issues when working with thousands of machines.
  </Accordion>
  <Accordion title="The MapReduce Model">
    A functional programming approach where data processing is split into a **Map** phase (filtering/sorting) and a **Reduce** phase (summary operation).
  </Accordion>
  <Accordion title="Apache Hadoop">
    The ecosystem comprising **HDFS** (storage) and **YARN** (resource management). How Hadoop implements MapReduce to process data where it resides (Data Locality).
  </Accordion>
</Accordions>
