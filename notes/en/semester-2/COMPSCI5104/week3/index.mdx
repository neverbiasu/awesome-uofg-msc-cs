## Overview
- Rhythm: Lecture + Lab
- Topics: Access Control Workflow, Digital Identity & Authentication, Authorization Models (DAC, RBAC, ABAC, MAC)

## Schedule (Sequential)
| Session | Topic | Description |
|---|---|---|
| Lecture 3 | Access Control | Fundamentals of access control, authentication mechanisms, and authorization models |
| Lab | OTP Implementation | Implementing Time-based One-Time Password (TOTP) using Python `pyotp` library |

## Learning Objectives
1. Understand the basic workflow of access control (Authentication vs. Authorization).
2. Master the lifecycle of digital identity and common authentication methods (Passwords, OTP, Biometrics, etc.).
3. Deeply understand and compare four mainstream authorization models: DAC, RBAC, ABAC, and MAC.
4. Be able to implement basic TOTP authentication using Python.
