# Course Overview
This course provides a systematic approach to software security. Students will learn how to identify threats, design secure architectures, and use automated tools to find and fix vulnerabilities throughout the development lifecycle.
<Accordions>
  <Accordion title="Assessment Information">
    - Threat Modeling Assignment
    - Security Analysis Lab
    - Final Exam
  </Accordion>
</Accordions>
