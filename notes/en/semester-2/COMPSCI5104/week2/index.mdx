## Overview

- **Rhythm**: Lecture + Tutorial (integrated into lecture)
- **Topics**: Vulnerabilities (OWASP Top 10), Threats, Countermeasures, Secured Software Development Lifecycle (SSDLC), Security Requirement Planning.

## Learning Objectives

- Identify common software vulnerabilities, such as those listed in the OWASP Top 10.
- Understand the relationship between vulnerabilities, threats, and countermeasures.
- Describe how security can be integrated into each phase of the Software Development Lifecycle (SDLC).
- Explain the process of gathering and analyzing security requirements for a system.
