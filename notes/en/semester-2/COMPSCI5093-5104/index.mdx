# COMPSCI 5093/5104: Secured Software Engineering

This course covers the principles and practices of secure software engineering, including security risk analysis, secure development lifecycle, and building software systems that are resilient to attacks.

<Accordions>
  <Accordion title="Course Information">
    **Learning Objectives:**
    1. Understand security risks in software development
    2. Apply secure coding practices
    3. Implement security throughout the software development lifecycle
    4. Analyze and mitigate security vulnerabilities
    5. Design and build secure software systems
  </Accordion>
  <Accordion title="Course Structure & Assessment">
    **Course Structure:**
    - Lectures: Security concepts and best practices
    - Labs: Hands-on security implementation
    - Assignments: Practical security tasks

    **Assessment:**
    - Coursework
    - Final exam
  </Accordion>
</Accordions>
