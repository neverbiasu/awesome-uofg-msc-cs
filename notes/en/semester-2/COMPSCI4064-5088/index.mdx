# COMPSCI 4064/5088: Big Data

This course introduces core big data concepts and technologies, covering the complete knowledge system from hardware fundamentals to distributed computing frameworks, with a focus on mainstream big data processing tools like Hadoop and Spark.

<Accordions>
  <Accordion title="Course Information">
    **Learning Objectives:**
    1. Understand the definition and characteristics of big data
    2. Master hardware fundamentals and scaling strategies
    3. Learn the MapReduce programming model
    4. Proficiently use Hadoop and Spark frameworks
    5. Understand the difference between batch and stream processing
  </Accordion>
  <Accordion title="Course Structure & Assessment">
    **Course Structure:**
    - Video lectures: Theoretical knowledge
    - Labs: Big data tools practice
    - Assignments: Programming exercises

    **Assessment:**
    - Coursework assignments
    - Final exam
  </Accordion>
</Accordions>
