## Exam Structure
- **Duration:** 2 hours (+30 mins additional time)
- **Format:** Open book, online, timed exam.
- **Total Marks:** 60
- **Number of Questions:** 4 (Answer all)

## Question Breakdown

### Question 1: Linear Algebra & kNN
- **Topics:** k-Nearest Neighbors, Covariance, PCA, and SVD.
- **Key Concepts:**
    - Calculating Euclidean distance (L2 Norm).
    - Predicting a class using the kNN algorithm.
    - Calculating a covariance matrix, eigenvectors, and eigenvalues using `numpy`.
    - Performing dimensionality reduction by projecting data onto the principal component.
    - Manually calculating the Singular Value Decomposition (SVD) for a simple matrix.
    - Relationship between determinant, matrix inversion, and non-singular matrices.

### Question 2: Probabilities
- **Topics:** Empirical and parametric distribution modeling.
- **Key Concepts:**
    - Using an empirical distribution (histogram/kernel density) to estimate a probability distribution.
    - Modeling data with a normal distribution and estimating its parameters.
    - Identifying the limitations of a simple model (e.g., a single Gaussian for bimodal data).
    - Proposing a more suitable model (e.g., a Gaussian Mixture Model), explaining its parameterization and fitting process.

### Question 3: Optimisation
- **Topics:** Linear and non-linear modeling, and constrained optimisation.
- **Key Concepts:**
    - Formulating a real-world problem (predicting ratings) as a linear least-squares problem, defining the variables and their dimensions.
    - Identifying potential reasons why a linear model might be unsuitable.
    - Formulating a more complex, non-linear model (e.g., based on bell-shaped functions).
    - Counting the number of parameters in the non-linear model.
    - Setting up a constrained optimisation problem to find an optimal solution under given constraints (e.g., daily airtime, minimum advertisement time).

### Question 4: Databases
- **Topics:** File organisation, storage costs, and join strategies.
- **Key Concepts:**
    - Computing the blocking factor and the number of blocks required for a relation.
    - Choosing the best file organisation (e.g., heap, sequential) based on operational requirements (insertion vs. read frequency).
    - Describing an efficient strategy for a 3-way join and estimating its total I/O cost.
    - Comparing the performance of Naive Nested Loop Join vs. Index-based Nested-Loop Join.
