## Exam Structure
- **Duration:** 2 hours
- **Format:** Open book, online, timed exam.
- **Total Marks:** 80
- **Number of Questions:** 4 (Answer all)

## Question Breakdown

### Question 1: Linear Algebra
- **Topics:** Graph theory, matrix operations, and Singular Value Decomposition (SVD).
- **Key Concepts:**
    - Constructing an adjacency matrix from a directed graph.
    - Calculating state transitions using the adjacency matrix.
    - Theoretical calculation of past states (matrix inversion).
    - Transforming a directed graph's adjacency matrix to an undirected one.
    - Defining and calculating the steady state of a system.
    - Interpreting SVD components (singular values).
    - Calculating the pseudo-inverse from an SVD decomposition.

### Question 2: Optimisation
- **Topics:** Linear least squares and constrained optimisation.
- **Key Concepts:**
    - Solving least squares problems using the normal equations method.
    - Performing iterations of gradient descent with a given step size.
    - Discussing the advantages of Stochastic Gradient Descent (SGD) for large datasets.
    - Applying the Lagrange multiplier method to solve a constrained optimisation problem.

### Question 3: Probabilities
- **Topics:** Parameter estimation, model selection, and conditional probability.
- **Key Concepts:**
    - Parametrising a normal distribution for a given dataset (e.g., gaze locations).
    - Estimating distribution parameters from data.
    - Identifying when a given model (e.g., a single normal distribution) is inappropriate.
    - Proposing and parametrising an alternative model (e.g., a Gaussian Mixture Model).
    - Estimating parameters for the alternative model.
    - Using recorded outcomes to estimate conditional probabilities (e.g., likelihood of an action given a gaze location).

### Question 4: Databases
- **Topics:** I/O costs, indexing, and modern database choices.
- **Key Concepts:**
    - Calculating storage blocks required for relations based on record and block sizes.
    - Estimating selection cardinality for a join operation.
    - Explaining the role of selectivity in query optimisation.
    - Justifying the choice of a database type (e.g., vector database) for a specific use case like music recommendation with high-dimensional feature vectors.
    - Describing storage and indexing strategies for efficient retrieval in the chosen database.
