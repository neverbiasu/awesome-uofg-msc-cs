## Exam Structure
- **Duration:** 2 hours (+30 mins additional time)
- **Format:** Open book, online, timed exam.
- **Total Marks:** 60
- **Number of Questions:** 3 (Answer all)

## Question Breakdown

### Question 1: Computational Linear Algebra and Optimisation
- **Topics:** Vector space models, distance/similarity, PCA, and stochastic gradient descent.
- **Key Concepts:**
    - Representing documents as vectors (e.g., bag-of-words).
    - Understanding L0 and Lp norms in the context of document vectors.
    - Choosing appropriate distance or similarity measures (e.g., Cosine Similarity) for document comparison and justifying the choice.
    - Interpreting contour plots of Gaussian distributions in relation to their covariance matrices.
    - Visually determining if PCA can effectively reduce dimensionality.
    - Deriving the expression for stochastic gradient descent for linear regression.
    - Explaining how to extend linear regression to polynomial regression and the problem of overfitting.
    - Understanding how variable learning rates work in SGD.

### Question 2: Probabilities & Bayes' Rule
- **Topics:** Basic probability, conditional probability, and expected value.
- **Key Concepts:**
    - Calculating simple probabilities of drawing cards from a deck.
    - Calculating conditional probabilities for sequential events without replacement.
    - Calculating the expected value of a payout based on the probabilities of different outcomes.
    - Using expected value to make decisions (e.g., whether to fold or draw in a card game).

### Question 3: Database Systems
- **Topics:** Storage costs and query processing.
- **Key Concepts:**
    - Computing blocking factors and the number of blocks required to store relations.
    - Explaining and estimating the I/O cost of a query processing algorithm (e.g., nested loop join).
    - Considering the impact of file organisation (Heap vs. Sequential) on query cost.
    - Comparing the efficiency of different join orders.
