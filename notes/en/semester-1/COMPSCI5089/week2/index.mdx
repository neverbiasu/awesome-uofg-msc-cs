## Overview
- Format: Lecture
- Themes: Linear Systems, Inversion, Matrix Decompositions

## Learning Objectives
1. Understand how to model discrete problems using continuous mathematics (matrices).
2. Learn how to represent graphs as matrices and perform flow analysis.
3. Understand the concepts of eigenvalues and eigenvectors and their applications.
4. Learn about matrix decompositions like SVD and their use in data analysis.

## Key Knowledge Points
- **Graph Representation**: Adjacency matrices, edge-weighted graphs.
- **Matrix Operations**: Matrix powers, inversion, and their geometric interpretations.
- **Eigen-analysis**: Eigenvectors, eigenvalues, and the power iteration method.
- **Matrix Decompositions**: Singular Value Decomposition (SVD) and its applications in dimensionality reduction and approximation.

## Practice Checklist
- [ ] Represent a simple graph as an adjacency matrix.
- [ ] Calculate matrix powers to simulate changes in a system over time.
- [ ] Use `numpy.linalg.eig` to find the eigenvalues and eigenvectors of a matrix.
- [ ] Perform SVD on a matrix and understand the resulting components.
