## Overview
- **Goal**: To understand the definition, properties, and basic operations of vectors and matrices, and how to create them in NumPy.
- **Scope**: This note covers vector/matrix definitions, addition, scalar multiplication, norms, dot product, transposition, and NumPy implementation.

## Core Concepts in NumPy

### Vectors in NumPy
- In NumPy, vectors are represented as 1D arrays.

```python
import numpy as np

# Create a vector from a list
v = np.array([1, 2, 3])

# Check its shape (will be (3,))
print(v.shape)
```

### Matrices in NumPy
- Matrices are represented as 2D arrays.

```python
import numpy as np

# Create a 2x3 matrix from a list of lists
M = np.array([[1, 2, 3], [4, 5, 6]])

# Check its shape (will be (2, 3))
print(M.shape)
```

### Creating Special Matrices
- NumPy provides convenient functions to create common types of matrices.

```python
# A 3x3 matrix of all zeros
zeros = np.zeros((3, 3))

# A 2x4 matrix of all ones
ones = np.ones((2, 4))

# A 3x3 identity matrix (1s on the diagonal, 0s elsewhere)
eye = np.eye(3)
```

## Vector Properties and Operations

### Vector Addition
- Two vectors of the same dimension can be added by adding their corresponding components.
- If $$v = [v_1, v_2]$$ and $$w = [w_1, w_2]$$, then $$v + w = [v_1 + w_1, v_2 + w_2]$$.

### Scalar Multiplication
- Multiplying a vector by a scalar involves multiplying each component of the vector by that scalar.
- If $$a$$ is a scalar and $$v = [v_1, v_2]$$, then $$a * v = [a * v_1, a * v_2]$$.

### Vector Norms (Magnitude)
- A norm is a function that assigns a strictly positive length or size to each vector in a vector space.
- **L1 Norm (Manhattan Distance)**: The sum of the absolute values of the components.
  - $$\parallel v \parallel_1 = \sum_i |v_i|$$
- **L2 Norm (Euclidean Distance)**: The square root of the sum of the squared components. This is the most common way to measure vector length.
  - $$\parallel v \parallel_2 = \sqrt{\sum_i v_i^2}$$
- **L-infinity Norm**: The largest absolute value among the components of the vector.
  - $$\parallel v \parallel_\infty = \max_i |v_i|$$

### Dot Product
- The dot product of two vectors is a scalar value that measures their geometric relationship.
- $$v \cdot w = \sum_i (v_i * w_i)$$
- **Orthogonality**: If the dot product of two non-zero vectors is zero, they are **orthogonal** (perpendicular) to each other.
  - $$v \cdot w = 0$$

## Matrix Properties and Operations

### Matrix Addition
- Two matrices of the same dimensions can be added by adding their corresponding elements.
- If $$C = A + B$$, then $$C_{ij} = A_{ij} + B_{ij}$$.

### Scalar Multiplication
- Multiplying a matrix by a scalar involves multiplying every element of the matrix by that scalar.
- If $$C = sA$$, then $$C_{ij} = s * A_{ij}$$.

### Matrix Transposition
- The **transpose** of a matrix, denoted $$A^T$$, is formed by turning its rows into columns and its columns into rows.
- If $$B = A^T$$, then $$B_{ij} = A_{ji}$$.

### Matrix-Vector Multiplication
- A matrix can be multiplied by a vector to produce a new vector. This represents applying a linear transformation to a point in space.
- If $$\mathbf{y} = A\mathbf{x}$$, the $$i$$-th element of $$\mathbf{y}$$ is the dot product of the $$i$$-th row of $$A$$ with the vector $$\mathbf{x}$$.
