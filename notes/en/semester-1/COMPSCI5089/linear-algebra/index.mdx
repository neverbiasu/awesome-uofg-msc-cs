## Overview
This unit covers the foundational concepts of linear algebra essential for data science and machine learning.
- **Format**: Lecture
- **Topics**: Vectors, Matrices, Computational Linear Algebra

## Learning Schedule
| Type      | Title                        | Description                                      |
| - |  |
| Lecture   | Vectors and Matrices         | Foundational concepts, operations, and properties. |
| Lecture   | Computational Linear Algebra | Advanced applications and matrix decompositions. |

## Learning Objectives
1. Understand the definitions and basic operations of vectors and matrices.
2. Learn how to calculate dot products and perform matrix multiplication.
3. Grasp the concept of solving systems of linear equations and the role of computational tools like NumPy.

## Key Knowledge Points
- **Vectors and Matrices**: Foundational definitions, basic operations (addition, scalar multiplication), norms, dot product, and transposition.
- **Computational Linear Algebra**: Solving linear systems, matrix decompositions (Eigen, SVD), and applications like PCA.

## Practice Checklist
- [ ] Perform vector addition and dot product calculations by hand.
- [ ] Execute matrix multiplication and find the transpose of a matrix.
- [ ] Use `np.linalg.solve` in a Python script to solve a simple system of linear equations.

## Assessment Reminders
- The concepts in this unit are foundational for understanding many machine learning algorithms.
