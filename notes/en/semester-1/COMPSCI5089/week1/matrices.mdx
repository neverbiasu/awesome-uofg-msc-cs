## Overview

Matrices are 2D arrays of numbers that serve as fundamental tools in linear algebra and data science. They can represent data, systems of equations, or, most importantly, **linear maps** that transform vectors from one space to another. This page covers the definition of matrices, their basic operations, and their role as operators that can scale, rotate, and shear vector spaces.

## What is a Matrix?

A matrix is a rectangular grid of numbers arranged in rows and columns. An $$n \times m$$ matrix has *n* rows and *m* columns.

<Callout title="Notation">
- Matrices are typically denoted by a bold uppercase letter, e.g., **A**.
- The element in the *i*-th row and *j*-th column of matrix **A** is written as $$A_{i,j}$$.
- The set of all $$n \times m$$ real-valued matrices is denoted by $$R^{n \times m}$$.
</Callout>

## Basic Matrix Operations

### Addition and Subtraction
Two matrices of the **same size** can be added or subtracted by performing the operation element-wise.

```math
(A+B)_{i,j} = A_{i,j} + B_{i,j}
```

### Scalar Multiplication
A matrix can be multiplied by a scalar, which involves multiplying every element of the matrix by that scalar.

```math
(cA)_{i,j} = c \cdot A_{i,j}
```

### Matrix-Vector Multiplication
Applying a matrix **A** to a vector **x** (written as **Ax**) transforms the vector. This is a weighted sum of the columns of the matrix, where the weights are the elements of the vector.

If **A** is an $$n \times m$$ matrix and **x** is an *m*-dimensional vector, the result **y** is an *n*-dimensional vector.

```math
 y = Ax
```

### Matrix-Matrix Multiplication
Multiplying two matrices, **C = AB**, represents the **composition** of two linear maps. If **A** is $$p \times q$$ and **B** is $$q \times r$$, the resulting matrix **C** will be $$p \times r$$.

<Callout title="Order Matters!">
Matrix multiplication is **not commutative**, meaning in most cases:
$$ AB \neq BA $$
The order of operations corresponds to reading from right to left. For example, in **BAx**, the transformation **A** is applied to **x** first, and then **B** is applied to the result.
</Callout>

### Transposition
The **transpose** of a matrix **A**, denoted $$A^T$$, is formed by swapping its rows and columns. If **A** is $$n \times m$$, then $$A^T$$ is $$m \times n$$.

```python
import numpy as np

A = np.array([[1, 2, 3], [4, 5, 6]])
# A is a 2x3 matrix

# A.T is the 3x2 transpose
print(A.T)
```

## Matrices as Linear Maps

The most powerful interpretation of matrices is as **linear maps** (or linear transforms). A map is linear if it satisfies two properties:
1.  **Additivity**: $$f(x+y) = f(x) + f(y)$$
2.  **Homogeneity**: $$f(cx) = c \cdot f(x)$$

All matrix transformations are linear maps. They can represent operations like scaling, rotation, and shearing, but not translation (as translation doesn't preserve the origin).

## Special Types of Matrices

| Type | Description |
|---|---|
| **Identity Matrix (I)** | A square matrix with 1s on the diagonal and 0s elsewhere. It's the matrix equivalent of the number 1 (i.e., $$AI = IA = A$$). |
| **Zero Matrix** | A matrix with all elements equal to 0. |
| **Diagonal Matrix** | A matrix where only the diagonal elements can be non-zero. Represents scaling along axes. |
| **Symmetric Matrix** | A square matrix that is equal to its transpose ($$A = A^T$$). Covariance matrices are symmetric. |
| **Orthogonal Matrix** | A square matrix whose transpose is also its inverse ($$A^T = A^{-1}$$). Represents a pure rotation. |

## Matrix Properties

- **Determinant (det(A))**: A scalar value that represents how much the matrix expands or contracts space. If `det(A) = 0`, the matrix is **singular**, meaning it collapses at least one dimension and is non-invertible.
- **Trace (Tr(A))**: The sum of the diagonal elements of a square matrix. For a covariance matrix, the trace equals the total variance in the data.
- **Rank**: The number of non-zero singular values of a matrix, which corresponds to the number of linearly independent columns or rows. It tells you the dimension of the output space.

## Matrix Inversion and Decomposition

- **Inversion**: The inverse of a square matrix **A**, denoted $$A^{-1}$$, "undoes" the operation of **A**. It only exists if the matrix is non-singular (i.e., `det(A) \neq 0`).
- **Eigendecomposition**: Factorizes a square matrix into its eigenvalues and eigenvectors. This reveals the matrix's fundamental properties, such as its principal directions of action.
- **Singular Value Decomposition (SVD)**: A more general factorization that applies to *any* matrix (not just square ones). It is a cornerstone of computational linear algebra, used in PCA, noise reduction, and more.

## Key Takeaways
- Matrices are 2D arrays that represent linear transformations on vectors.
- Basic operations include addition, scalar multiplication, and matrix multiplication, where order is critical.
- The transpose ($$A^T$$) swaps the rows and columns of a matrix.
- Special matrices like the Identity, Diagonal, and Symmetric matrices have important properties and uses.
- The **determinant** and **trace** are important scalar properties of a square matrix.
- **Matrix decomposition** (like Eigendecomposition and SVD) is a powerful technique for analyzing matrices and is central to many data science algorithms like PCA.
