## Overview
This is the first official week of the COMPSCI5089 course. The core topic is the fundamentals of **Linear Algebra**, focusing on **Vectors** and **Matrices**. There are no lab sessions this week; the main goal is to grasp the core concepts through lectures and self-study materials to build a mathematical foundation for subsequent machine learning and data analysis tasks.

## This Week's Schedule
| Session | Topic | Description |
|---|---|---|
| Lecture 1 | Vectors and Matrices | Course introduction and a review of the basic definitions, operations, and geometric interpretations of vectors and matrices. |

## Learning Objectives
1.  **Understand** the basic concepts of vectors and matrices, including their definitions, notations, and special types.
2.  **Master** basic vector and matrix operations, such as addition, scalar multiplication, dot product, and matrix multiplication.
3.  **Be able to** explain the geometric meaning of vectors, such as norm (length) and direction.
4.  **Be aware of** the application scenarios of linear algebra in data science.

## Key Concepts
- **Vector Basics**:
  - Vector definition, row vs. column vector notation
  - Vector addition, subtraction, and scalar multiplication
  - Dot product (inner product) and its geometric interpretation
  - Vector norms (L1, L2) and unit vectors
- **Matrix Basics**:
  - Matrix definition, dimensions, and notation
  - Matrix addition, subtraction, and scalar multiplication
  - Matrix-vector and matrix-matrix multiplication
  - Special matrices: zero matrix, identity matrix, transpose matrix

## Practice Checklist (Self-assessment)
- [ ] Complete vector addition, subtraction, and dot product exercises.
- [ ] Calculate the L1 and L2 norms of a given vector.
- [ ] Manually perform the multiplication of two 2x2 matrices.
- [ ] Read and run the code examples in the lecture Jupyter Notebook.
- [ ] Think about how to represent a simple dataset (e.g., a student grade sheet) using vectors and matrices.
