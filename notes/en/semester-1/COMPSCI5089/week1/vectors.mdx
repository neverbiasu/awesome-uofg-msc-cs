## Overview

Vectors are a fundamental concept in linear algebra and serve as the *lingua franca* for data in machine learning and data science. They provide a mathematical structure to represent, compare, and manipulate data points. This page covers the core concepts of vectors, including their definition, standard operations (addition, scalar multiplication), methods for measuring their size (norms), and their geometric properties (inner product).

## What is a Vector?

A vector can be thought of in several ways:
- **As a tuple of numbers:** An ordered list of real numbers, like $$[x_1, x_2, ..., x_n]$$.
- **As a point in space:** A location in a coordinate system. For example, a vector $$[5, 7]$$ represents a point in a 2D plane.
- **As an arrow from the origin:** A direction and a magnitude in space.

In the context of data science, the "points in space" model is often the most useful, as it allows us to think of our data as existing within a geometric space.

<Callout title="Notation">
- Vectors are typically denoted by a bold lowercase letter, e.g., **x**.
- The set of all n-dimensional real-valued vectors is denoted by $$R^n$$.
</Callout>

## Basic Vector Operations

A **vector space** is a collection of vectors where two primary operations are defined: vector addition and scalar multiplication.

### Vector Addition
Vectors of the same dimension can be added by adding their corresponding elements (element-wise sum).

```math
x + y = [x_1 + y_1, x_2 + y_2, ..., x_n + y_n]
```

### Scalar Multiplication
A vector can be multiplied by a scalar (a single real number), which scales the vector by that amount. This is also an element-wise operation.

```math
ax = [ax_1, ax_2, ..., ax_n]
```

### Code Example: Basic Operations in NumPy

```python
import numpy as np

# Define two vectors
x = np.array([0, 1, 1])
y = np.array([4, 5, 6])
a = 2

# Addition
print(f"x + y = {x + y}")

# Scalar Multiplication
print(f"a * x = {a * x}")
```

## Measuring Vectors: Norms

A **norm** is a function that assigns a strictly positive length or size to each vector in a vector space. It allows us to measure the "bigness" of a vector.

### L2 Norm (Euclidean Norm)
The most common norm is the L2 norm, also known as the Euclidean length of a vector. It corresponds to the intuitive length of the vector in space.

```math
||x||_2 = \sqrt{x_1^2 + x_2^2 + ... + x_n^2}
```

In NumPy, this can be computed directly using `np.linalg.norm()`.

```python
x = np.array([1.0, 10.0, -5.0])
# ||x|| = 11.22
print(f"L2 norm of x: {np.linalg.norm(x)}")
```

### Other Norms (Lp-norms)
The concept of a norm can be generalized to Lp-norms (or Minkowski norms), which are defined by:

```math
||x||_p = (\sum_{i=1}^{n} |x_i|^p)^{1/p}
```

| p | Notation | Common Name | Use Case |
|---|---|---|---|
| 2 | $$||x||_2$$ | Euclidean Norm | Standard spatial distance. |
| 1 | $$||x||_1$$ | Manhattan Norm | Measures distance on a grid (e.g., city blocks). |
| ∞ | $$||x||_\infty$$ | Max Norm | Captures the maximum element in the vector. |
| 0 | $$||x||_0$$ | "Zero Norm" | Counts the number of non-zero elements. |


### Unit Vectors and Normalization
A **unit vector** is a vector with a norm of 1. It represents a "pure direction". Any vector can be normalized to a unit vector by dividing it by its norm.

<Callout title="Normalization Formula">
To normalize a vector **x** using the Euclidean norm, you scale it by the inverse of its length:
$$
\hat{x} = \frac{x}{||x||_2}
$$
</Callout>

## The Geometry of Vectors: Inner Product

The **inner product** (or dot product) of two vectors determines the angle between them and is a fundamental operation for understanding their geometric relationship.

```math
x \cdot y = \sum_{i=1}^{n} x_i y_i
```

The inner product is related to the **cosine distance**, which measures the angle $$ \theta $$ between two vectors:

```math
\cos(\theta) = \frac{x \cdot y}{||x|| \cdot ||y||}
```
For unit vectors, this simplifies to $$ \cos(\theta) = x \cdot y $$. An inner product of 0 implies the vectors are **orthogonal** (at a 90-degree angle).

<Callout title="Warning: np.inner() vs np.dot()">
In NumPy, for 1-D arrays (vectors), `np.inner(a, b)` and `np.dot(a, b)` compute the same inner product. However, for 2-D arrays (matrices), their behaviors diverge significantly. For matrix multiplication, it is safer and clearer to use the `@` operator or `np.matmul()`.
</Callout>

## Vectors in Data Science

- **Data Representation**: Datasets are commonly stored as 2D tables, where each **row** can be seen as a feature vector representing a single observation.
- **Centering Data**: A common preprocessing step is to "center" a dataset by calculating the **mean vector** (the element-wise mean of all row vectors) and subtracting it from every vector. This gives the dataset a zero mean.
- **Curse of Dimensionality**: While vectors are powerful, algorithms that work well in low dimensions (e.g., d=2 or d=3) often break down in high-dimensional spaces. As dimensions increase, the volume of the space grows exponentially, causing data to become sparse. This makes tasks like finding nearest neighbors much harder.

## Key Takeaways
- Vectors are ordered lists of numbers that can represent points in space, data, or features.
- A vector space defines rules for **vector addition** and **scalar multiplication**.
- **Norms** (like L1 and L2) measure the length or magnitude of a vector.
- The **inner product** (dot product) measures the angle between two vectors and is fundamental to concepts like orthogonality and projection.
- In data science, vectors are used to represent data points, and operations like **centering** are common preprocessing steps.
- Be aware of the **curse of dimensionality**, where high-dimensional spaces have counter-intuitive properties that can make analysis difficult.
