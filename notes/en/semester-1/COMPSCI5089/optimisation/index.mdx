## Overview
This unit introduces the core principles of optimisation, a key process in training machine learning models.
- **Format**: Lecture
- **Topics**: Optimisation Fundamentals, Gradient-Based Algorithms

## Learning Schedule
| Type      | Title                     | Description                                       |
| --------- | ------------------------- | ------------------------------------------------- |
| Lecture   | Optimisation I            | Formulating problems with objective functions.    |
| Lecture   | Optimisation II           | Solving problems using gradient descent.          |

## Learning Objectives
1. Understand how to formulate an optimisation problem by defining objective functions and parameters.
2. Differentiate between key types of optimisation problems (e.g., convex vs. non-convex).
3. Grasp the core concepts of gradient descent and the role of the learning rate.

## Key Knowledge Points
- **Problem Formulation**: The roles of objective functions, parameters, and constraints in defining a problem.
- **Problem Types**: Key differences between convex and non-convex optimisation, and between constrained and unconstrained problems.
- **Gradient Descent**: The concept of using the gradient to iteratively find a minimum, the importance of the learning rate, and the distinction between local and global minima.

## Practice Checklist
- [ ] Formulate a simple real-world scenario (e.g., finding the best price for a product) as an optimisation problem.
- [ ] For a simple function like `f(x) = x^2`, manually calculate the next step in gradient descent from a starting point.
- [ ] Explain the potential consequences of setting a learning rate that is too high or too low.

## Assessment Reminders
- Understanding optimisation is critical, as it forms the basis for training almost all modern machine learning models.
