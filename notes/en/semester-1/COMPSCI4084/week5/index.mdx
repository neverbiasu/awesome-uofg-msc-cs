## Overview
- **Pace**: This week focuses on hands-on learning through lab exercises, emphasizing practical application of Unix commands and shell scripting.
- **Themes**: Unix Command Line Fundamentals, Text File Processing, User & Permissions Management, Processes & Jobs, Git Version Control, LaTeX Document Processing, Shell Scripting.

## Learning Objectives
1. Master essential Unix command-line tools for text processing, file management, and system monitoring.
2. Understand and apply principles of user and file permissions for system security.
3. Be able to control and manage processes and jobs effectively.
4. Gain proficiency in using Git for both local version control and remote collaboration.
5. Learn the basics of LaTeX for professional document preparation.
6. Develop foundational skills in shell scripting for task automation.

## Key Knowledge Points
- **文本处理与分析**：
  - `grep`：模式搜索，日志过滤。
  - `sort` & `uniq`：数据聚合，识别重复项。
  - `wc`：统计行、词、字符。
  - `tr`：字符转换与删除。
  - `sed`：流编辑器，文本替换与编辑。
  - `curl`：网络数据传输，侦察与测试。
- **系统管理与安全**：
  - 用户与权限：`whoami`, `id`, `sudo`, `passwd`, `chmod`, `chown`, `usermod`。
  - 进程与作业：`ps`, `top`, `kill`, `jobs`, `fg`, `bg`。
  - 系统监控：`df`, `uptime`。
  - 编译器警告：`-Wall`, `-Wextra`, `-Werror` 在安全编码中的作用。
- **版本控制**：
  - Git 基础：`init`, `status`, `add`, `commit`, `log`, `diff`。
  - Git 远程协作：SSH 密钥设置, `clone`, `push`, `pull`, 合并冲突。
- **文档处理**：
  - LaTeX 基础：安装, 文档结构, 文本/数学排版, Makefile 自动化编译。
- **Shell 脚本编程**：
  - 脚本创建与执行。
  - 用户输入与命令行参数。

## Practice Checklist
- [ ] Practice `grep` to filter logs for specific patterns.
- [ ] Use `sort` and `uniq -c` to identify frequent entries in a log file.
- [ ] Change file permissions using `chmod` and `chown`.
- [ ] Monitor system processes with `ps` and `top`, and terminate processes with `kill`.
- [ ] Initialize a Git repository, make commits, and view history.
- [ ] Set up SSH keys for GitHub and practice `git clone`, `push`, `pull`.
- [ ] Create a simple LaTeX document and compile it to PDF.
- [ ] Write a basic shell script that takes user input or command-line arguments.
