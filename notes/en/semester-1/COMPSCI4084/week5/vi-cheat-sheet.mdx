## Overview
- **Objective**: This note provides a concise and handy reference for essential commands in the `vi` editor, a powerful and ubiquitous text editor in Unix-like systems. It aims to help users quickly recall and apply `vi` commands to enhance their text editing efficiency.
- **Scope**: Covers fundamental `vi` operations such as cursor movement, text insertion, deletion, replacement, copying, pasting, searching for patterns, repeating commands, and saving/quitting files. It also includes basic help and find/replace functionalities.

## Learning Objectives
1. Master basic `vi` editor navigation commands for efficient cursor movement.
2. Be able to insert, delete, and replace text effectively within `vi`.
3. Learn to perform text searches and copy/paste operations using `vi` commands.
4. Familiarize with `vi`'s commands for saving changes and quitting the editor.
5. Understand how to use `vi`'s help and find/replace features.

## Key Knowledge Points

### 1. Movement Commands
- **Motivation**: Efficient navigation is key to productive text editing in `vi`. These commands allow you to move the cursor precisely without using a mouse.
- **Core Concepts**:
  - `h`: Move cursor left.
  - `j`: Move cursor down.
  - `k`: Move cursor up.
  - `l`: Move cursor right.
  - `^`: Go to the beginning of the line.
  - `$`: Go to the end of the line.
  - `gg`: Go to the first line of the document.
  - `G`: Go to the last line of the document.
  - `:n`: Go to line `n`.
- **Example**:
```bash
# Example: Moving to the 10th line in vi
# Description: Opens a file in vi and moves the cursor to the 10th line.
vi myfile.txt
:10
```
- **Summary**: `vi` movement commands enable precise and rapid cursor positioning within a document.

### 2. Inserting and Deleting Text
- **Motivation**: The ability to quickly add and remove text is fundamental to any editor. `vi` provides various commands for inserting text at different positions and deleting characters, words, or lines.
- **Core Concepts**:
  - **Inserting Text**:
    - `i`: Insert text at the current cursor position.
    - `I`: Insert text at the beginning of the current line.
    - `a`: Append text after the current cursor position.
    - `A`: Append text at the end of the current line.
    - `o`: Open a new line below the current line and insert text.
    - `O`: Open a new line above the current line and insert text.
  - **Deleting Text**:
    - `x`: Delete character under the cursor.
    - `dd`: Delete the current line.
    - `dw`: Delete the current word.
    - `d{motion}`: Delete from cursor to `{motion}` (e.g., `d$` deletes to end of line).
- **Example**:
```bash
# Example: Inserting and deleting text in vi
# Description: Opens a file, inserts text at the end of a line, and then deletes a word.
vi myfile.txt
A This is new text. # Append text at end of line
# (Press Esc to exit insert mode)
dw # Delete a word
```
- **Summary**: `vi` offers flexible commands for inserting and deleting text, allowing for efficient content modification.

### 3. Replacing, Copying, and Pasting Text
- **Motivation**: Modifying existing text, duplicating content, and moving it around are common editing tasks. `vi` provides powerful commands for these operations.
- **Core Concepts**:
  - **Replacing Text**:
    - `r`: Replace a single character under the cursor.
    - `cw`: Change (replace) the current word.
    - `cc`: Change (replace) the current line.
    - `c{motion}`: Change from cursor to `{motion}`.
  - **Copy/Paste**:
    - `y{motion}`: Yank (copy) text from cursor to `{motion}`.
    - `yy`: Yank (copy) the current line.
    - `p`: Paste text after the cursor.
    - `P`: Paste text before the cursor.
- **Example**:
```bash
# Example: Copying and pasting a line in vi
# Description: Opens a file, copies the current line, and pastes it below.
vi myfile.txt
yy # Yank (copy) the current line
p # Paste the copied line below the current line
```
- **Summary**: `vi`'s commands for replacing, copying, and pasting text enable rapid content manipulation and reorganization.

### 4. Searching and Repeating Commands
- **Motivation**: Quickly finding specific text and repeating previous actions significantly speeds up editing. `vi` has robust search capabilities and a simple mechanism for repeating commands.
- **Core Concepts**:
  - **Searching**:
    - `/{pattern}`: Forward search for `{pattern}`.
    - `?{pattern}`: Reverse search for `{pattern}`.
    - `n`: Repeat the last search in the same direction.
    - `N`: Repeat the last search in the opposite direction.
  - **Repeating Commands**:
    - `{num}{command}`: Repeat `command` `{num}` times (e.g., `5dd` deletes 5 lines).
    - `.`: Repeat the previous change (e.g., the last insert or delete operation).
- **Example**:
```bash
# Example: Searching for a word and repeating a command in vi
# Description: Opens a file, searches for "error", and then deletes the next 3 lines.
vi myfile.txt
/error # Search for "error"
# (Cursor moves to the first occurrence)
3dd # Delete the next 3 lines
```
- **Summary**: `vi`'s search and repeat functionalities allow for quick navigation to relevant text and efficient execution of repetitive editing tasks.

### 5. Saving, Quitting, and Help
- **Motivation**: Knowing how to properly save your work, exit the editor, and access help is essential for any `vi` user.
- **Core Concepts**:
  - **Save and Quit**:
    - `:w`: Write (save) changes to the file.
    - `:wq`: Write and quit.
    - `:q`: Quit (only if no changes have been made).
    - `:q!`: Force quit, discarding unsaved changes.
    - `:wq!`: Force write and quit (overrides read-only status).
  - **Help**:
    - `:help [topic/command]`: Get help on a specific topic or command.
    - `vimtutor`: An interactive tutorial for `vi`/`Vim`.
- **Example**:
```bash
# Example: Saving and quitting in vi
# Description: Saves changes to myfile.txt and then quits the editor.
vi myfile.txt
# (Make some edits)
:wq
```
- **Summary**: Essential commands for managing file state and accessing built-in help ensure a smooth `vi` editing experience.

---

### 6. Find and Replace (Substitution)
- **Motivation**: For more complex text transformations, `vi` (and `Vim`) offers powerful substitution commands, allowing you to find patterns and replace them with new text, either on a single line or throughout the entire document.
- **Core Concepts**:
  - `:s/{old}/{new}/{options}`: Substitute `{new}` for `{old}` on the current line.
  - `:%s/{old}/{new}/{options}`: Substitute `{new}` for `{old}` in the entire document.
  - `g` option: Substitutes all occurrences on a line; otherwise, only the first occurrence is changed per line.
- **Example**:
```bash
# Example: Replacing a word globally in vi
# Description: Replaces all occurrences of "error" with "warning" throughout the entire document.
vi myfile.txt
:%s/error/warning/g
```
- **Summary**: `vi`'s substitution commands provide advanced find and replace capabilities, crucial for refactoring and large-scale text modifications.

## Best Practices
- **Practice Regularly**: The best way to master `vi` is through consistent practice. Use `vimtutor` to get started.
- **Understand Modes**: Remember that `vi` operates in different modes (normal, insert, visual, command-line). Always know which mode you are in.
- **Use Command Chaining**: Combine movement and action commands (e.g., `d$` to delete to end of line) for efficiency.
- **Leverage Search**: Use `/` and `?` for quick navigation to specific text.
- **Save Frequently**: Use `:w` to save your work periodically.
