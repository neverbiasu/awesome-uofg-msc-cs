## Overview
- **Objective**: This note introduces LaTeX as a powerful and professional document preparation system, particularly suited for academic papers, technical reports, and dissertations. It aims to equip learners with the foundational knowledge to create structured and aesthetically pleasing documents.
- **Scope**: Covers the basics of LaTeX, including its installation (local and cloud-based via Overleaf), the minimal document structure, essential text formatting commands (fonts, sizes), document sectioning, and the robust capabilities for mathematical typesetting. It also touches upon automating compilation with Makefiles and practical exercises.

## Learning Objectives
1. Understand the fundamental workflow of LaTeX: writing source code, compiling, and viewing the PDF output.
2. Be able to set up a LaTeX environment, either locally or using the Overleaf cloud service.
3. Master the minimal structure required for a basic LaTeX document.
4. Apply various text formatting commands (e.g., bold, italic, font sizes) and structure documents with sections and cross-references.
5. Utilize LaTeX's powerful features for typesetting mathematical equations and symbols.
6. Automate the LaTeX compilation process using Makefiles.

## Key Knowledge Points

### 1. Introduction to LaTeX and Setup
- **Motivation**: LaTeX is a high-quality typesetting system widely used in academia and science for producing professional-looking documents. It separates content from presentation, allowing authors to focus on writing while LaTeX handles the layout and formatting. It's highly recommended for reports and dissertations.
- **Core Concepts**:
  - LaTeX is a markup language, similar to Markdown or HTML, where you write a script that specifies the document's structure and content.
  - This script is then compiled into a PDF to view the rendered document.
  - **Installation**: Local installations (e.g., `texlive-full` on Ubuntu, MacTeX on macOS) are multi-GB and time-consuming.
  - **Overleaf**: A cloud-based LaTeX service offering a convenient online editor and compiler. University subscriptions often provide free Pro features.
- **Usage Scenarios/Patterns**:
  - Writing academic papers, theses, and dissertations.
  - Creating technical reports, presentations, and books.
  - Collaborating on documents using Overleaf.
- **Example**:
```bash
# Example: Installing texlive-full on Ubuntu
# Description: Command to install the full TeX Live distribution on Ubuntu.
sudo apt update
sudo apt install texlive-full
```
- **Notes/Best Practices**:
  - For beginners or collaborative projects, Overleaf is often the easier and more efficient choice.
  - Local installations provide more control but require significant disk space and maintenance.
- **Summary**: LaTeX is a powerful tool for professional document creation, with both local and cloud-based setup options, making it ideal for academic and technical writing.

### 2. Basic Document Structure and Text Formatting
- **Motivation**: A well-structured document is easy to read and navigate. LaTeX provides simple commands to define document classes, sections, and apply various text styles, ensuring consistency and professionalism.
- **Core Concepts**:
  - **Minimal Scaffolding**:
    - `\documentclass{article}`: Defines the document type (e.g., `article`, `report`, `book`).
    - `\begin{document}` and `\end{document}`: Enclose the main content of the document.
  - **Text Formatting**:
    - `\textit{italic}`: Italic text.
    - `\textbf{bold}`: Bold text.
    - `\texttt{typewriter}`: Typewriter font.
    - `\textsf{sans-serif}`: Sans-serif font.
    - Font sizes: `{\tiny very small}` to `{\Huge very large}`.
  - **Document Structure**:
    - `\section{Introduction}`: Creates a new section.
    - `\label{sec:intro}`: Assigns a label to a section for cross-referencing.
    - `\ref{sec:intro}`: References a labeled section.
- **Usage Scenarios/Patterns**:
  - Creating a simple report with an introduction and other sections.
  - Emphasizing text with bold or italic fonts.
  - Referring to specific sections within the document.
- **Example**:
```latex
% Example: Basic LaTeX document with text formatting and sectioning
% Description: A simple LaTeX document demonstrating document class, text styles, and sectioning with cross-references.
\documentclass{article}
\begin{document}

In \LaTeX, you may use \textit{italic} and \textbf{bold} face fonts.
It is also possible to have \texttt{typewriter} and \textsf{sans-serif} fonts.
You may change the font size from {\tiny very small} to {\Huge very large}.

\section{Introduction}
\label{sec:intro}
Some intro text.

\section{Another Section}
\label{sec:nother}
Please refer back to Section \ref{sec:intro}.

\end{document}
```
- **Notes/Best Practices**:
  - Use logical sectioning to organize your document effectively.
  - Cross-referencing (`\label`, `\ref`) automatically updates page/section numbers, preventing manual errors.
  - Choose font styles judiciously for readability and emphasis.
- **Summary**: LaTeX provides robust commands for structuring and formatting text, enabling the creation of clear, organized, and professional documents.

### 3. Mathematical Typesetting
- **Motivation**: One of LaTeX's greatest strengths is its unparalleled ability to typeset complex mathematical equations and symbols beautifully and consistently, making it the standard for scientific and engineering documents.
- **Core Concepts**:
  - **Equation Environment**: `\begin{equation}` and `\end{equation}` for numbered, displayed equations.
  - **Mathematical Symbols**: Commands like `\lnot` (negation), `\land` (logical AND), `\equiv` (equivalence), `\lor` (logical OR), `\cup` (union), `\cap` (intersection).
  - **Inline Math**: Use `$` for inline mathematical expressions (e.g., `$E=mc^2$`).
  - **Mathematical Symbols Reference**: Online resources like `https://en.wikibooks.org/wiki/LaTeX/Mathematics#List_of_Mathematical_Symbols` provide extensive lists.
- **Usage Scenarios/Patterns**:
  - Typesetting complex formulas in physics, mathematics, computer science.
  - Including inline variables or simple equations within text.
  - Creating tutorial sheets or problem sets with clear mathematical notation.
- **Example**:
```latex
% Example: Mathematical typesetting in LaTeX
% Description: Demonstrates a De Morgan rewrite rule and a distributivity rule using LaTeX's equation environment.
\documentclass{article}
\begin{document}

Below is an instance of a De Morgan rewrite rule:
\begin{equation}
\lnot (A \land B) \equiv \lnot A \lor \lnot B
\end{equation}

Remember all the set equivalences you learnt in Algorithmic Foundations? Typeset them in a \LaTeX document. Here's a distributivity rule:
\begin{equation}
A \cup (B \cap C) \equiv (A \cup B) \cap (A \cup C)
\end{equation}

\end{document}
```
- **Notes/Best Practices**:
  - Use the `equation` environment for numbered, standalone equations.
  - Leverage online resources for finding specific mathematical symbols.
  - Practice regularly to become proficient with mathematical syntax.
- **Summary**: LaTeX excels at mathematical typesetting, offering precise control over the appearance of equations and symbols, which is essential for technical documentation.

### 4. Automating LaTeX Compilation with Makefiles
- **Motivation**: Compiling LaTeX documents often involves multiple steps (e.g., `pdflatex`, `bibtex`, `pdflatex` twice). Makefiles automate this process, ensuring that documents are always compiled correctly and efficiently, especially for complex projects.
- **Core Concepts**:
  - **Makefile**: A file that contains rules to tell the `make` utility how to build a target (e.g., a PDF from a `.tex` file).
  - **Targets**: `all` (default build), `clean` (removes intermediate files).
  - **Commands**: `pdflatex`, `rm` (for cleaning).
  - **Intermediate Files**: `.aux`, `.log`, `.out` files generated during compilation.
- **Usage Scenarios/Patterns**:
  - Automating the build process for large LaTeX projects.
  - Ensuring consistent compilation across different environments.
  - Cleaning up generated intermediate files.
- **Example**:
```makefile
# Example: Makefile for LaTeX document compilation
# Description: A simple Makefile to automate the compilation of a LaTeX document (firstdoc.tex) to PDF.

PDF = firstdoc.pdf
TEX = firstdoc.tex

all: $(PDF)

$(PDF): $(TEX)
	pdflatex $(TEX)

clean:
	rm -f *.aux *.log *.out $(PDF)
```
- **Notes/Best Practices**:
  - Include a `clean` target to remove temporary files, keeping your project directory tidy.
  - For complex documents with bibliographies or indices, the Makefile might need additional `bibtex` or `makeindex` commands.
- **Summary**: Makefiles are invaluable for automating LaTeX compilation, streamlining the workflow and ensuring reliable document generation for any project size.
