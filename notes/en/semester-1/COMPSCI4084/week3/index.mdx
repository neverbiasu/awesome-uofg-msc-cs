## Overview
- This week uses a tAPP + Lab format, focusing on data processing, manipulation, and visualization.
- Topics cover: NumPy array operations; Pandas data structures, I/O, and cleaning; Matplotlib for visualization; and creating custom Python packages.

## This Week's Schedule (in order)
| Session | Topic | Description |
|---|---|---|
| Class 4 | NumPy, Pandas Data Structures & Ops, Custom Packages | Array operations, DataFrame manipulation, fancy indexing, date and missing data handling. |
| Class 5 | Data Visualization | Matplotlib plotting basics: line plots, scatter plots, bar charts, histograms, etc. |

## Learning Objectives
1. Master NumPy array creation, indexing, slicing, and broadcasting mechanisms.
2. Become proficient in using Pandas for data reading, writing, filtering, cleaning, and transformation.
3. Understand and handle date formats and missing data (NaN).
4. Create a custom Python package to reuse data analysis code.
5. Use Matplotlib to create basic charts and customize their styles.

## Key Concepts
- **NumPy Core**:
  - `ndarray` creation (`array`, `arange`, `zeros`, `ones`), `shape` and `dtype` attributes.
  - Indexing and slicing: integer indexing, boolean masking, and fancy indexing (integer array indexing).
  - Array arithmetic and broadcasting rules.
- **Pandas Data Manipulation**:
  - `Series` and `DataFrame` data structures; reading/writing CSV/Excel/JSON.
  - Data selection: `loc` (label-based), `iloc` (position-based), boolean indexing.
  - Data cleaning: handling missing values (`dropna`, `fillna`), data type conversion.
  - Date handling: `pd.to_datetime()`, `date_range`, time-series indexing.
- **Custom Packages**:
  - Directory structure and `__init__.py`; module imports and relative imports.
- **Data Visualization (Matplotlib)**:
  - `pyplot` interface: `plot`, `scatter`, `bar`, `hist`, `pie`.
  - Customizing chart elements: title, axis labels, legend, grid.
  - Subplot layouts (`subplots`) for displaying multiple charts.

## Practice Checklist (Self-assessment)
- [ ] Create a NumPy array and use a boolean mask to filter elements that meet a condition.
- [ ] Use Pandas to read a CSV file, view descriptive statistics (`describe`), and handle missing values.
- [ ] Convert a date string column to a `datetime` type and extract year/month/day information.
- [ ] Create a simple custom package (e.g., `mydata_package`) containing data loading and cleaning functions.
- [ ] Plot a line chart and a scatter plot for a dataset, adding a title and axis labels.
- [ ] Use `subplots` to display multiple charts on a single canvas.
