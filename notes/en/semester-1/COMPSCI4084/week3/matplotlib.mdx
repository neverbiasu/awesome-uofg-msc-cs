## Overview
- **Goal**: Master Matplotlib's `pyplot` interface to create common charts (line, scatter, bar, histogram, pie) and understand subplot layouts and style customization.
- **Scope**: Covers `plot`, `scatter`, `bar`, `hist`, `pie`, `subplot`, `legend`, `grid`, `title`, `xlabel`, `ylabel`, etc. Does not cover interactive dashboards (like Plotly) or advanced 3D rendering details.

## Learning Objectives
1. Be able to draw basic line plots, scatter plots, and bar charts, and add titles, axis labels, and legends.
2. Master subplot layouts (`subplot` / `subplots`) to display multiple plots on a single canvas.
3. Understand the common parameters for histograms and box plots (`bins`, `alpha`) and be able to display error bars.

## Key Concepts

### Line Plots and Labels
- **Motivation**: To observe trends that change over time or sequence.
- **Core Concepts**: `plt.plot(x, y, label=..., linewidth=..., color=...)`. Use `plt.title`, `plt.xlabel`, `plt.ylabel` to add metadata.
- **Example**:
```python

x = list(range(1, 31))
y = [2 * i for i in x]
```
- **Summary**: Good titles and labels significantly improve chart readability.

### Scatter Plots and Point Styles
- **Motivation**: To display the distribution and relationship between variables.
- **Core Concepts**: `plt.scatter(x, y, s=size, c=color, alpha=transparency)`.
- **Example**:
```python
x1 = [20, 30, 50, 60, 80]
y1 = [10, 50, 100, 180, 200]
```
- **Summary**: Scatter plots, combined with color/size encoding, can display multidimensional information.

### Bar Charts and Error Bars
- **Motivation**: To display categorical data and its uncertainty.
- **Core Concepts**: `plt.bar`, `yerr`, `error_kw`, `alpha`.
- **Example**:
```python
langs = ['Python', 'Java', 'C', 'C++']
pop = [100, 96.3, 94.4, 87.5]
std = [1.2, 2.3, 1.5, 1.0]
```
- **Summary**: Error bars add statistical information to visualizations.

### Histograms, Box Plots, and Pie Charts
- **Motivation**: Histograms are for distributions, box plots show quartiles and outliers, and pie charts show composition proportions.
- **Core Concepts**: `plt.hist`, `df.plot(kind='box')`, `plt.pie`.
- **Example**:
```python

data = np.random.randint(0, 101, size=100)
```
- **Summary**: Choosing the right chart type helps reveal data characteristics.

### Multi-plot Layouts and Subplots
- **Motivation**: To display multiple perspectives or different series simultaneously.
- **Core Concepts**: `plt.subplot(nrows, ncols, index)` or `fig, axs = plt.subplots()`.
- **Example**:
```python
fig, axs = plt.subplots(1, 2, figsize=(8, 4))
axs[0].plot(x, y)
axs[1].scatter(x1, y1)
```
- **Summary**: Using subplots effectively makes report pages more compact.

## Best Practices
- Use `figsize` and `dpi` to control output size and resolution. Use `plt.tight_layout()` to prevent labels from overlapping.
- When using a log scale or normalized data, label the axis ticks for easier interpretation (`plt.xscale('log')`).
- Encapsulate plotting code into functions for reusability and testing.
