## Overview
- **Goal**: Master Pandas APIs for reading from and writing to various data sources, to better import raw data into DataFrames and export them to common formats.
- **Scope**: Covers `read_csv`, `read_excel`, `read_html`, `to_csv`, `to_excel`, and interaction with SQLite/SQLAlchemy via `pandas.io.sql`. Does not cover distributed I/O optimization for large databases.

## Learning Objectives
1. Be able to use `pd.read_csv`/`pd.read_table` to read tabular text and precisely control parsing with parameters like `names`, `header`, `nrows`, and `skiprows`.
2. Be able to read from and write to Excel (`read_excel`/`to_excel`) and HTML tables (`read_html`/`to_html`).
3. Understand how to interface with SQLite (or other databases supported by SQLAlchemy) via `pandas.io.sql`.
4. Master common options for `to_csv` like suppressing the `index`/`header` and specifying encoding/delimiters.

## Key Concepts

### DataFrame and Series Briefly
- **Motivation**: `DataFrame` provides a labeled 2D table structure, facilitating column-based analysis and visualization.
- **Core Concepts**: A `DataFrame` is a collection of columns (each a `Series`). A `Series` is a 1D labeled array that interoperates seamlessly with NumPy functions.
- **Summary**: Understanding the structure of `DataFrame`/`Series` helps in choosing the right I/O and manipulation functions.

### Reading CSV/TXT
- **Motivation**: CSV is the most common format for data exchange.
- **Core Concepts**: `pd.read_csv('file.csv', header=None, names=[...], delimiter=',', parse_dates=[...], dayfirst=True, nrows=..., skiprows=...)`.
- **Example**:
```python

# Basic read
df = pd.read_csv('data/texting.csv')
# Specify column names
df2 = pd.read_csv('data/texting.csv', header=None, names=['a','b','c'])
# Read only the first 100 rows
df_head = pd.read_csv('data.csv', nrows=100)
# Use a regex delimiter
df_re = pd.read_csv('data.txt', sep=r'\s+', engine='python')
```
- **Notes**: Use regular expressions for irregular delimiters. Setting `parse_dates` and `dayfirst` can automatically parse date columns.
- **Summary**: Using the parameters of `read_csv` effectively can significantly simplify subsequent cleaning processes.

### Reading/Writing Excel / HTML
- **Motivation**: Excel and HTML are often used as data sources or reporting formats.
- **Core Concepts**: `pd.read_excel`, `DataFrame.to_excel`, `pd.read_html`, `DataFrame.to_html`.
- **Example**:
```python
# Read the first sheet of an Excel file
df_x = pd.read_excel('file.xlsx', sheet_name=0)
# Write to Excel, without the index
# Parse all tables from a webpage
tables = pd.read_html('https://example.com')
```
- **Notes**: Reading Excel requires installing an engine like `openpyxl` or `xlrd`. `read_html` returns a list of DataFrames.
- **Summary**: Mastering Excel/HTML I/O facilitates handling data from multiple sources.

### Interacting with Databases (SQLite / SQLAlchemy)
- **Motivation**: To interface DataFrames with relational databases for persistence and querying.
- **Core Concepts**: `sqlalchemy.create_engine`, `pd.read_sql`, `DataFrame.to_sql`.
- **Example**:
```python
engine = create_engine('sqlite:///mydb.sqlite')
# Read from the table
q = 'SELECT * FROM table_name'
df2 = pd.read_sql(q, engine)
```
- **Notes**: `to_sql` can take `if_exists='append'|'replace'|'fail'`. For large tables, it's recommended to write in chunks.
- **Summary**: The SQL API is suitable for project-level persistence and complex filtering queries.

## Best Practices
- Specify `parse_dates` and `dayfirst` during reading to avoid complex post-processing.
- Use chunking (`chunksize`) for large tables to lower peak memory usage.
- When saving to a database, explicitly specify `dtype` or create indexes after writing to improve query performance.
