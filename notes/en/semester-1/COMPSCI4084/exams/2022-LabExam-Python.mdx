### Task 1b: Database and Bus Fare Calculation (6 Marks)
**Task Description:**
When the "Save" button is clicked, the program should save each passenger's age and ticket price to a database named `TravelPrice` and automatically clear the window to enter the next passenger's age.
- The database should be named `TravelPrice` (1 Mark).
- When the "Display age" button is clicked, the system should display all passenger ages saved in the database (3 Marks).
- When the "Display ticket price" button is clicked, the system should display the ticket price for each passenger saved in the database. Note: Each ticket price must correspond to a passenger's age (3 Marks).
- When the "Display cost" button is clicked, the system should display the total cost of the journey for the group of passengers (5 Marks).
- When the "Clear All" button is clicked, it should clear all three display windows and delete all content from the database.
**Key Concepts/Knowledge Points:**
- Database operations (save, display, clear)
- Fare calculation logic (based on age)
- tkinter event handling

## Key Takeaways

- Understanding how to process and calculate data based on business logic (e.g., age-based pricing).
- Pay attention to code modularity and error handling.
