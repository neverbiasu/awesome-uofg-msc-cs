# 2022 COMPSCI4084 Python Lab Exam

## 考试概述
本考试包含 Python 部分，主要考察 tkinter GUI 和数据库操作。

## 考试要求
- 题目要求在同一个 Python 源文件中完成所有任务。
- 提交文件命名为 `your_name_python_task.py`。
- 通过 Moodle 提交。

### 任务 1b: 数据库和计算巴士票价 (6 Marks)
**题目描述:**
程序应在点击“Save”按钮时，将每位乘客的年龄和票价保存到名为 `TravelPrice` 的数据库中，并自动清除窗口以输入下一位乘客的年龄。
- 数据库应命名为 `TravelPrice` (1 Mark)。
- 点击“Display age”按钮时，系统应显示数据库中保存的所有乘客年龄 (3 Marks)。
- 点击“Display ticket price”按钮时，系统应显示数据库中保存的每位乘客的票价。注意：每张票价必须与乘客年龄对应 (3 Marks)。
- 点击“Display cost”按钮时，系统应显示该组乘客旅程的总费用 (5 Marks)。
- 点击“Clear All”按钮时，应清除所有三个显示窗口并删除数据库中的所有内容。

**关键概念/知识点:**
- 数据库操作 (保存、显示、清除)
- 票价计算逻辑 (基于年龄)
- tkinter 事件处理

## 关键要点 (Key Takeaways)
- 熟悉 Python tkinter 库进行 GUI 开发。
- 掌握 Python 数据库（如 SQLite）的基本操作，包括数据存储、查询和删除。
- 理解如何根据业务逻辑（如年龄定价）进行数据处理和计算。
- 注意代码的模块化和错误处理。
