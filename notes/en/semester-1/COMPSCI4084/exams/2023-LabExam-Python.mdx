# 2023 COMPSCI4084 Python Lab Exam

## Exam Overview
This exam includes a Python section, primarily assessing tkinter GUI, database management, data validation, and simulating virtual librarian functionalities.

## Exam Requirements
- All tasks are required to be completed in a single Python source file.
- The submitted file should be named `your_name_python_task.py`.
- Submission is via Moodle.

## Part One: Python Questions

### Task 1a: tkinter GUI and Database Library System (14 Marks)
**Task Description:**
Create a library management system and integrate a simulated virtual librarian.
1.  Create a program that displays the following screen (5 Marks).
2.  The user should be able to enter the book's ISBN, title, author, and publication year, and save valid book details to a database named `LibraryDB` when the "Save" button is clicked. An appropriate message should be displayed upon successful saving (4 Marks).
3.  When the "Clear" button is clicked, the system should clear all fields in the window (2 Marks).
4.  When the "Display Books" button is clicked, the system should display all book details saved in the database (3 Marks).
**Key Concepts/Knowledge Points:**
- tkinter GUI interface design
- Database operations (save, display, clear)
- Basic functionalities of a library management system

### Task 1b: Book Data Validation (3 Marks)
**Task Description:**
1.  The system should ensure that duplicate ISBNs are not stored. If an entered ISBN already exists, the system should display an appropriate message (1 Mark).
2.  Ensure the entered year is not later than the current year and not earlier than 1450 (1 Mark).
3.  The system should ensure that both the title and author fields are not empty. If any field is empty, the system should display an appropriate message (1 Mark).
**Key Concepts/Knowledge Points:**
- Data validation (duplicate ISBN, year range, non-empty check)
- Error message prompts

### Task 1c: Integrate a Simulated ChatGPT as a Virtual Librarian (7 Marks)
**Task Description:**
Create a chat window to simulate interaction with ChatGPT. The system should connect to `LibraryDB` to retrieve real-time data to answer user queries. The virtual librarian should be able to answer the following types of queries:
- “Recommend me a book by [author name].” (3.5 Marks)
- “When was [book title] published.” (3.5 Marks)
Only these two sentence structures need to be handled; support for other sentences is not required.
**Key Concepts/Knowledge Points:**
- Simulated Natural Language Processing (NLP)
- Database queries to respond to user requests
- String matching and parsing

## Key Takeaways
- Comprehensively use tkinter, databases, and data validation to build a functional application.
- Learn how to simulate simple AI interactions by retrieving information from a database.
- Emphasize user interface design, data integrity, and user experience.
- Pay attention to code modularity and error handling.
