## Overview
- This week uses a tAPP + Lab format, focusing on Python fundamentals and development environment setup.
- Topics cover: Basic Python syntax, conditional branching, OOP introduction; Git/GitHub for collaboration; Conda environments and (optional) Colab.

## This Week's Schedule (in order)
| Session | Topic | Description |
|---|---|---|
| Class 0 | Course Intro; Git/GitHub; Conda & Colab | Set up environment and toolchain, familiarize with collaboration workflow. |
| Class 1 | Python Basics & Conditionals; OOP Intro | Variables/types/expressions/conditionals; classes & objects, methods, simple encapsulation. |

## Learning Objectives
1. Complete development environment setup (Anaconda/Conda + VS Code; Colab optional).
2. Master basic Git operations (clone/commit/push/branch/PR) and understand team collaboration workflows.
3. Solidify Python fundamentals (variables, types, I/O, conditionals & boolean logic).
4. Understand basic OOP concepts (class, object, method, encapsulation).

## Key Concepts
- **Environment & Tools**:
  - Conda: environment creation/activation/dependency export; avoid mixing with system Python.
  - Git: basic workflow, commit message conventions; remote collaboration and conflict resolution basics.
- **Python Basics**:
  - Data types, operators, input/output, string manipulation; indentation and code style.
  - Conditional statements (`if/elif/else`), logical operators (`and/or/not`), ternary expressions.
- **OOP Introduction**:
  - Class definition, constructors, instance attributes & methods; simple encapsulation and `__str__`/`__repr__`.

## Practice Checklist (Self-assessment)
- [ ] Create and activate a dedicated Conda environment for the course (confirm interpreter and package versions).
- [ ] Initialize a Git repository, set `user.name`/`user.email`, and complete the first commit and push.
- [ ] Write a small program with conditional branching (e.g., converting a score to a grade).
- [ ] Define a simple class (e.g., `Account`/`Student`), implement attributes and methods, and print instance information.
