## Overview
- **Goal**: Quickly get started with Google Colab (a cloud-based Jupyter environment) to complete a full cycle from creation to sharing and collaboration.
- **Scope**: Covers creating and running notebooks, enabling GPU/TPU, installing dependencies, accessing Google Drive files, collaboration, revision history, and minimal R support.

## Learning Objectives
1. Create and run a minimal Colab notebook containing both code and Markdown cells.
2. Enable GPU/TPU and run a brief numerical/plotting example.
3. Mount Google Drive to read and write files; master sharing and version history.

## Key Concepts

### 1. Getting Started
- **Steps**: Go to https://colab.research.google.com → "New Notebook" → Run sample code.
```python
print("Hello, Colab!")
```
- **Notes**: Use Markdown cells to document purpose and steps. It's good practice to place dependency installation commands in the first code cell.

### 2. Hardware Acceleration (GPU/TPU) & Plotting
- **Steps**: Runtime → Change runtime type → Select GPU (or TPU) from the Hardware accelerator dropdown.
- **Installation & Plotting**:
```bash
!pip -q install numpy matplotlib
```
```python

arr = np.random.rand(100) * 10
```
- **Tips**: Pinning key library versions can reduce environment drift. Plotting requires importing `matplotlib.pyplot`.

### 3. Collaboration & Version History
- **Sharing**: Click "Share" in the top right → Add collaborator emails and set permissions.
- **History**: File → Revision history to view and revert to previous versions.

### 4. Mounting Drive & File I/O
```python
base = '/content/drive/MyDrive'

with open(f"{base}/colab-demo.txt", "w") as f:
    f.write("Saved from Colab.")
```
- **Caution**: Resetting the runtime will clear temporary storage. Important files should be saved to Drive.

### 5. R Runtime (Minimal Example)
```bash
!apt-get -y update && apt-get -y install r-base
!R -e "install.packages('IRkernel'); IRkernel::installspec(user = FALSE)"
```
- **Switch Runtime**: Runtime → Change runtime type → Select R. Then run:
```r
print("Hello, R in Colab!")
```

## Best Practices
- Pin dependencies for a reproducible environment.
- Persist important files and manage sharing permissions.
