## Learning Outcomes

<Tabs items={["Programming Environment", "Development Skills", "System Administration"]}>
  <Tab value="programming-environment">
    1. Familiarity with modern programming environments and workflows; proficiency in command-line and editor usage; understanding the importance of good documentation.
    2. Ability to configure and use common development tools (IDE, version control, package management).
  </Tab>
  <Tab value="development-skills">
    3. Write structured programs in Java and Python, with the ability to solve problems independently using online resources.
    4. Master program testing and debugging; able to write basic unit tests.
    5. Proficient in using version control tools like Git and understanding collaborative workflows.
    6. Ability to use data science tools like Jupyter/Colab/Conda and perform basic database operations (SQLite).
  </Tab>
  <Tab value="system-administration">
    7. Understand basic Linux operations and file system navigation; able to perform basic system monitoring and printing operations.
    8. Ability to install and configure common software, and write/run simple Shell scripts.
  </Tab>
</Tabs>

## Modified Team-Based Learning

<Tabs items={["Pre-class Prep", "In-class Activities", "Lab Sessions"]}>
  <Tab value="pre-class-prep">
    1. Preview assigned materials and complete a short quiz.
    2. Focus on concepts and code examples to prepare for class discussions.
  </Tab>
  <Tab value="in-class-activities">
    1. Individual thinking: First, solve problems independently.
    2. Group discussion: Exchange and integrate solutions with team members.
    3. Team submission: Formulate a team answer and conduct peer review.
  </Tab>
  <Tab value="lab-sessions">
    1. Labs are typically 2 hours; materials are released at least one week in advance.
    2. Collaborate within your team to complete lab tasks; solutions and example code are provided afterward.
  </Tab>
</Tabs>
