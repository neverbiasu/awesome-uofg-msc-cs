## Learning Objectives
1. Master the core features of the UNIX operating system, including file management, process management, and permission control.
2. Be able to proficiently use commands like `ls`, `cd`, `pwd`, `mkdir`, `rm`, `cp`, `mv` for file system navigation and operations.
3. Be familiar with the basic use of the Vim text editor, including mode switching, insertion, saving, and exiting.
4. Understand the usage of UNIX standard devices, I/O redirection, and pipes (`|`).
5. Master the features of Shell metacharacters and variables, and be able to write simple Shell scripts.
6. Understand the basics of C programming, including basic syntax, compilation process, and Makefile automated builds.

## Key Knowledge Points
- **Unix Basics**:
  - Multi-user, multi-tasking, hierarchical directory structure
  - Kernel, Shell, Utilities
  - Common command quick reference
- **File System & Vim**:
  - File system navigation (`ls`, `cd`, `pwd`)
  - File/directory operations (`mkdir`, `rm`, `cp`, `mv`)
  - Vim mode switching, insertion, saving, exiting, copying, pasting, deleting
- **Shell Basics**:
  - Standard devices (`stdin`, `stdout`, `stderr`)
  - I/O redirection (`>`, `>>`, `<`)
  - Pipes (`|`)
  - Shell metacharacters and quoting (`*`, `$`, `"`, `'`, `\`)
  - Shell variable definition and reference
  - Command combination (` ;`, `&&`, `||`)
- **C Programming & Makefile**:
  - C language basic syntax, data types, variables, functions, pointers
  - C program compilation process (preprocessing, compilation, assembly, linking)
  - `gcc`/`clang` compiler usage
  - Makefile rules (target, dependencies, command), variables, phony targets

## Practice Checklist (Self-check)
- [ ] Successfully navigate the file system in a UNIX terminal, and create, copy, move, and delete files and directories.
- [ ] Use the Vim editor to create and edit a text file, and perform save and exit operations.
- [ ] Use pipes and redirection to combine multiple UNIX commands to complete data processing tasks.
- [ ] Write a simple Shell script that includes variable definitions and conditional judgments.
- [ ] Write a simple C program and compile and run it using `gcc` or `clang`.
- [ ] Write a Makefile for the C program to implement automated compilation and cleaning.
