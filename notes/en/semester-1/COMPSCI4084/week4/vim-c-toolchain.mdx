## Overview
- **Goal**: To learn the basic operations of the Vim editor and understand how to use it to write, compile, and run C programs in a Unix environment.
- **Scope**: Covers Vim's core modes and commands, and the basic C toolchain workflow (edit with Vim, compile with GCC).

## Learning Objectives
1. **Understand** the modal nature of Vim (Normal, Insert, Visual).
2. **Perform** basic text editing: creating, saving, quitting, copying, pasting, and deleting text.
3. **Use** `gcc` to compile a simple C program written in Vim.
4. **Follow** the standard edit-compile-run cycle on the command line.

## Key Knowledge Points

### 1. Introduction to Vim
- **Motivation**: Vim is a powerful, keyboard-centric text editor that is pre-installed on most Unix systems, making it an essential tool for command-line development and server administration.
- **Core Concepts**:
  - **Modal Editing**: Unlike most editors, Vim operates in different modes. The main ones are:
    - **Normal Mode**: The default mode. Used for navigation and issuing commands (like deleting or copying text). You return here by pressing `Esc`.
    - **Insert Mode**: Used for typing text. You enter this mode by pressing `i` (to insert before the cursor), `a` (to append after the cursor), or `o` (to open a new line below).
    - **Visual Mode**: Used for selecting text. You enter this mode by pressing `v`.
  - **Basic Workflow**: The fundamental process for editing a file is:
    1. Open a file: `vim filename.c`
    2. Enter Insert Mode: Press `i`
    3. Type your code.
    4. Return to Normal Mode: Press `Esc`
    5. Save and Quit: Type `:wq` and press Enter.
- **Summary**: The key to using Vim is understanding its modal nature. Always be aware of which mode you are in.

### 2. Essential Vim Commands (in Normal Mode)
- **Motivation**: To perform common editing tasks efficiently without a mouse.
- **Core Concepts**:
  - **Saving & Quitting**:
    - `:w`: Write (save) the file.
    - `:q`: Quit. Fails if there are unsaved changes.
    - `:wq`: Write and quit.
    - `:q!`: Quit without saving (discard changes).
  - **Editing**:
    - `dd`: Delete the current line.
    - `yy`: Yank (copy) the current line.
    - `p`: Paste the copied/deleted content after the cursor.
    - `u`: Undo the last action.
    - `x`: Delete the character under the cursor.
  - **Navigation**: While arrow keys work, traditional Vim navigation uses `h` (left), `j` (down), `k` (up), and `l` (right) in Normal Mode.
- **Summary**: Learning these basic commands allows you to perform all fundamental text editing operations.

### 3. The C Toolchain Workflow
- **Motivation**: To understand the standard process of turning C source code into an executable program on a Unix system.
- **Core Concepts**: The cycle consists of three main steps:
    1. **Edit**: Write your source code using a text editor like Vim.
       - `vim hello.c`
    2. **Compile**: Use a compiler like GCC (GNU Compiler Collection) or Clang to translate the source code into machine code. The `-o` flag specifies the name of the output executable file.
       - `gcc hello.c -o hello`
    3. **Run**: Execute the compiled program.
       - `./hello`
- **Example**: Let's create, compile, and run a "Hello, World!" program.
  1.  **Edit `hello.c`**:
      ```c
      #include <stdio.h>
      int main() {
          printf("Hello, World!\n");
          return 0;
      }
      ```
  2.  **Compile it**:
      ```bash
      gcc hello.c -o hello
      ```
  3.  **Run it**:
      ```bash
      ./hello
      # Output: Hello, World!
      ```
- **Summary**: The edit-compile-run cycle is a fundamental workflow for software development in compiled languages like C.

## Best Practices
- **Live in Normal Mode**: Try to spend most of your time in Normal Mode, only entering Insert Mode to type text. This is the path to Vim efficiency.
- **Save Often**: Get into the habit of pressing `Esc` and typing `:w` frequently to save your work.
- **Use Compiler Warnings**: Compile with the `-Wall` flag (e.g., `gcc -Wall hello.c -o hello`) to enable all warnings, which can help you catch potential bugs early.
