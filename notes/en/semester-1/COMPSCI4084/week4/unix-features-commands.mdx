## Overview
- **Goal**: To understand the core philosophy and features of the Unix operating system and to master basic command-line operations.
- **Scope**: Covers the Unix philosophy, core features (multi-user, multi-tasking, file system), and a reference for common commands. Does not cover advanced shell scripting or system administration.

## Learning Objectives
1. **Understand** the core design philosophy of Unix (e.g., "everything is a file").
2. **Recognize** the main components of a Unix-like system: Kernel, Shell, and Utilities.
3. **Master** basic commands for file and directory manipulation.
4. **Be able to** get help and information about commands using `man`.

### 1. Unix Philosophy and Features
- **Motivation**: Unix's design principles have influenced decades of software development. Understanding them helps in using the system effectively.
- **Core Concepts**:
  - **Everything is a file**: Devices, services, and sockets are all represented as files in the file system, providing a unified interface.
  - **Small, single-purpose programs**: Each tool does one thing well (e.g., `ls` lists files, `grep` finds text).
  - **Compose programs to do complex tasks**: Use pipes (`|`) to chain simple tools together to perform complex operations.
  - **Store data in plain text**: Plain text is a universal interface, making data accessible and easy to process with any tool.
  - **Core Features**:
    - **Multi-user**: Multiple users can use the system simultaneously.
    - **Multi-tasking**: The system can run multiple programs concurrently.
    - **Hierarchical File System**: A tree-like structure of directories and files, starting from the root (`/`).
- **Summary**: The Unix philosophy promotes simplicity, modularity, and composition, enabling powerful and flexible workflows.

### 2. Command Quick Reference
- **Motivation**: A quick-lookup guide for the most frequently used Unix commands.
- **Core Concepts**:
  - **File & Directory Management**
    - `ls`: List directory contents.
    - `cd`: Change directory.
    - `pwd`: Print working directory.
    - `mkdir`: Create a new directory.
    - `rmdir`: Remove an empty directory.
    - `cp`: Copy files or directories.
    - `mv`: Move or rename files or directories.
    - `rm`: Remove files or directories.
  - **Viewing & Editing Files**
    - `cat`: Concatenate and display file content.
    - `less`/`more`: View file content page by page.
    - `head`/`tail`: View the beginning/end of a file.
    - `vim`/`nano`: Text editors.
  - **System Information & Help**
    - `man`: Display the manual page for a command.
    - `whoami`: Display the current user ID.
    - `date`: Display the current date and time.
  - **Process Management**
    - `ps`: List current processes.
    - `kill`: Send a signal to a process (e.g., to terminate it).
- **Notes/Best Practices**:
  - Use `man <command>` whenever you are unsure about a command's usage or options.
  - Be very careful with `rm -r`, as it recursively deletes files and directories without confirmation.
- **Summary**: Mastering these basic commands is the first step to becoming proficient in the Unix command-line environment.

## Best Practices
- **Use `man` pages liberally**: They are the definitive source of information.
- **Organize files logically**: Use directories to structure your work.
- **Be cautious with destructive commands**: Double-check commands like `rm` before executing.
- **Leverage tab completion**: Press the `Tab` key to auto-complete file paths and command names to save time and avoid typos.
