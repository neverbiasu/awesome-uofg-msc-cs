## Overview
- This week continues the tAPP + Lab format, deepening Python programming skills.
- Topics cover: function definitions and parameters, loop structures, data structures (lists/tuples/dictionaries), file I/O and exceptions, SQLite databases, and an introduction to PyTorch.

## This Week's Schedule (in order)
| Session | Topic | Description |
|---|---|---|
| Class 2 | Functions, Loops, Data Structures | Function parameters and return values; for/while loops; basic operations for lists, tuples, and dictionaries. |
| Class 3 | File Handling, SQLite, PyTorch | File I/O and exception handling; SQL basics with SQLite3; PyTorch tensors and basic operations. |

## Learning Objectives
1. Master function definition, parameter passing (positional/keyword/default), and return values.
2. Become proficient with `for`/`while` loops and the `range` function; understand `break`/`continue` in loops.
3. Master the creation, access, modification, and iteration of lists, tuples, and dictionaries.
4. Be able to perform file I/O operations and handle common exceptions.
5. Understand basic SQLite operations (CREATE TABLE, INSERT, SELECT, UPDATE, DELETE).
6. Get acquainted with basic PyTorch concepts and tensor operations.

## Key Concepts
- **Functions & Variable Management**:
  - Function definition, parameters (positional, keyword, default), return values, scope.
  - Variable management and side effects; pure functions vs. functions with side effects.
- **Loop Structures**:
  - `for` loops (with `range`, strings, lists); `while` loops with conditional control.
  - `break`/`continue` statements; nested loops.
- **Data Structures**:
  - **List**: mutable, indexed, sliced, `append`/`insert`/`remove`/`sort`.
  - **Tuple**: immutable, packing and unpacking.
  - **Dictionary**: key-value pairs, access, update, iteration (`keys`/`values`/`items`).
- **Files & Exceptions**:
  - File open modes (`r`/`w`/`a`); `with` statement and context management.
  - Exception handling (`try`/`except`/`finally`); common exception types.
- **SQLite Database**:
  - Connection and cursor; `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
  - Parameterized queries and SQL injection prevention.
- **PyTorch Introduction**:
  - Tensor creation and operations; device management (CPU/GPU).
  - Basic arithmetic and tensor shape manipulation.

## Practice Checklist (Self-assessment)
- [ ] Write a function with multiple parameters (including defaults) and test different ways of calling it.
- [ ] Use `for` and `while` loops to generate number sequences and perform conditional iteration.
- [ ] Create and manipulate lists, tuples, and dictionaries, performing CRUD operations.
- [ ] Implement file read/write functionality and handle exceptions like file not found with `try`/`except`.
- [ ] Use `sqlite3` to create a database table and perform insert and select operations.
- [ ] Install PyTorch, create a tensor, and perform basic tensor arithmetic.
