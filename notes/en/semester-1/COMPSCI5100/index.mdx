# COMPSCI 5100: Machine Learning & AI for Data Scientists

This course presents an introduction to the general theory of learning from data and to several popular Machine Learning methods. The module is focused on practical applications of Machine Learning techniques from standard libraries such as scikit-learn in a variety of domains, as well as good practice in training and validating Machine Learning models.

    **Course Aims:**
    1. Explain the process of learning from data for regression, classification, and clustering.
    2. Implement and apply machine learning algorithms in Python using libraries like scikit-learn.
    3. Explain the strengths and weaknesses of common algorithms.
    4. Understand the impact of loss functions.
    5. Demonstrate knowledge of major machine learning application areas.
    6. Demonstrate proficiency in the data-driven modelling process.
  </Accordion>
  <Accordion title="Course Structure & Assessment">
