## Key Concepts

### The Problem of Overfitting and Large Weights
- **Motivation**: As seen with high-order polynomials, complex models that overfit the training data often have extremely large positive and negative weights. These large weights cause the model function to fluctuate wildly to catch every data point, including noise.
<Callout type="info" title="Core Idea of Regularization">
  Preventing model weights from becoming too large helps control complexity and reduce overfitting.
</Callout>

### Regularization: Penalizing the Loss Function
- **Core Concept**: Regularization works by adding a **penalty term** to the original loss function. This penalty term is a function of the model's weights. The new regularized loss function is:
  `L_reg = L_data + L_penalty`
  - `L_data` is the original Mean Squared Error (MSE).
  - `L_penalty` discourages large weights.
  - The model now has to find a balance between fitting the data well (minimizing `L_data`) and keeping its weights small (minimizing `L_penalty`).

### Ridge Regression (L2 Regularization)
- **Core Concept**: Ridge Regression uses the **L2 norm** of the weights as its penalty term. The penalty is the sum of the squared weights, scaled by a hyperparameter `λ` (lambda).
  `L_penalty = λ * Σ_{k=1 to K} w_k² = λ * ||w||²`
- **Effect**: The L2 penalty forces the weights to be small, but it rarely forces them to be exactly zero. It shrinks all weights towards zero, resulting in a smoother, less complex model function.
- **The `λ` Hyperparameter**: `λ` (called `alpha` in `scikit-learn`) controls the strength of the regularization.
  - If `λ = 0`, it's the same as ordinary least squares.
  - As `λ` increases, the weights are shrunk more and more, leading to a simpler model (higher bias, lower variance).
- **Example**:
  ```python
  # Example: Applying Ridge regression to an 8th-order polynomial
  from sklearn.linear_model import Ridge
  from sklearn.pipeline import make_pipeline
  from sklearn.preprocessing import PolynomialFeatures
  # Create a pipeline
  model = make_pipeline(PolynomialFeatures(8), Ridge(alpha=0.001))
  # Fit the model
  model.fit(x_reshaped, t_reshaped)
  ```

### Lasso Regression (L1 Regularization)
- **Core Concept**: Lasso Regression uses the **L1 norm** of the weights as its penalty term. The penalty is the sum of the absolute values of the weights, scaled by `λ`.
  ```math
  L_\text{penalty} = \lambda \sum_{k=1}^{K} |w_k| = \lambda \|w\|_1
  ```
- **Key Property: Sparsity**: The L1 penalty has a unique effect: it can force some of the model weights to be **exactly zero**. This means the model effectively ignores the corresponding features.
<Callout type="info" title="Lasso's Sparsity Property">
  Lasso (L1 regularization) can force some model weights to be exactly zero, effectively performing automatic feature selection.
</Callout>
- **Example**:
  ```python
  # Example: Applying Lasso regression
  from sklearn.linear_model import Lasso
  model = make_pipeline(PolynomialFeatures(8), Lasso(alpha=0.0001))
  model.fit(x_reshaped, t_reshaped)
  # We could inspect the model's coefficients to see which are zero
  # print(model.named_steps['lasso'].coef_)
  ```

### Choosing the Regularization Parameter `λ`
- **Motivation**: The choice of `λ` is critical. If `λ` is too small, the model will still overfit. If `λ` is too large, the model will be too simple and will underfit (not capture the underlying trend).
<Callout type="info" title="Choosing Optimal λ">
  Treat `λ` as a hyperparameter and use cross-validation to find the value that minimizes validation error.
</Callout>

## Best Practices
<Callout type="warn" title="Important: Feature Scaling">
  Always scale your features before applying Ridge or Lasso regression, as regularization is sensitive to feature scale.
</Callout>

## Key Takeaway
- Regularization (Ridge/Lasso) prevents overfitting by penalizing large model weights.
- Ridge (L2) shrinks weights towards zero; Lasso (L1) can force some weights to exactly zero, enabling feature selection.
- Cross-validation is essential for selecting the optimal regularization strength (λ).
