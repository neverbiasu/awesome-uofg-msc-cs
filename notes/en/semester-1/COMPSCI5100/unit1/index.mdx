## Overview
This unit introduces the fundamentals of regression, a core supervised learning technique. We will start with simple linear regression, understand how to measure model performance using loss functions, and then explore more complex models like polynomial regression. Key challenges such as overfitting will be addressed using validation and regularization techniques.
- **Form**: Lecture + Lab
- **Themes**: Linear Regression, Model Complexity, Cross-Validation, Regularization

## Learning Objectives
1.  Understand and implement simple linear regression.
2.  Explain the concept of a loss function and its role in model fitting.
3.  Use polynomial regression to model non-linear relationships.
4.  Understand the problem of overfitting and use cross-validation to select an appropriate model.
5.  Explain and apply Ridge (L2) and Lasso (L1) regularization to control model complexity.

## Key Knowledge Points
- **Linear Regression**:
  - The model `t = w_0 + w_1*x` and the meaning of parameters `w_0`, `w_1`.
  - Squared Loss (Mean Squared Error) as a measure of model fit.
  - The analytical solution for linear regression: `ŵ = (XᵀX)⁻¹Xᵀt`.
- **Model Complexity & Overfitting**:
  - Using polynomial basis functions to create more complex models.
  - The trade-off between model complexity and generalization.
  - How high-order polynomials can overfit by fitting to noise in the training data.
- **Validation**:
  - The difference between training data and validation data.
  - Using a validation set to estimate a model's performance on unseen data.
  - The process of K-fold cross-validation for robust model selection.
- **Regularization**:
  - Penalizing large weight values to prevent overfitting.
  - **Ridge Regression (L2)**: Adds a `λ * ||w||²` penalty, shrinking weights.
  - **Lasso Regression (L1)**: Adds a `λ * ||w||₁` penalty, which can shrink weights to zero and perform feature selection.
  - Using cross-validation to find the optimal regularization parameter `λ`.
