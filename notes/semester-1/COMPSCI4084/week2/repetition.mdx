## 概要
- 目标：掌握 Python 循环结构，实现代码重复执行与条件控制。
- 范围：覆盖 for/while 循环、range 函数、嵌套循环与控制语句；不涉及迭代器协议与生成器。

## 学习目标
1. 掌握 `for` 循环语法与 `range()` 函数的使用（起始、结束、步长）。
2. 理解 `while` 循环的条件控制与边界检查。
3. 能够使用 `break`/`continue` 控制循环流程。
4. 理解嵌套循环的结构与应用场景。

## 关键知识点

### 1. for 循环基础
- **动机**：需要对集合（列表、字符串、range）中的每个元素执行相同操作，避免重复代码。
- **核心概念**：
  - for 循环也称为"计数循环"（counting loop）
  - 语法：`for <variable> in <collection>: <body>`
  - 集合可以是：range、字符串、列表、元组等可迭代对象
  - 循环变量在每次迭代中自动更新为下一个元素
- **使用场景/模式**：
  - 遍历已知次数的操作
  - 处理序列中的每个元素
  - 生成数字序列并执行操作
- **示例**：
```python
# 基础 range 循环
# 说明：range(1, 5) 生成 1, 2, 3, 4（不包含 5）
for i in range(1, 5):
    print(i)  # 输出：1, 2, 3, 4

# 遍历字符串
# 说明：每次迭代 ch 为字符串中的一个字符
word = "Python"
for ch in word:
    print(ch)  # 每行输出一个字母：P, y, t, h, o, n
```
- **注意事项/最佳实践**：
  - `range(n)` 从 0 开始到 n-1，共 n 次迭代
  - `range(start, stop)` 从 start 到 stop-1
  - 循环变量命名应有意义（`i`/`j`/`k` 仅用于简单计数）
- **小结**：for 循环适用于已知迭代次数或需要遍历集合的场景；配合 range 可灵活控制次数。

### 2. range 函数详解
- **动机**：需要生成整数序列以控制循环次数或步长，支持正向/反向计数。
- **核心概念**：
  - `range(stop)`：0 到 stop-1
  - `range(start, stop)`：start 到 stop-1
  - `range(start, stop, step)`：带步长的序列
  - step 可为负数，实现倒序
- **使用场景/模式**：
  - 正向计数：`range(1, 10)` → 1 到 9
  - 倒序计数：`range(20, 0, -4)` → 20, 16, 12, 8, 4
  - 跳步计数：`range(1, 10, 2)` → 1, 3, 5, 7, 9
- **示例**：
```python
# 带步长的循环
# 说明：step=2 表示每次增加 2
for i in range(1, 10, 2):
    print(i)  # 输出：1, 3, 5, 7, 9

# 倒序循环
# 说明：step=-4 表示每次减少 4
for i in range(20, 0, -4):
    print(i)  # 输出：20, 16, 12, 8, 4
```
- **注意事项/最佳实践**：
  - range 不包含 stop 值（左闭右开区间）
  - 倒序时 start 必须大于 stop，step 为负数
  - range 返回惰性序列（节省内存），需要时用 `list(range(...))`
- **小结**：range 的三参数形式（start, stop, step）提供灵活的序列生成能力，支持正反向与跳步。

### 3. while 循环
- **动机**：当迭代次数未知，需根据条件动态判断是否继续循环时使用。
- **核心概念**：
  - 语法：`while <condition>: <body>`
  - 循环前检查条件（可能一次都不执行）
  - 条件为 `True` 时执行循环体，`False` 时退出
  - 必须确保循环内有更新条件的逻辑，避免死循环
- **使用场景/模式**：
  - 用户输入验证（直到输入合法）
  - 累加到达阈值
  - 游戏循环（直到满足结束条件）
- **示例**：
```python
# 累加到阈值
# 说明：持续累加用户输入，直到总和 >= 100
total = 0
while total < 100:
    num = int(input("Enter a number: "))
    total += num
print(f"Total: {total}")

# 条件控制的循环
# 说明：根据用户输入决定是否继续
again = "yes"
while again == "yes":
    print("Hello")
    again = input("Loop again? (yes/no): ")
```
- **注意事项/最佳实践**：
  - 确保循环变量/条件在循环内被更新，避免死循环
  - 复杂条件考虑提取为布尔变量或使用 `break`
  - 初始条件应在循环前设置好
- **权衡与替代**：
  - 已知次数用 for，未知次数用 while
  - 可用 `while True` + `break` 实现后检查循环（先执行后判断）
- **小结**：while 循环适用于未知迭代次数的场景；需确保条件可达 False，避免死循环。

### 4. 嵌套循环
- **动机**：处理二维结构（如表格、矩阵）或需要多层遍历的场景。
- **核心概念**：
  - 循环体内包含另一个循环
  - 外层循环每迭代一次，内层循环完整执行所有迭代
  - 可以是 for-in-for、while-in-while 或混合
- **使用场景/模式**：
  - 打印乘法表
  - 遍历二维列表
  - 生成组合（如笛卡尔积）
- **示例**：
```python
# for 嵌套 while 示例
# 说明：外层 for 控制行数，内层 while 控制列内容
for row in range(3):
    col = 0
    while col < 4:
        print(f"({row},{col})", end=" ")
        col += 1
    print()  # 换行
# 输出：
# (0,0) (0,1) (0,2) (0,3)
# (1,0) (1,1) (1,2) (1,3)
# (2,0) (2,1) (2,2) (2,3)

# 简单乘法表（部分）
# 说明：外层循环控制被乘数，内层控制乘数
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i*j}", end="  ")
    print()
```
- **注意事项/最佳实践**：
  - 注意循环变量命名，避免内外层变量名冲突
  - 嵌套层数不宜过深（一般不超过 3 层），否则考虑函数拆分
  - 内层循环每次都会完整执行，注意时间复杂度（O(n²) 或更高）
- **小结**：嵌套循环用于多层遍历；需注意变量作用域与性能影响。

### 5. break 与 continue
- **动机**：在循环执行过程中，根据特定条件提前退出循环或跳过当前迭代。
- **核心概念**：
  - `break`：立即退出当前循环（不执行后续代码和剩余迭代）
  - `continue`：跳过本次迭代剩余代码，直接进入下一次迭代
  - 仅影响最内层循环
- **使用场景/模式**：
  - break：找到目标值后提前结束搜索
  - continue：跳过无效数据，只处理符合条件的项
- **示例**：
```python
# break 示例：找到目标后退出
# 说明：在列表中查找第一个偶数
numbers = [1, 3, 5, 8, 9, 10]
for num in numbers:
    if num % 2 == 0:
        print(f"Found first even: {num}")
        break  # 找到后立即退出循环

# continue 示例：跳过不符合条件的项
# 说明：只打印奇数，跳过偶数
for num in range(1, 11):
    if num % 2 == 0:
        continue  # 跳过偶数，不执行下面的 print
    print(num)  # 输出：1, 3, 5, 7, 9
```
- **注意事项/最佳实践**：
  - break/continue 影响可读性，优先考虑用条件表达式重构
  - 嵌套循环中需明确 break 退出的是哪一层
  - 避免过多使用，可用守卫子句或提取函数替代
- **权衡与替代**：
  - 简单条件优先用 `if` 过滤而非 continue
  - 可用函数 `return` 替代 break（早返回模式）
- **小结**：break 用于提前退出，continue 用于跳过当前迭代；使用时需注意对代码流程的影响。

## 最佳实践
- 已知迭代次数优先用 `for` + `range`，未知次数用 `while`。
- 循环变量命名应具描述性；`i`/`j`/`k` 仅用于简单计数。
- while 循环必须确保条件可达 False，避免死循环；初始化条件要在循环前完成。
- 嵌套循环不宜超过 3 层；复杂逻辑考虑提取为函数。
- 谨慎使用 `break`/`continue`；优先用条件表达式或守卫子句保持代码清晰。
- range 使用左闭右开区间，注意 stop 值不包含在序列中。
