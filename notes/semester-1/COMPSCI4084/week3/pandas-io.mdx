## 概要
- 目标：掌握 Pandas 用于读取与写入各类数据源的 API，更好地将原始数据导入 DataFrame 并导出为常见格式。
- 范围：介绍 `read_csv`, `read_excel`, `read_html`, `to_csv`, `to_excel`, 以及通过 `pandas.io.sql` 与 SQLite/SQLAlchemy 的交互；不覆盖大型数据库分布式读写优化。

## 学习目标
1. 能使用 `pd.read_csv`/`pd.read_table` 读取文本表格并通过 `names`, `header`, `nrows`, `skiprows` 等参数精确控制解析。
2. 能读写 Excel (`read_excel`/`to_excel`) 与 HTML 表格 (`read_html`/`to_html`)。
3. 理解如何通过 `pandas.io.sql` 与 SQLite（或其他通过 SQLAlchemy 支持的数据库）互通数据。
4. 掌握 `to_csv` 写出时抑制 `index/header` 与编码/分隔符的常见选项。

## 关键知识点
### 1. DataFrame 与 Series 简述
- **动机**：DataFrame 提供标签化二维表结构，便于进行基于列的分析与可视化。
- **核心概念**：DataFrame 是列字典（每列为 Series）的集合；Series 为一维带标签数组，能与 NumPy 函数无缝互操作。
- **小结**：理解 DataFrame/Series 的结构有助于选择合适的 IO 与操作函数。

---
### 2. 读取 CSV/TXT
- **动机**：CSV 是数据交换最常见的格式。
- **核心概念**：`pd.read_csv('file.csv', header=None, names=[...], delimiter=',', parse_dates=[...], dayfirst=True, nrows=..., skiprows=...)`。
- **示例**：
```python
import pandas as pd
# 基本读取
df = pd.read_csv('data/texting.csv')
# 指定列名
df2 = pd.read_csv('data/texting.csv', header=None, names=['a','b','c'])
# 只读前 100 行
df_head = pd.read_csv('data.csv', nrows=100)
# 使用正则分隔
df_re = pd.read_csv('data.txt', sep=r'\s+', engine='python')
```
- **注意事项**：当分隔符不规则时，可使用正则表达式；设置 `parse_dates` 与 `dayfirst` 可自动解析日期列。
- **小结**：用好 `read_csv` 的参数能显著简化后续清洗流程。

---
### 3. 读写 Excel / HTML
- **动机**：Excel/HTML 常作为数据来源或报告格式。
- **核心概念**：`pd.read_excel`, `DataFrame.to_excel`, `pd.read_html`, `DataFrame.to_html`。
- **示例**：
```python
# 读取 Excel 第一个工作表
df_x = pd.read_excel('file.xlsx', sheet_name=0)
# 写出 Excel，去掉索引
df.to_excel('out.xlsx', index=False)
# 解析网页中所有表
tables = pd.read_html('https://example.com')
```
- **注意事项**：读取 Excel 需要安装 `openpyxl` / `xlrd` 等引擎；`read_html` 返回表格列表。
- **小结**：掌握 Excel/HTML IO 便于处理多来源数据。

---
### 4. 与数据库交互（SQLite / SQLAlchemy）
- **动机**：将 DataFrame 与关系型数据库互通，便于持久化与查询。
- **核心概念**：`sqlalchemy.create_engine`, `pd.read_sql`, `DataFrame.to_sql`。
- **示例**：
```python
from sqlalchemy import create_engine
engine = create_engine('sqlite:///mydb.sqlite')
df.to_sql('table_name', engine, index=False, if_exists='replace')
# 读取表
q = 'SELECT * FROM table_name'
df2 = pd.read_sql(q, engine)
```
- **注意事项**：`to_sql` 可以选择 `if_exists='append'|'replace'|'fail'`，传输大表时建议分批次写入。
- **小结**：SQL API 适用于项目性持久化与复杂过滤查询。

---
### 5. 写出 CSV 的常见选项
- **动机**：与他人共享数据时需要控制格式与元信息。
- **核心概念**：`df.to_csv('out.csv', index=False, header=True, sep=',', encoding='utf-8')`。
- **示例**：
```python
df.to_csv('out.csv', index=False)
```
- **注意事项**：注意编码（UTF-8 vs Latin-1）与分隔符，避免 Excel 在不同地区打开出现乱码或列错位。
- **小结**：设置合适参数能保证跨平台的数据兼容性。

## 最佳实践
- 在读取时就指定 `parse_dates` 和 `dayfirst` 以免后续处理复杂。
- 对大型表使用分块读取（`chunksize`）以降低内存峰值。
- 保存到数据库时显式指定 `dtype` 或在写入后创建索引以提升查询效率。
