## 概要
- **目标**：本笔记旨在全面理解类 Unix 操作系统中的用户和权限管理、进程控制和系统监控。它强调了这些概念在维护系统安全、稳定性和操作效率方面的关键作用。
- **范围**：涵盖用于识别用户（`whoami`、`id`）、管理权限（`sudo`）、更改密码（`passwd`）、控制文件/目录访问（`chmod`、`chown`）、修改用户账户（`usermod`）以及审计系统活动（`find`、`last`、`history`）的基本命令。它还包括用于监控和管理运行进程（`ps`、`top`、`kill`、`jobs`、`fg`、`bg`）、检查磁盘使用情况（`df`）、系统正常运行时间（`uptime`）以及用于文件归档（`tar`、`gzip`）和基本二进制分析（`strings`、`file`、`hexdump`）的实用工具。

## 学习目标
1. 掌握用户和组识别、权限提升和密码管理的命令。
2. 理解并应用文件和目录权限（`chmod`、`chown`）来保护系统资源。
3. 能够监控、控制和终止运行中的进程和后台作业。
4. 利用系统监控工具（`df`、`uptime`）评估系统健康状况和资源使用情况。
5. 熟悉用于文件归档、压缩和基本二进制分析的实用工具（`tar`、`gzip`、`strings`、`file`、`hexdump`）。

## 关键知识点

### 1. 用户与权限管理
- **动机**：适当的用户和权限管理是类 Unix 系统安全性的基石。它确保只有经过授权的个人和进程才能访问、修改或执行特定文件和资源，从而防止未经授权的访问和数据泄露。
- **核心概念**：
  - `whoami`：显示当前用户的有效用户名。
  - `id`：显示用户和组 ID（UID/GID）以及辅助组。
  - `sudo`：以 root 权限执行命令（superuser do）。
  - `passwd`：更改用户密码，这是基本的安全实践。
  - `chmod`：修改文件权限（读取、写入、执行），适用于所有者、组和其他用户。使用八进制表示法（例如，`700` 表示所有者 rwx，其他用户无权限）。
  - `chown`：更改文件所有权（用户和/或组）。只有 root 用户才能将所有权更改给其他用户；普通用户如果拥有文件并且是目标组的成员，则可以更改组所有权。
  - `usermod`：修改用户账户（例如，添加到组、更改主目录）。
  - `find`：根据各种条件（包括权限或所有权）查找文件，对安全审计很有用。
  - `last`：显示上次登录用户的列表，有助于检测异常登录活动。
  - `history`：显示当前用户的命令历史记录，对审计和取证很有用。
- **使用场景/模式**：
  - 通过限制写入权限来保护敏感配置文件。
  - 授予临时 root 权限以执行管理任务。
  - 审计用户活动和登录模式。
  - 使用 `umask` 更改新文件的默认文件权限（材料中未明确涵盖，但由 `chmod` 上下文暗示）。
- **示例**：
```bash
# Example: Secure a file to be readable only by the owner
# Description: Creates a file and sets its permissions so only the owner can read, write, and execute it.
touch sensitive_data.txt
chmod 700 sensitive_data.txt
ls -l sensitive_data.txt
# Output will show permissions like -rwx------
```
- **注意事项/最佳实践**：
  - 遵循最小权限原则：仅授予执行任务所需的最低权限。
  - 定期审查和审计文件权限和用户账户。
  - 使用强大、独特的密码并定期更改。
  - 谨慎使用 `sudo`；理解以 root 身份运行命令的含义。
- **小结**：有效的用户和权限管理对于系统安全至关重要，可控制对资源的访问并防止未经授权的操作。

### 2. 进程与作业控制
- **动机**：理解和管理进程对于系统性能、故障排除和识别恶意活动至关重要。进程是程序的运行实例，作业是 shell 管理的进程。
- **核心概念**：
  - `ps aux`：列出系统上所有运行中的进程，显示用户、PID、CPU/内存使用情况、命令等。
  - `top`：提供运行中进程、系统负载和资源消耗的实时动态视图。
  - `kill [PID]`：通过进程 ID（PID）终止进程。`kill -9 [PID]`（SIGKILL）强制终止。
  - `jobs`：列出当前 shell 会话中在后台运行或已停止的作业。
  - `fg [job_id]`：将后台作业带到前台。
  - `bg [job_id]`：在后台恢复已停止的作业。
- **使用场景/模式**：
  - 识别资源密集型进程。
  - 终止无响应的应用程序或可疑进程。
  - 在后台管理长时间运行的任务。
  - 检测可能隐藏为后台进程的恶意软件。
- **示例**：
```bash
# Example: Start a background job and manage it
# Description: Starts a sleep command in the background, lists it, and then brings it to the foreground.
sleep 100 &
jobs
fg %1 # Assuming %1 is the job ID for sleep 100
```
- **注意事项/最佳实践**：
  - 定期使用 `top` 或 `ps` 监控进程以查找异常。
  - 使用 `kill -9` 时要小心，因为它不允许进程优雅地清理。
  - 恶意软件通常伪装成合法进程；查找异常名称、路径或父/子关系。
- **小结**：进程和作业控制对于系统管理至关重要，可实现高效的资源管理、故障排除和安全事件响应。

### 3. 系统监控与文件实用工具
- **动机**：除了用户和进程管理之外，监控系统资源和拥有多功能的文件实用工具对于维护系统健康、诊断问题和执行取证分析至关重要。
- **核心概念**：
  - `df -h`：以人类可读的格式显示磁盘空间使用情况。
  - `uptime`：显示系统已运行时间、用户数量和平均负载。
  - `tar`：将多个文件归档到一个 `.tar` 文件中（磁带归档）。
  - `gzip`：压缩文件，通常与 `tar` 一起使用（例如，`.tar.gz`）。
  - `strings`：从二进制文件中提取可打印字符序列（字符串）。对于在可执行文件中查找隐藏文本（如 URL、IP 或密码）很有用。
  - `file`：通过检查其魔术数字和内容来确定文件类型（例如，可执行文件、文本、图像）。
  - `hexdump -C`：显示文件的原始十六进制和 ASCII 内容。对于低级二进制分析和逆向工程很有用。
- **使用场景/模式**：
  - 在安装新软件之前检查可用磁盘空间。
  - 快速评估系统负载和稳定性。
  - 归档项目目录以进行备份或分发。
  - 分析可疑二进制文件以查找嵌入的文本或文件类型。
  - 通过检查隐藏字符串或原始二进制数据来检测恶意软件。
- **示例**：
```bash
# Example: Archive and compress a directory, then analyze a binary
# Description: Creates a compressed archive of a project directory and then uses 'strings' and 'file' on a binary.
mkdir project_dir && touch project_dir/file1.txt
tar -czvf project.tar.gz project_dir/
df -h .

# Assuming 'malware_sample' is a binary file
strings malware_sample
file malware_sample
hexdump -C malware_sample
```
- **注意事项/最佳实践**：
  - 定期检查磁盘空间以防止系统不稳定。
  - 使用 `tar` 和 `gzip` 进行高效的多个文件备份和传输。
  - `strings` 和 `hexdump` 是强大的逆向工程和恶意软件分析工具，可揭示隐藏信息。
  - 将这些工具组合在管道中以进行更复杂的分析任务。
- **小结**：一套系统监控和文件实用工具补充了用户/进程管理，为系统健康、数据管理和安全取证提供了基本功能。

## 最佳实践
- **最小权限原则**：仅授予用户和进程执行其任务所需的最低权限。
- **定期监控**：持续监控系统日志、进程和资源使用情况，以查找可能表明安全漏洞或性能问题的异常。
- **安全密码**：强制执行强密码策略并鼓励定期更改密码。
- **审计跟踪**：利用 `history` 和系统日志（`last`）维护活动审计跟踪，以实现问责制和取证分析。
- **理解命令输出**：始终阅读并理解命令的输出，尤其是在处理权限、进程或系统资源时。
- **备份和归档**：使用 `tar` 和 `gzip` 等工具定期备份关键数据。
