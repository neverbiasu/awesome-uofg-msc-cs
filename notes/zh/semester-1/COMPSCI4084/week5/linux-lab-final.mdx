## 概要
- **目标**：本笔记旨在全面指导掌握 Linux 命令行，实现与操作系统的有效交互、高效的文件管理、进程控制以及通过 Shell 脚本进行基本自动化。它旨在为桌面和远程服务器环境构建基础技能。
- **范围**：涵盖基本的命令行概念，从基本导航（`pwd`、`cd`、`ls`）和文件操作（`echo`、`mkdir`、`mv`、`cp`、`rm`）到强大的实用程序（`cat`、`head`、`tail`、`ps`、`kill`、`man`）。它还介绍了 Shell 脚本编程的基础知识，包括创建、运行脚本以及通过用户输入和命令行参数使脚本具有交互性。

## 关键知识点

### 命令行基础与导航
- **动机**：Linux 命令行提供了一种强大而高效的方式与系统交互，通常优于图形界面，尤其适用于自动化和远程服务器管理。掌握其基础知识对于任何 Linux 用户都至关重要。
- **核心概念**：
  - **终端**：与操作系统交互的基于文本的界面。
  - `ssh`：安全外壳，用于连接远程 Linux 机器（例如，`ssh user@host`）。
  - `pwd`：打印工作目录，显示您在文件系统中的当前位置。
  - `cd [directory]`：更改目录，将您移动到指定目录。
  - `ls`：列出目录内容。`ls -l` 用于长列表，`ls -a` 用于所有文件（包括隐藏文件）。
  - **大小写敏感性**：Linux 命令和文件名区分大小写。
  - **文件结构**：分层结构，`/`（根）位于顶部。
  - **Tab 补全**：按 `Tab` 键自动补全命令和文件名，节省时间并防止输入错误。
  - `~`：代表当前用户的主目录。
  - `*`：通配符，匹配任何字符序列。
- **使用场景/模式**：
  - 连接到大学云虚拟机或远程服务器。
  - 查找当前位置并在目录之间移动。
  - 列出文件以查看目录内容。
  - 使用通配符过滤 `ls` 输出（例如，`ls p*`）。
- **示例**：
```bash
# Example: Navigating the file system
# Description: Connects to a remote machine, checks current directory, moves to root, lists contents, then returns home.
ssh your_GUID_username@10.224.160.71
pwd
cd /
ls
cd ~
pwd
```
- **注意事项/最佳实践**：
  - 始终记住 Linux 区分大小写。
  - 广泛使用 `Tab` 补全以加快工作流程。
  - 理解分层文件系统结构。
- **小结**：掌握基本的命令行导航是高效管理 Linux 系统的第一步，使用户能够移动和检查文件系统。

### 文件和目录管理
- **动机**：高效地创建、移动、复制和删除文件和目录是任何 Linux 用户的日常任务。这些命令提供了对数据组织的精确控制。
- **核心概念**：
  - `echo [text]`：将文本写入屏幕。可以使用 `>` 将输出重定向到文件。
  - `> [filename]`：将标准输出重定向到文件。如果文件不存在则创建，如果存在则覆盖。
  - `mkdir [directory_name]`：创建新目录。
  - `mv [source] [destination]`：移动或重命名文件/目录。
  - `cp [source] [destination]`：复制文件/目录。
  - `rm [file]`：删除文件。
  - `rmdir [directory]`：删除空目录。
- **使用场景/模式**：
  - 创建包含特定内容的文本文件。
  - 将文件组织到新目录中。
  - 备份重要文件。
  - 清理不需要的文件或空文件夹。
- **示例**：
```bash
# Example: Creating, moving, and copying files
# Description: Creates a text file, a directory, moves the file, and copies another.
echo "Hello World" > file1.txt
mkdir test_dir
mv file1.txt test_dir/
cp test_dir/file1.txt test_dir/file2.txt
ls test_dir
```
- **注意事项/最佳实践**：
  - 小心使用 `rm`，因为删除的文件不易恢复。
  - `mv` 移动文件，`cp` 创建副本。
  - `rmdir` 仅用于空目录；`rm -r` 用于非空目录（谨慎使用）。
- **小结**：Linux 提供了一套强大的命令来管理文件和目录，对数据组织和操作提供了精细的控制。

### 基本实用程序：`cat`、`head`、`tail`、`ps`、`kill`、`man`
- **动机**：除了基本的文件管理，一系列强大的实用程序帮助用户查看文件内容、检查进程和访问文档，这对于故障排除和系统理解至关重要。
- **核心概念**：
  - `cat [file]`：连接文件并打印到标准输出。通常用于显示文件内容。
  - `head [file]`：显示文件的前几行（默认 10 行）。`head -n [num] [file]` 用于指定行数。
  - `tail [file]`：显示文件的后几行（默认 10 行）。`tail -n [num] [file]` 用于指定行数。
  - `ps`：进程状态，显示当前运行的进程。`ps -f` 用于完整格式列表。
  - `kill [PID]`：向进程发送信号，通常用于终止进程。`kill -9 [PID]` 用于强制终止。
  - `man [command]`：手册，显示给定命令的手册页，提供有关其用法和选项的详细信息。
- **使用场景/模式**：
  - 快速查看小文件的全部内容（`cat`）。
  - 检查日志文件中的最新条目（`tail`）。
  - 识别和终止行为异常的进程（`ps`、`kill`）。
  - 学习新命令或选项（`man`）。
- **示例**：
```bash
# Example: Viewing file content and managing processes
# Description: Displays the first 3 lines of a file, starts a background process, and then kills it.
echo -e "1\n2\n3\n4\n5" > numbers.txt
head -n 3 numbers.txt
sleep 100 &
ps -f
kill [PID_of_sleep_process]
man ls
```
- **注意事项/最佳实践**：
  - `cat` 适用于小文件；对于大文件，`less` 或 `more` 更好。
  - `tail -f` 可用于跟踪文件增长（例如，日志文件）。
  - 小心使用 `kill -9`，因为如果进程未能优雅关闭，可能会导致数据丢失。
  - `man` 是学习任何命令的最佳工具。
- **小结**：基本实用程序提供了强大的功能，用于检查文件内容、监控和控制进程以及访问全面的文档，增强了用户管理和故障排除 Linux 系统的能力。

### Shell 脚本编程基础
- **动机**：Shell 脚本编程允许您通过将一系列命令组合到一个可执行文本文件中来自动化重复性任务。这显著提高了系统管理和开发工作流程的效率和一致性。
- **核心概念**：
  - **脚本**：包含一系列命令的文本文件。
  - **Shebang**：`#!/bin/bash`（或类似内容）在脚本开头，指定解释器。
  - **执行**：`./script_name`（需要执行权限，`chmod +x script_name`）。
  - **用户输入**：`read -p "Prompt: " variable` 将用户输入读取到变量中。
  - **命令行参数**：`$1`、`$2`、`$3` 等，分别指代传递给脚本的第一个、第二个、第三个命令行参数。
- **使用场景/模式**：
  - 自动化日常备份。
  - 设置开发环境。
  - 执行复杂的文件操作。
  - 创建交互式工具供用户使用。
- **示例**：
```bash
# Example: Simple shell script with user input and arguments
# Description: A script that greets the user and lists files in a specified directory.
#!/bin/bash
# Script: greet_and_list.sh
# Usage: ./greet_and_list.sh [directory]
read -p "Enter your name: " NAME
echo "Hello, $NAME!"
if [ -z "$1" ]; then
  echo "No directory specified. Listing current directory:"
  ls
else
  echo "Listing files in $1:"
  ls "$1"
fi
```
- **注意事项/最佳实践**：
  - 始终在脚本中添加 shebang 行。
  - 使用 `chmod +x` 使脚本可执行。
  - 使用双引号括起变量（`"$1"`、`"$NAME"`）以防止空格问题。
  - 逐步测试脚本以调试错误。
- **小结**：Shell 脚本编程是 Linux 用户的一项基本技能，通过组合现有命令，可以实现任务自动化、创建自定义工具和高效管理复杂工作流程。

## 最佳实践
- **定期练习**：持续练习命令行是提高熟练度和速度的最佳方式。
- **使用 `man` 获取帮助**：当对命令或其选项有疑问时，请使用 `man [command]` 查阅其手册页。
- **理解大小写敏感性**：始终记住 Linux 对命令、文件名和参数区分大小写。
- **利用 Tab 补全**：使用 `Tab` 键自动补全命令和路径，减少输入和错误。
- **使用管道组合命令**：学习使用 `|` 链接命令以创建强大的数据处理管道。
- **从简单的脚本开始**：从小型、简单的脚本开始，逐步增加复杂性。
