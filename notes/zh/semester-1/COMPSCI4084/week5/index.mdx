## 学习目标
1. 掌握用于文本处理、文件管理和系统监控的基本 Unix 命令行工具。
2. 理解并应用用户和文件权限原则以确保系统安全。
3. 能够有效地控制和管理进程与作业。
4. 熟练使用 Git 进行本地版本控制和远程协作。
5. 学习 LaTeX 的基本知识，用于专业的文档准备。
6. 掌握 Shell 脚本编程的基础技能，用于任务自动化。

## 关键知识点
- **文本处理与分析**：
  - `grep`：模式搜索，日志过滤。
  - `sort` & `uniq`：数据聚合，识别重复项。
  - `wc`：统计行、词、字符。
  - `tr`：字符转换与删除。
  - `sed`：流编辑器，文本替换与编辑。
  - `curl`：网络数据传输，侦察与测试。
- **系统管理与安全**：
  - 用户与权限：`whoami`, `id`, `sudo`, `passwd`, `chmod`, `chown`, `usermod`。
  - 进程与作业：`ps`, `top`, `kill`, `jobs`, `fg`, `bg`。
  - 系统监控：`df`, `uptime`。
  - 编译器警告：`-Wall`, `-Wextra`, `-Werror` 在安全编码中的作用。
- **版本控制**：
  - Git 基础：`init`, `status`, `add`, `commit`, `log`, `diff`。
  - Git 远程协作：SSH 密钥设置, `clone`, `push`, `pull`, 合并冲突。
- **文档处理**：
  - LaTeX 基础：安装, 文档结构, 文本/数学排版, Makefile 自动化编译。
- **Shell 脚本编程**：
  - 脚本创建与执行。
  - 用户输入与命令行参数。

## 实践清单
- [ ] 练习使用 `grep` 过滤日志中的特定模式。
- [ ] 使用 `sort` 和 `uniq -c` 识别日志文件中的频繁条目。
- [ ] 使用 `chmod` 和 `chown` 更改文件权限。
- [ ] 使用 `ps` 和 `top` 监控系统进程，并使用 `kill` 终止进程。
- [ ] 初始化 Git 仓库，进行提交，并查看历史记录。
- [ ] 为 GitHub 设置 SSH 密钥，并练习 `git clone`、`push`、`pull`。
- [ ] 创建一个简单的 LaTeX 文档并将其编译为 PDF。
- [ ] 编写一个接受用户输入或命令行参数的基本 Shell 脚本。
