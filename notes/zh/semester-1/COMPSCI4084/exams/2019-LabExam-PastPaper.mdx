# 2019 COMPSCI4084 Lab Exam Past Paper (Python + Java)

## 考试概述
本考试包含两个部分：第一部分要求编写 Python 程序，第二部分要求编写 Java 程序。总分 24 分，另有 1 分用于代码风格。

## 考试要求
- 考试期间将使用默认配置的实验室机器。
- 不允许携带任何物品，不允许访问任何预先编写的文档或代码文件。
- 考试期间严禁考生之间交流。
- 遇到硬件或软件问题应立即召唤监考人员。
- Python 任务需在单独的源文件中完成，并命名为 `python_task1.py`, `python_task2.py`, `python_task3.py`, `python_task4.py`，通过 Moodle 提交。
- Java 任务需将所有类放在 `superhero` 包中，并命名为 `Power.java`, `GameCharacter.java`, `Player.java`，通过 Moodle 提交。

## 第一部分：Python 题目

### 任务 1: 数据库 (5 Marks)
**题目描述:**
创建一个新的 SQL 数据库，包含两个表：`Authors` 和 `Books`。
`Authors` 表包含 `ID`, `Name`, `Place of Birth`。
`Books` 表包含 `ID`, `Title`, `Author`, `Data Published`。
并插入给定的数据。
将解决方案保存到 `python_task1.py`。

**关键概念/知识点:**
- SQL 数据库创建和数据插入
- 数据库表设计

### 任务 2: 显示数据库 (7 Marks)
**题目描述:**
使用 `BookInfo` 数据库，显示作者及其出生地列表。程序应要求用户输入出生地，然后显示在该地点出生的作者的所有图书的标题、出版日期和作者姓名。
将解决方案保存到 `python_task2.py`。

**关键概念/知识点:**
- 数据库查询和数据显示
- 用户输入处理

### 任务 3: 查询数据库 (5 Marks)
**题目描述:**
程序应要求用户输入一个年份，并显示在该年份之后出版的所有图书，按出版年份排序。
将解决方案保存到 `python_task3.py`。

**关键概念/知识点:**
- 数据库查询 (按年份过滤、排序)
- 用户输入处理

### 任务 4: 写入文件 (7 Marks)
**题目描述:**
程序应要求用户输入作者姓名，然后将该作者的所有图书保存到名为 `Booklist.txt` 的文本文件中，每个字段用破折号分隔。最后，应显示文本文件的内容。
将解决方案保存到 `python_task4.py`。

**关键概念/知识点:**
- 文件 I/O 操作
- 字符串格式化

## 第二部分：Java 题目

### 任务 1: Power (2 Marks)
**题目描述:**
创建一个枚举类型 `Power`，包含以下值：`CLONING, COMPUTER, ENERGY_BLAST, FLIGHT, INVINCIBILITY, MAGIC, MAGNETISM, SCIENCE, SMALL, SPEED, STRENGTH, TELEPATHY, TRANSFORMATION, WEAPONS, WATER`。所有类应放在 `superhero` 包中。

**关键概念/知识点:**
- Java 枚举类型

### 任务 2: GameCharacter (6 Marks)
**题目描述:**
创建一个 `GameCharacter` 类，表示游戏角色，包含以下属性：
- `name` (String)
- `powers` (Set of Power objects)
构造函数签名：`public GameCharacter(String name, int cost, Power... powers)`。
要求：
- 类必须是不可变的。
- 必须有完整的 `get` 方法集，但没有 `set` 方法。
- 提供适当的 `equals()`, `hashCode()` 和 `toString()` 实现。`toString()` 必须手动编写。
- 为类和所有成员编写描述性 Javadoc 注释。

**关键概念/知识点:**
- Java 类设计 (属性、构造函数、getter)
- 不可变类
- `equals()`, `hashCode()` 和 `toString()` 方法重写
- Javadoc 注释

### 任务 3: Player (6 Marks)
**题目描述:**
实现一个 `Player` 类，表示游戏玩家，包含一个字段：
- 玩家当前拥有的游戏角色集合 (GameCharacter 对象)。
包含以下方法：
- 构造函数初始化角色集合。
- 添加角色的方法。
- 获取字段值的 `get` 方法。

**关键概念/知识点:**
- Java 类设计 (属性、构造函数、方法)
- 集合操作

### 任务 4: chooseCharacters (10 Marks)
**题目描述:**
在 `GameCharacter` 类中实现一个额外的公共方法：
- `public Set<GameCharacter> chooseCharacters(Power... neededPowers)`
该方法应根据所需能力返回提供所有所需能力的角色集合，如果不可能提供，则返回 `null`。如果存在多个有效集合，则返回其中任何一个。

**关键概念/知识点:**
- 集合操作
- 算法设计 (寻找满足条件的角色组合)

## 关键要点 (Key Takeaways)
- 掌握 Python 和 Java 两种语言的编程能力。
- 熟悉 Python 数据库操作和文件 I/O。
- 掌握 Java 面向对象编程，包括枚举、类设计、不可变类、方法重写、集合操作和算法设计。
- 理解如何将复杂问题分解为模块化任务并逐步实现。
