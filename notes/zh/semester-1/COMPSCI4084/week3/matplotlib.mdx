## 概要
- 目标：掌握 Matplotlib 的 `pyplot` 接口以创建常见图表（折线、散点、柱状、直方图、饼图）并了解子图布局与样式定制。
- 范围：`plot`, `scatter`, `bar`, `hist`, `pie`, `subplot`, `legend`, `grid`, `title`, `xlabel`, `ylabel` 等；不覆盖交互式仪表盘（如 Plotly）或高级 3D 渲染细节。

## 学习目标
1. 能绘制基本折线图、散点图与柱状图并添加标题、坐标轴标签与图例。
2. 掌握子图布局（`subplot` / `subplots`）以在单张画布显示多个图。
3. 理解直方图与箱线图的常见参数（`bins`, `alpha`）并能展示误差条（error bars）。

## 关键知识点

### 1. 折线图与标签
- **动机**：观察随时间或顺序变化的趋势。
- **核心概念**：`plt.plot(x,y, label=..., linewidth=..., color=...)`，使用 `plt.title`, `plt.xlabel`, `plt.ylabel` 添加元信息。
- **示例**：
```python

x = list(range(1,31))
y = [2*i for i in x]
```
- **小结**：良好的标题与标签能显著提升图表可读性。

### 2. 散点图与点样式
- **动机**：显示变量间的分布与关系。
- **核心概念**：`plt.scatter(x,y, s=大小, c=颜色, alpha=透明度)`。
- **示例**：
```python
x1 = [20,30,50,60,80]
y1 = [10,50,100,180,200]
```
- **小结**：散点图配合颜色/大小编码可展示多维信息。

### 3. 柱状图与误差条
- **动机**：展示分类数据及其不确定性。
- **核心概念**：`plt.bar`, `yerr`, `error_kw`, `alpha`。
- **示例**：
```python
langs = ['Python','Java','C','C++']
pop = [100,96.3,94.4,87.5]
std = [1.2,2.3,1.5,1.0]
```
- **小结**：误差条能增加可视化的统计信息传达。

### 4. 直方图、箱线图与饼图
- **动机**：直方图用于分布，箱线图显示分位数与异常值，饼图显示组成比例。
- **核心概念**：`plt.hist`, `df.plot(kind='box')`, `plt.pie`。
- **示例**：
```python

data = np.random.randint(0,101, size=100)
```
- **小结**：选择合适的图表类型有助于揭示数据特征。

### 5. 多图布局与子图
- **动机**：同时展示多个视角或不同系列。
- **核心概念**：`plt.subplot(nrows, ncols, index)` 或 `fig, axs = plt.subplots()`。
- **示例**：
```python
fig, axs = plt.subplots(1,2, figsize=(8,4))
axs[0].plot(x,y)
axs[1].scatter(x1,y1)
```
- **小结**：合理使用子图使报告页面更紧凑。

## 最佳实践
- 使用 `figsize` 与 `dpi` 控制输出大小与分辨率；使用 `plt.tight_layout()` 避免标签重叠。
- 对数尺度或归一化数据时标注轴刻度便于解读（`plt.xscale('log')`）。
- 将绘图代码封装为函数以便重复使用与测试。
