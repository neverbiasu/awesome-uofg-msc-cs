## 概要
- 本周采用 tAPP + Lab 的形式，聚焦数据处理、操作与可视化。
- 主题覆盖：NumPy 数组操作；Pandas 数据结构、读写与清洗；Matplotlib 可视化；自定义 Python 包。

## 本周安排（按顺序）
| Session | 主题 | 说明 |
|---|---|---|
| Class 4 | NumPy, Pandas 数据结构与操作, 自定义包 | 数组运算, DataFrame 操作, fancy indexing, 日期与缺失数据处理 |
| Class 5 | 数据可视化 | Matplotlib 绘图基础：折线图, 散点图, 柱状图, 直方图等 |

## 学习目标
1. 掌握 NumPy 数组创建、索引、切片与广播机制。
2. 熟练使用 Pandas 进行数据读写、筛选、清洗与转换。
3. 理解并处理日期格式与缺失数据（NaN）。
4. 创建自定义 Python 包以复用数据分析代码。
5. 使用 Matplotlib 绘制基础图表并定制样式。

## 关键知识点
- **NumPy 核心**：
  - ndarray 创建（array, arange, zeros, ones）, shape 与 dtype 属性。
  - 索引与切片：整数索引, 布尔掩码（masking）, fancy indexing（整数数组索引）。
  - 数组运算与广播（broadcasting）规则。
- **Pandas 数据操作**：
  - Series 与 DataFrame 数据结构；读写 CSV/Excel/JSON。
  - 数据选择：loc（标签）, iloc（位置）, 布尔索引。
  - 数据清洗：处理缺失值（dropna, fillna）, 数据类型转换。
  - 日期处理：pd.to_datetime(), date_range, 时间序列索引。
- **自定义包（Package）**：
  - 目录结构与 __init__.py；模块导入与相对导入。
- **数据可视化（Matplotlib）**：
  - pyplot 接口：plot, scatter, bar, hist, pie。
  - 图表元素定制：标题, 坐标轴标签, 图例, 网格。
  - 子图布局（subplots）与多图展示。

## 实践清单（自检）
- [ ] 创建 NumPy 数组, 使用布尔掩码筛选满足条件的元素。

- [ ] 将日期字符串列转换为 datetime 类型, 提取年/月/日信息。
- [ ] 创建一个简单的自定义包（如 mydata_package）, 包含数据加载与清洗函数。

- [ ] 使用 subplots 在一个画布上展示多张子图。
