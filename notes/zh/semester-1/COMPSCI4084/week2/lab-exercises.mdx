### for 循环与简单输出（练习 1–3）

#### 动机
- 练习对循环计数、条件分支和字符串输出的掌握：常见的入门题目用于考察循环结构与条件判断的组合。

#### 核心概念
- `for i in range(n)`、字符串重复输出、条件判断（if/else）。
- 输入校验：将用户输入转换为 `int` 并处理可能的 `ValueError`。

#### 示例（练习 1）
```python
# 练习1：根据用户输入重复输出名字或提示 Too high 三次
name = input('Enter your name: ')
try:
    n = int(input('Enter a number: '))
except ValueError:
    print('请输入一个整数')
else:
    if n < 10:
        for _ in range(n):
            print(name)
    else:
        for _ in range(3):
            print('Too high')
```

#### 注意事项/最佳实践
- 输入转换必须捕获异常，避免程序崩溃。
- 明确题目对边界（等于 10）的定义。

#### 小结
考点：range、循环次数控制、输入校验、条件分支。

### while 循环与累加 / 猜数游戏（练习 4–6）

#### 动机
- 测试使用 while 循环进行不定次数交互、累加或猜测直到满足条件的能力。

#### 核心概念
- `while` 循环、状态变量、计数器（attempts）、用户交互循环。

#### 示例（练习 5 猜数）
```python
compnum = 50
attempts = 0
while True:
    try:
        guess = int(input('Enter your guess: '))
    except ValueError:
        print('请输入整数')
        continue
    attempts += 1
    if guess == compnum:
        print(f'Well done, you took {attempts} attempts')
        break
    elif guess < compnum:
        print('Too low')
    else:
        print('Too high')
```

#### 注意事项/最佳实践
- 保证循环终止条件可达，避免死循环。
- 对用户输入进行类型与范围校验。

#### 小结
考点：while 循环、交互式状态管理、计数器与输入容错。

### 函数与结构化（练习 7）

#### 动机
- 将代码分解为小函数，提高可读性与可测试性。练习 7 要求用函数读取值并传递给计数函数。

#### 核心概念
- 函数定义 `def`、参数传递、返回值、函数调用顺序。

#### 示例
```python
def read_num():
    while True:
        try:
            return int(input('Enter a number: '))
        except ValueError:
            print('请输入整数')
def count_to(n):
    for i in range(1, n+1):
        print(i)
num = read_num()
count_to(num)
```

#### 注意事项/最佳实践
- 函数应尽量小且单一职责（单一功能原则）。
- 将 I/O 与逻辑分离有利于编写单元测试（把 `input()` 包装在独立函数中）。

#### 小结
考点：函数封装、职责分离、提高测试性。

### 列表管理菜单（练习 8）——小型 CRUD 应用

#### 动机
- 实现一个交互式菜单以管理姓名列表，考察列表操作、菜单循环、索引与用户体验设计。

#### 核心概念
- 列表的 `append`, `remove`, 索引赋值，`enumerate` 显示序号。
- 菜单循环：在用户选择退出前持续显示菜单。

#### 示例（菜单骨架）
```python
names = []
def show_menu():
    print('\nMenu:')
    print('1. Add name')
    print('2. Change name')
    print('3. Delete name')
    print('4. View names')
    print('5. Quit')
while True:
    show_menu()
    choice = input('Choose an option: ')
    if choice == '1':
        names.append(input('Enter name to add: '))
    elif choice == '2':
        idx = int(input('Enter index to change: '))
        names[idx] = input('Enter new name: ')
    elif choice == '3':
        idx = int(input('Enter index to delete: '))
        names.pop(idx)
    elif choice == '4':
        for i, n in enumerate(names):
            print(i, n)
    elif choice == '5':
        break
    else:
        print('Invalid option')
```

#### 注意事项/最佳实践
- 对索引进行范围检查。
- 用户体验：在菜单之后清晰反馈操作结果并回到菜单。
- 可将菜单逻辑拆分为函数以便测试。

#### 小结
考点：列表 CRUD、菜单循环、输入校验与用户友好提示。

### 随机练习（练习 9–12）

#### 动机
- 使用 `random` 模块实现随机选择与简单游戏逻辑，考察概率行为与分支处理。

#### 核心概念
- `random.choice`, `random.randint`，基本概率与猜测交互逻辑。

#### 示例（练习 9 随机水果）
```python

fruits = ['apple', 'banana', 'orange', 'pear', 'kiwi']
print(random.choice(fruits))
```

#### 示例（练习 11 猜数，两次机会）
```python

num = random.randint(1, 5)
first = int(input('Guess a number (1-5): '))
if first == num:
    print('Well done')
else:
    hint = 'too low' if first < num else 'too high'
    print(hint)
    second = int(input('Second guess: '))
    if second == num:
        print('Correct')
    else:
        print('You lose')
```

#### 注意事项/最佳实践
- 明确随机范围并在提示中告知用户。
- 对用户输入范围进行检查。

#### 小结
考点：`random` 使用、提示与控制流设计。

### Turtle 图形（练习 13–15）

#### 动机
- 用图形化方式理解循环、角度、随机与状态变化；适合视觉化练习与调试循环/几何逻辑。

#### 核心概念
- `turtle` 模块：画笔前进 `forward()`、旋转 `right()`/`left()`、颜色 `pencolor()`、画笔状态 `penup()`/`pendown()`。

#### 示例（绘制正八边形并为每边选随机颜色）
```python

colors = ['red','green','blue','orange','purple','yellow']
for _ in range(8):
    turtle.pencolor(random.choice(colors))
    turtle.forward(100)
    turtle.right(45)
```

#### 注意事项/最佳实践
- 在非交互环境（如自动评分）需跳过 Turtle，或把绘图保存为图像再断言。
- 控制循环步长与角度确保图形闭合。

#### 小结
考点：循环控制、几何角度、随机化颜色与图形参数。

### 列表/字典/元组/数组 进阶（练习 16–25）

#### 动机
- 考察对常用数据结构的熟练度：搜索、排序、合并、删除与格式化输出。

#### 核心概念
- 列表索引与查找、`list.sort()`/`sorted()`、`dict` 基本操作、`tuple` 的不可变性、数组（或用列表模拟）排序与格式化。

#### 示例（练习 16）
```python
nums = [123, 456, 789, 234]
x = int(input('Enter a three-digit number: '))
if x in nums:
    print('Position:', nums.index(x))
else:
    print("That's not in the list")
```

#### 注意事项/最佳实践
- 当题目要求保持原列表不变时，用 `sorted()` 而非 `list.sort()`。
- tuple 不可变，索引访问与列表相同但不支持赋值。
- 要展示浮点数保留两位，可使用 `format(value, '.2f')` 或 f-string：`f"{v:.2f}"`。

#### 小结
考点：列表查找与索引、排序、格式化与字典基本操作。

### 2D 列表与表格操作（练习 26–30）

#### 动机
- 模拟二维表格（行/列），练习行列索引、更新和删除行列数据的能力。

#### 核心概念
- 二维列表（列表中包含列表），通过 `data[row][col]` 访问和修改。
- 显示整行、追加元素、删除行或列等常见操作。

#### 示例（访问/修改）
```python
matrix = [
    [0, 2, 5, 8],
    [3, 7, 4, 1],
    [1, 6, 9, 2],
    [4, 2, 0, 3]
]
row = int(input('Which row? '))
col = int(input('Which column? '))
print('Value:', matrix[row][col])
# 修改
matrix[row][col] = int(input('New value: '))
```

#### 注意事项/最佳实践
- 校验行列索引范围，避免 IndexError。
- 当频繁对表格做复杂查询时，考虑使用 pandas.DataFrame 以提高开发效率。

#### 小结
考点：二维索引访问、行列操作、边界检查与数据一致性。

## 评分要点（导师/自动评分参考）
- 正确性（60%）：程序按题目描述完成功能且在有效输入下给出正确输出。
- 鲁棒性（20%）：对非法输入有合理处理（非整数、超出索引、空列表等）。
- 代码质量（10%）：结构清晰、函数化、适当注释、变量命名规范。

自动化测试建议：把 I/O 抽离到可注入的函数（比如传入 `input` 的替代函数或把逻辑写成返回值明确的函数），方便使用 pytest 模拟输入/断言输出。

## 常见陷阱与调试提示
- 忽略输入校验导致 ValueError/IndexError；在读取 int 时用 try/except。
- 在循环中修改列表导致跳过元素（删除时建议倒序或先创建新列表）。
- Turtle 在无 GUI 的 CI 环境无法运行（训练/自动评分时需额外处理）。
- 混用 `list.sort()` 和 `sorted()` 的语义差异（前者原地修改且返回 None）。
