## 概要
- 目标：掌握函数定义与调用，理解参数传递与返回值机制，提升代码复用性与模块化。
- 范围：覆盖函数定义、多种参数类型、局部/全局作用域、模块导入；不涉及装饰器、闭包、高阶函数等高级话题。

## 学习目标
1. 掌握函数定义语法（`def`）与调用机制。
2. 理解位置参数、关键字参数、默认参数的区别与使用场景。
3. 能够使用 `return` 语句返回值并在程序中使用返回结果。
4. 理解局部变量与全局变量的作用域与生命周期。
5. 能够导入模块（内置库或自定义模块）并调用其中的函数。

## 关键知识点

### 1. 函数定义与调用基础
- **动机**：将重复执行的代码封装为可复用的函数，提升代码可维护性与可读性。
- **核心概念**：
  - 函数是执行特定任务的语句组，可从多处调用
  - 定义：`def function_name(parameters): <body>`
  - 调用：`function_name(arguments)`
  - 函数体必须缩进（通常 4 个空格）
- **使用场景/模式**：
  - 重复逻辑提取为函数
  - 复杂任务分解为多个小函数
  - 提供可配置的功能接口
- **示例**：
```python
# 简单函数定义与调用
# 说明：无参数的问候函数
def greet():
    print("Hello from function!")
greet()  # 输出：Hello from function!
# 带参数的函数
# 说明：接收 name 参数，打印个性化问候
def greet_user(name):
    print(f"Hello, {name}!")
greet_user("Alice")  # 输出：Hello, Alice!
```
- **注意事项/最佳实践**：
  - 函数名使用小写加下划线（`snake_case`），如 `calculate_total`
  - 函数应保持单一职责，避免过长（建议不超过 20 行）
  - 函数定义应在调用之前（或导入模块时自动加载）
- **小结**：函数通过 `def` 定义，用函数名加括号调用；是代码复用的基础单元。

### 2. 参数类型：位置参数与关键字参数
- **动机**：不同场景需要不同的参数传递方式；位置参数简洁，关键字参数可读性高。
- **核心概念**：
  - **位置参数**：按顺序传递，必须匹配定义顺序
  - **关键字参数**：按参数名传递，顺序无关
  - 混合使用时，位置参数必须在关键字参数之前
- **使用场景/模式**：
  - 核心必填参数用位置参数
  - 可选配置或多参数时用关键字参数提升可读性
  - API 设计时，重要参数在前，可选参数用关键字
- **示例**：
```python
# 多参数函数定义
# 说明：绘制矩形，width 和 height 为位置参数
def draw_box(width, height, outline='*', fill=' '):
    """绘制指定宽高的矩形"""
    for i in range(height):
        if i == 0 or i == height - 1:
            print(outline * width)
        else:
            print(outline + fill * (width - 2) + outline)
# 仅提供位置参数（outline 和 fill 使用默认值）
draw_box(5, 3)
# 输出：
# *****
# *   *
# *****
# 混合使用位置参数和关键字参数
draw_box(4, 3, outline='#', fill='-')
# 输出：
# ####
# #--#
# ####
# 纯关键字参数调用（顺序无关）
draw_box(height=2, width=6, fill='.')
```
- **注意事项/最佳实践**：
  - 位置参数顺序必须与定义一致
  - 关键字参数可提升调用时的可读性，尤其是多参数时
  - 混合调用时，位置参数必须在前：`func(1, 2, key=3)` ✅，`func(key=3, 1, 2)` ❌
- **权衡与替代**：
  - 位置参数简洁但顺序依赖；关键字参数显式但冗长
  - 参数过多（> 5 个）考虑用配置对象或字典传参
- **小结**：位置参数按顺序传递，关键字参数按名称传递；混合使用时注意顺序规则。

### 3. 默认参数
- **动机**：为可选参数提供默认值，减少调用时的参数数量，提升 API 灵活性。
- **核心概念**：
  - 定义时指定默认值：`def func(a, b=10):`
  - 调用时可省略有默认值的参数
  - 默认参数必须在位置参数之后
- **使用场景/模式**：
  - 可选配置参数（如文件编码、日志级别）
  - 提供向后兼容的 API（新增可选参数不破坏旧代码）
- **示例**：
```python
# 带默认参数的函数
# 说明：name 默认为 'Guest'，可省略
def greet(name='Guest'):
    print(f"Hello, {name}!")
greet()           # 输出：Hello, Guest!
greet('Charlie')  # 输出：Hello, Charlie!
# 多个默认参数
# 说明：a 和 b 有默认值，可选择性覆盖
def add(a=0, b=0):
    return a + b
print(add())        # 输出：0
print(add(5))       # 输出：5
print(add(5, 3))    # 输出：8
print(add(b=10))    # 输出：10（仅覆盖 b）
```
- **注意事项/最佳实践**：
  - **陷阱**：不要使用可变对象（如 `[]`、`{}`）作为默认值，改用 `None` 并在函数体初始化
  ```python
  # ❌ 错误示例
  def append_item(x, bucket=[]):  # bucket 是可变对象，会在多次调用间共享
      bucket.append(x)
      return bucket
  # ✅ 正确写法
  def append_item(x, bucket=None):
      bucket = [] if bucket is None else bucket
      bucket.append(x)
      return bucket
  ```
  - 默认参数应放在位置参数之后：`def func(a, b=10)` ✅，`def func(a=10, b)` ❌
- **小结**：默认参数提供可选配置，减少必填参数；避免使用可变对象作为默认值。

### 4. 返回值与 return 语句
- **动机**：函数计算结果需要返回给调用者，供后续使用；而非仅在函数内打印。
- **核心概念**：
  - `return` 语句返回值并结束函数执行
  - 无 `return` 或 `return` 无值时，默认返回 `None`
  - 可返回任意类型：数字、字符串、列表、元组等
  - 可返回多个值（打包为元组）
- **使用场景/模式**：
  - 计算型函数：返回计算结果供后续使用
  - 查询型函数：返回查找到的数据
  - 转换型函数：返回处理后的数据
- **示例**：
```python
# 返回单个值
# 说明：计算两数之积并返回
def multiply(a, b):
    return a * b
result = multiply(4, 5)
print(f"The product is {result}")  # 输出：The product is 20
# 返回多个值（元组）
# 说明：同时返回商和余数
def divide_with_remainder(a, b):
    quotient = a // b
    remainder = a % b
    return quotient, remainder  # 返回元组
q, r = divide_with_remainder(10, 3)
print(f"Quotient: {q}, Remainder: {r}")  # 输出：Quotient: 3, Remainder: 1
# 条件返回
# 说明：根据条件提前返回
def get_grade(score):
    if score >= 90:
        return 'A'
    elif score >= 80:
        return 'B'
    elif score >= 70:
        return 'C'
    return 'D'  # 默认情况
print(get_grade(85))  # 输出：B
```
- **注意事项/最佳实践**：
  - 函数应有明确的返回类型（或注释说明）
  - 仅打印不返回（`print` 而非 `return`）会降低复用性
  - 多个 `return` 路径时，确保所有路径都有返回值或都返回 `None`
- **权衡与替代**：
  - 返回多值时，元组解包直观但需记住顺序；可改用字典或数据类提升可读性
- **小结**：`return` 将计算结果返回给调用者；无返回或仅打印会限制函数复用性。

### 5. 变量作用域：局部变量与全局变量
- **动机**：理解变量的可见范围，避免命名冲突与意外修改全局状态。
- **核心概念**：
  - **局部变量**：函数内定义，仅在函数内可见，函数返回后销毁
  - **全局变量**：函数外定义，整个程序可见
  - **变量遮蔽（shadowing）**：函数内同名局部变量会遮蔽全局变量
  - 参数变量、循环变量也是局部变量
- **使用场景/模式**：
  - 函数内部计算用局部变量，避免污染全局命名空间
  - 全局常量（如配置）用大写命名：`MAX_SIZE = 100`
  - 修改全局变量需用 `global` 关键字（但不推荐）
- **示例**：
```python
# 变量遮蔽示例
# 说明：函数内 x 是局部变量，不影响全局 x
x = 10  # 全局变量
def foo():
    x = 5  # 局部变量，遮蔽全局 x
    print(f"Inside function: x = {x}")
foo()  # 输出：Inside function: x = 5
print(f"Outside function: x = {x}")  # 输出：Outside function: x = 10
# 参数也是局部变量
# 说明：width 和 height 仅在 draw_box 内可见
def draw_box(width, height):
    for i in range(height):  # i 也是局部变量
        print('*' * width)
draw_box(3, 2)
# print(width)  # 错误！width 在函数外不存在
```
- **注意事项/最佳实践**：
  - 优先使用局部变量，减少全局状态
  - 避免在函数内修改全局变量（如需要，用 `global` 声明，但通常是代码坏味道）
  - 变量遮蔽可能引起混淆，注意命名冲突
- **权衡与替代**：
  - 需要跨函数共享状态时，优先通过参数传递或返回值，而非全局变量
  - 复杂状态管理考虑使用类（面向对象）
- **小结**：局部变量仅在函数内可见；全局变量整个程序可见；优先使用局部变量保持函数独立性。

### 6. 导入与复用：内置函数与模块
- **动机**：利用 Python 内置函数与标准库，避免重复造轮子；组织代码为模块便于跨项目复用。
- **核心概念**：
  - **内置函数**：直接可用，如 `print()`、`input()`、`len()`、`round()`
  - **标准库模块**：需导入，如 `math`、`random`
  - **导入语法**：
    - `import module`：导入整个模块，调用：`module.function()`
    - `from module import function`：导入特定函数，直接调用：`function()`
  - **自定义模块**：将函数定义在 `.py` 文件中，其他文件可导入
- **使用场景/模式**：
  - 数学计算：`import math` → `math.sqrt()`、`math.pi`
  - 随机数生成：`import random` → `random.randint()`、`random.choice()`
  - 跨文件复用：将通用函数放在独立模块中
- **示例**：
```python
# 导入内置模块
# 说明：使用 math 模块的数学函数

num = 16
print(math.sqrt(num))  # 输出：4.0
print(math.pi)         # 输出：3.141592653589793
# 部分导入
# 说明：仅导入需要的函数，简化调用
dice = randint(1, 6)  # 生成 1-6 的随机整数
color = choice(['red', 'blue', 'green'])  # 随机选择颜色
print(f"Dice: {dice}, Color: {color}")
# 自定义模块示例（假设有 myutils.py）
# myutils.py 内容：
# def add(a, b):
#     return a + b
# 在另一个文件中导入
# import myutils
# result = myutils.add(5, 3)
```
- **注意事项/最佳实践**：
  - 导入语句通常放在文件开头
  - `import *` 导入所有内容会污染命名空间，不推荐
  - 模块名应简洁且无冲突，使用小写加下划线
  - 自定义模块中，将测试代码放在 `if __name__ == '__main__':` 块内，避免导入时执行
- **小结**：通过 `import` 导入内置或自定义模块，复用现有功能；标准库提供丰富工具，减少重复开发。

## 最佳实践
- 函数名使用小写加下划线（`snake_case`），保持描述性；避免使用保留字。
- 默认参数避免使用可变对象（`list`/`dict`），改用 `None` 并在函数体初始化。
- 函数应保持单一职责，避免过长（建议不超过 20 行）；复杂逻辑拆分为多个小函数。
- 优先使用局部变量；需要跨函数共享数据时，通过参数传递或返回值，避免全局变量。
- 返回值优于仅打印；确保函数有明确的输入输出契约。
- 导入语句放在文件开头；避免 `import *`，显式导入需要的函数或模块。
