## 概要
- 目标：掌握UNIX文件系统的导航、基本文件操作命令，并熟悉Vim文本编辑器的基本使用。
- 范围：覆盖`ls`, `cd`, `pwd`, `mkdir`, `rm`, `cp`, `mv`等文件管理命令的实践，以及Vim的模式切换、插入、保存、退出、复制、粘贴、删除等核心操作；不涉及高级Vim配置或Shell脚本编程。

## 学习目标
1. 能够熟练使用`ls`, `cd`, `pwd`命令进行文件系统导航和查看。
2. 掌握`mkdir`, `rm`, `cp`, `mv`等命令进行文件和目录的创建、删除、复制和移动。
3. 理解Vim编辑器的三种主要模式（普通模式、插入模式、可视模式）及其切换。
4. 能够使用Vim进行文本的插入、保存、退出、复制、粘贴和删除等基本编辑操作。
5. 了解UNIX系统访问方式，包括WSL、虚拟机和SSH。

## 关键知识点

### 1. 访问UNIX终端
- **动机**：在不同操作系统环境下（Windows, macOS, Linux）访问UNIX终端是进行后续操作的基础。
- **核心概念**：
  - **Windows**：推荐安装并激活WSL (Windows Subsystem for Linux)，通过`wsl.exe`使用终端。也可使用VirtualBox安装虚拟机。
  - **macOS**：终端应用自带SSH客户端，可连接远程Linux服务器。也可安装Homebrew获取额外工具，或使用VirtualBox安装虚拟机。
  - **Linux**：直接使用`gnome-terminal`或`xterm`等命令启动bash shell。
  - **SSH**：`ssh username@hostname.com`用于连接远程Linux服务器。
- **使用场景/模式**：根据个人操作系统选择最便捷的终端访问方式。
- **示例**：
```bash
# Windows下启动WSL终端
wsl.exe
# macOS/Linux下连接远程服务器
ssh your_username@remote_host.com
```
- **注意事项/最佳实践**：WSL安装可能耗时较长；使用在线VM需注意账户和费用；SSH是连接远程服务器的标准方式。
- **小结**：多种方式可访问UNIX终端，WSL和SSH是跨平台访问的常用且高效手段。

### 2. 文件系统导航与基本文件操作
- **动机**：熟练的文件系统导航和操作是UNIX/Linux环境下高效工作的基石。
- **核心概念**：
  - **特殊目录**：
    - `~`：用户主目录。
    - `/`：根目录。
    - `.`：当前目录。
    - `..`：父目录。
  - **导航命令**：
    - `pwd`：打印当前工作目录 (Print Working Directory)。
    - `cd <directory>`：改变当前目录 (Change Directory)。
  - **文件/目录操作命令**：
    - `ls`：列出目录内容 (List files)。`ls -al`显示所有文件（包括隐藏文件）及详细信息。
    - `mkdir <directory>`：创建目录 (Make Directory)。
    - `rm <file>`：删除文件 (Remove file)。
    - `rm -r <directory>`：递归删除目录及其内容。
    - `rm -f <file>`：强制删除文件。
    - `rm -rf <directory>`：强制递归删除目录及其内容（**慎用！**）。
    - `cp <source> <destination>`：复制文件或目录。
    - `mv <source> <destination>`：移动或重命名文件或目录。
    - `cat > <file>`：将标准输入写入文件。
    - `zip -r <archive.zip> <directory>`：压缩目录。
    - `unzip <archive.zip>`：解压缩文件。
- **使用场景/模式**：创建项目目录、组织文件、删除不再需要的文件、备份和恢复文件。
- **示例**：
```bash
# 检查当前目录
pwd
# 切换到根目录，然后列出内容，再回到主目录
cd /
ls
cd ~
ls
# 创建一个新目录
mkdir tutorial1
# 创建一个文件并写入内容
cat > a.txt
Hello Unix!
# (按Ctrl+D结束输入)
# 移动文件到新目录
mv a.txt tutorial1/
# 压缩目录
zip -r files.zip tutorial1
# 恢复目录并删除原始目录
unzip files.zip
rm -rf tutorial1
```
- **注意事项/最佳实践**：
  - `rm -rf`命令非常强大且危险，使用前务必确认目标，避免误删重要数据。
  - 熟悉`man`命令查看命令帮助。
  - 善用`tab`键进行命令和文件名的自动补全。
- **小结**：通过`pwd`, `cd`, `ls`, `mkdir`, `rm`, `cp`, `mv`等命令，可以高效地在UNIX文件系统中进行导航和管理。

### 3. Vim文本编辑器基础
- **动机**：Vim是UNIX/Linux环境下广泛使用的强大文本编辑器，掌握其基本操作对于命令行开发和系统管理至关重要。
- **核心概念**：
  - **Vim模式**：
    - **普通模式 (Normal Mode)**：Vim的默认模式，用于导航、删除、复制、粘贴等操作。所有命令都是单键触发。
    - **插入模式 (Insert Mode)**：用于输入文本。通过按`i`, `a`, `o`等键进入。
    - **可视模式 (Visual Mode)**：用于选择文本块，进行复制、删除等操作。通过按`v`键进入。
  - **基本操作**：
    - **进入Vim**：`vim <filename>`。
    - **进入插入模式**：`i` (在当前光标前插入), `a` (在当前光标后插入), `o` (在当前行下方插入新行)。
    - **退出插入模式**：按`Esc`键。
    - **保存文件**：在普通模式下输入`:w`然后回车。
    - **退出Vim**：在普通模式下输入`:q`然后回车。
    - **保存并退出**：在普通模式下输入`:wq`或`ZZ`然后回车。
    - **不保存退出**：在普通模式下输入`:q!`然后回车。
    - **复制 (Yank)**：在普通模式下，`yy`复制当前行，`yw`复制一个单词。在可视模式下，选择文本后按`y`。
    - **粘贴 (Put)**：在普通模式下，`p`粘贴到光标后，`P`粘贴到光标前。
    - **删除 (Delete)**：在普通模式下，`dd`删除当前行，`dw`删除一个单词，`x`删除光标下的字符。
  - **语法高亮**：在普通模式下输入`:syntax on`。
- **使用场景/模式**：编辑配置文件、编写代码、快速修改文本文件。
- **示例**：
```bash
# 创建并编辑一个Java文件
vim Hello.java
# (进入Vim后，按i进入插入模式，输入Java代码)
# public class Hello {
#   public static void main(String[] args) {
#     System.out.println("Hello world");
#   }
# }
# (按Esc退出插入模式，然后输入:wq保存并退出)

# 编译Java代码
javac Hello.java
# 运行Java程序
java Hello
```
- **注意事项/最佳实践**：
  - Vim是模式化的编辑器，理解模式切换是学习Vim的关键。
  - 熟悉常用快捷键可以极大提高编辑效率。
  - 可以在线查找Vim教程和速查表。
- **小结**：Vim是一款高效且高度可配置的文本编辑器，通过掌握其模式和基本命令，可以显著提升命令行下的文本处理能力。

## 最佳实践
- 始终使用`pwd`确认当前目录，避免在错误位置操作文件。
- 在使用`rm -rf`时，务必谨慎，可以先用`ls -R`确认要删除的内容。
- 熟悉Vim的普通模式命令，尽量减少进入插入模式的次数，以提高编辑效率。
- 善用Vim的可视模式进行文本选择和块操作。
- 对于不熟悉的命令，先使用`man`命令查看其用法和选项。
