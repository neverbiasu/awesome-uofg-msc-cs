## 概要
- **目标**：掌握 Unix 文件系统的导航，以及创建、删除、复制和移动文件与目录的命令。
- **范围**：涵盖访问 Unix 终端、文件系统层次结构、核心导航与操作命令，以及文件压缩。

## 学习目标
1. **识别**并使用多种方法（如 SSH、WSL）访问 Unix 终端。
2. **理解**文件系统层次结构，包括特殊目录（`/`, `~`, `.`, `..`）以及绝对路径和相对路径的区别。
3. **掌握**核心导航命令（`pwd`, `ls`, `cd`）。
4. **掌握**文件和目录操作命令（`mkdir`, `rm`, `cp`, `mv`）。
5. **能够**使用 `zip` 和 `unzip` 压缩和解压文件。

## 关键知识点

### 1. 访问 Unix 终端
- **动机**：在管理文件系统之前，您需要先进入命令行环境。
- **核心概念**：
  - **SSH (Secure Shell)**：连接到远程 Linux 服务器的标准方式。命令通常是 `ssh your_username@remote_host.com`。
  - **WSL (Windows Subsystem for Linux)**：对于 Windows 用户，WSL 提供了一个完整的 Linux 环境，可通过运行 `wsl.exe` 来访问。
  - **macOS/Linux 终端**：这两种操作系统都提供了内置的终端应用程序，可直接访问类 Unix 的 shell。
- **小结**：无论您的机器是本地的还是远程的，像 SSH、WSL 和内置终端这样的工具都提供了进入 Unix shell 的入口点。

### 2. 文件系统层次结构
- **动机**：为了有效地导航，您必须首先理解地图。Unix 文件系统是一个分层的树状结构。
- **核心概念**：
  - **根目录 (`/`)**：整个文件系统的唯一的顶级目录。
  - **主目录 (`~`)**：您的个人目录，您拥有完全的权限来创建和管理文件。
  - **当前目录 (`.`)**：对您当前所在目录的简写引用。
  - **父目录 (`..`)**：对您当前位置上一级目录的简写引用。
  - **绝对路径**：从根目录开始的路径（例如 `/home/user/documents`）。无论您当前的位置在哪里，它都是明确的。
  - **相对路径**：从您当前目录开始的路径（例如 `../images` 或 `./notes`）。
- **小结**：理解树状结构以及绝对路径和相对路径之间的区别，是所有文件系统操作的基础。

### 3. 核心导航命令
- **动机**：这三个命令是在文件系统中定位自己和四处移动的基本工具。
- **核心概念**：
  - **`pwd` (Print Working Directory)**：显示您当前所在目录的绝对路径。
  - **`ls` (List)**：列出当前目录的内容（文件和子目录）。常用选项包括：
    - `ls -l`：长格式，显示权限、所有者、大小和修改日期。
    - `ls -a`：显示所有文件，包括隐藏文件（以点 `.` 开头的文件）。
  - **`cd` (Change Directory)**：用于移动到不同的目录。
    - `cd /home/user`：导航到绝对路径。
    - `cd ../project`：导航到相对路径。
    - `cd`：不带参数时，导航到您的主目录 (`~`)。
- **小结**：使用 `pwd` 知道您在哪里，使用 `ls` 查看周围有什么，使用 `cd` 进行移动。

### 4. 文件和目录操作
- **动机**：这些命令允许您创建、组织和删除构成文件系统的文件和目录。
- **核心概念**：
  - `mkdir dir`: 创建一个名为 `dir` 的新目录。
  - `cp source destination`: 复制文件或目录。使用 `cp -r` 递归地复制目录及其内容。
  - `mv source destination`: 移动或重命名文件或目录。
  - `rm file`: 删除（delete）一个文件。使用 `rm -r dir` 递归地删除一个目录。
- **注意事项/最佳实践**：
  - 使用 `rm` 时要格外小心，特别是带有 `-r`（递归）和 `-f`（强制）标志时。命令行上没有回收站；删除是永久性的。
  - `mv` 是重命名文件的标准方法（例如 `mv old-name.txt new-name.txt`）。
- **示例工作流**：
  ```bash
  # 创建一个项目目录并进入
  mkdir my_project && cd my_project
  # 创建一个笔记文件
  touch notes.txt
  # 复制它作为备份
  cp notes.txt notes.bak
  # 创建一个归档目录并将备份文件移入
  mkdir archive
  mv notes.bak archive/
  # 删除原始文件
  rm notes.txt
  ```

### 5. 归档与压缩
- **动机**：将多个文件捆绑成一个单独的归档文件，以便于传输或存储。
- **核心概念**：
  - `zip archive.zip files...`: 将一个或多个 `files` 压缩成一个 `archive.zip` 文件。
  - `unzip archive.zip`: 将 `archive.zip` 的内容解压到当前目录。
- **示例**：
  ```bash
  # 压缩整个目录
  zip -r project_archive.zip my_project/
  # 将归档文件解压到新位置
  mkdir restored_project
  cd restored_project
  unzip ../project_archive.zip
  ```

## 最佳实践
- **确认位置**：在运行像 `rm` 这样的破坏性命令之前，始终使用 `pwd` 来确保您在正确的目录中。
- **使用 Tab 自动补全**：按 `Tab` 键自动补全文件名和目录名。这可以减少拼写错误并节省时间。
- **警惕 `rm -rf`**：此命令会强制递归删除文件。一个小小的拼写错误就可能清除重要数据。在按 Enter 键之前，请仔细检查您的命令。
