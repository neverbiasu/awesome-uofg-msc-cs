## 概要
- **目标**：通过重定向 I/O 到文件和在命令间使用管道，来掌握在 shell 中控制数据流的方法。
- **范围**：涵盖标准 I/O 流、重定向（`>`、`>>`、`<`）、管道（`|`），以及像变量和引用这样的基本 shell 概念。

## 学习目标
1. **理解**三个标准流：`stdin`、`stdout` 和 `stderr`。
2. **使用**重定向操作符从文件读取输入和向文件写入输出。
3. **使用**管道操作符（`|`）将命令链接起来以进行复杂的数据处理。
4. **理解** shell 变量的基础知识和引用的重要性。

## 关键知识点

### 标准 I/O 流
- **动机**：您在 shell 中运行的每个命令都与三个标准数据流一起工作，这允许可预测的输入和输出处理。
- **核心概念**：
  - **`stdin` (标准输入)**：文件描述符 `0`。命令的默认输入源，通常是键盘。
  - **`stdout` (标准输出)**：文件描述符 `1`。命令正常输出的默认目的地，通常是屏幕。
  - **`stderr` (标准错误)**：文件描述符 `2`。命令错误信息的默认目的地，通常也是屏幕。
- **小结**：理解这三个流是控制数据来源和去向的关键。

### I/O 重定向
- **动机**：将命令的输出保存到文件，或使其从文件读取输入，而不是与终端交互。
- **核心概念**：
  - **`>` (重定向 stdout)**：将命令的标准输出发送到一个文件，如果文件已存在则会**覆盖**它。
    - `ls -l > file_listing.txt`
  - **`>>` (追加 stdout)**：将命令的标准输出追加到一个文件的末尾，如果文件不存在则会创建它。
    - `echo "Log entry at $(date)" >> system.log`
  - **`<` (重定向 stdin)**：使命令从文件而不是键盘读取其标准输入。
    - `sort < unsorted_names.txt`
  - **`2>` (重定向 stderr)**：将标准错误重定向到一个文件。这对于将错误消息与正常输出分开很有用。
    - `find / -name "*.log" > results.txt 2> errors.log`
- **小结**：重定向操作符让您能够对命令的输入和输出进行文件级控制。

### 管道 (`|`)
- **动机**：将多个命令直接连接起来，将一个命令的输出直接作为另一个命令的输入，而无需使用临时文件。这体现了 Unix “小工具做好一件事”的哲学。
- **核心概念**：
  - 管道 `|` 操作符接收其左侧命令的 `stdout`，并将其用作右侧命令的 `stdin`。
  - 可以将任意数量的命令链接在一起，形成一个“管道线”。
  - 管道中的命令是并发运行的，数据在它们之间流动。
- **示例**：一个常见的模式是获取数据，搜索特定内容，然后格式化结果。
  ```bash
  # 获取网页内容，查找包含特定模式的行，并提取前几行
  curl -s https://www.bbc.co.uk/weather/2648579 | grep "wr-day__weather-type-description" | head -n 3
  ```
- **小结**：管道是在命令行上创建复杂数据处理工作流的强大功能。

### Shell 基础：变量和引用
- **动机**：要编写更复杂、更健壮的命令或脚本，您必须了解 shell 如何解释变量和特殊字符（元字符）。
- **核心概念**：
  - **变量**：存储数据。使用 `MY_VAR="some value"` 赋值（`=`周围没有空格），并使用 `$MY_VAR` 引用。
  - **元字符**：对 shell 有特殊含义的字符，如 `*`、`$`、`|`、`>`。
  - **引用**：控制 shell 如何解释元字符。
    - **双引号 (`"`)**：弱引用。允许变量替换（`$VAR`），但阻止其他特殊字符（如空格或 `*`）被解释。
    - **单引号 (`'`)**：强引用。禁用所有特殊含义；所有内容都被视为文字字符串。
    - **反斜杠 (`\`)**：转义紧随其后的单个字符，移除其特殊含义。
- **示例**：
  ```bash
  GREETING="Hello World"
  echo "弱引用: $GREETING"   # 输出: 弱引用: Hello World
  echo '强引用: $GREETING' # 输出: 强引用: $GREETING
  ```

## 最佳实践
- **分步构建管道**：在创建复杂的管道时，先运行第一个命令，检查其输出，然后添加下一个命令，依此类推。这使调试变得容易得多。
- **始终引用变量**：在使用变量时，请用双引号将其括起来（例如 `echo "$MY_VAR"`），以防止变量中包含空格或其他特殊字符时出现意外行为。
- **了解覆盖与追加的区别**：当您想创建一个新文件时使用 `>`，当您想向现有文件（如日志）添加内容时使用 `>>`。
