## 概要
- **目标**：理解 Unix 操作系统的基础特性和设计原则。
- **范围**：涵盖多用户、多任务、内核/Shell 架构、进程以及文件系统的基本结构等概念。本笔记侧重于 Unix 设计的“是什么”和“为什么”。

## 学习目标
1. **描述** Unix 的多用户和多任务处理能力。
2. **解释** 内核（Kernel）、Shell 和实用工具（Utilities）在 Unix 系统中的角色。
3. **理解** 进程的概念以及系统如何管理多个程序。
4. **认识** Unix 文件系统的基本分层结构。

## 关键知识点

### 1. Unix 主要特性
- **动机**：了解那些使 Unix 成为一个开创性且具影响力的操作系统的特点。
- **核心概念**：
  - **多用户（Multi-user）**：允许多个用户同时使用同一台机器，通常通过终端实现。操作系统通过在不同用户的程序之间进行处理器时间切片来支持此功能。
  - **多任务（Multi-tasking）**：系统可以同时运行多个程序。
  - **分层目录结构（Hierarchical Directory Structure）**：文件被组织在一个树状结构中，这对于组织和维护文件至关重要。
  - **可移植性（Portability）**：大部分 Unix 内核是用 C 语言而非汇编语言编写的，这使得将其适配到不同的硬件平台相对容易。
  - **开发工具（Development Tools）**：Unix 为开发者提供了丰富的支持工具生态系统，如编译器和调试器。
- **小结**：Unix 的核心特性提供了一个强大、灵活且可移植的环境，使其在当时众多系统中脱颖而出。

---

### 2. Unix 基本结构
- **动机**：理解 Unix 操作系统的基本组件以及它们如何相互作用。
- **核心概念**：
  - **内核（The Kernel）**：操作系统的核心。它负责调度程序、管理文件访问和存储、执行安全策略以及执行所有硬件访问。
  - **Shell**：用户与内核交互的接口。它解释用户命令，执行它们，并管理用户的环境。常见的 Shell 包括 Bourne Shell (sh)、C Shell (csh) 和 Bash。
  - **实用工具（Utilities）**：一系列提供标准功能的程序，如文件管理（`ls`, `rm`）、进程管理（`ps`, `kill`）和用户管理（`passwd`）。
- **小结**：Unix 使用分层架构：内核管理系统核心，实用工具提供通用功能，而 Shell 作为用户命令的解释器。

---

### 3. 进程管理
- **动机**：了解 Unix 如何处理正在运行的程序（进程）是管理系统资源和进行故障排查的关键。
- **核心概念**：
  - **进程（Process）**：在 Unix 系统上运行的每个程序都是一个进程。当输入一个命令时，操作系统会创建一个进程控制块（PCB）来保存其状态、优先级和其他信息。
  - **进程管理工具**：
    - `ps`：列出当前正在运行的进程。
    - `kill`：向一个进程发送信号（例如，终止）。
    - `&`：一个在后台运行进程的操作符。
  - **内存管理**：当 RAM 不足时，内核会将一个进程换出（swap out）到磁盘以释放内存。过度的交换（称为“磁盘颠簸”或 'disk thrashing'）会降低系统性能。
- **小结**：Unix 将并发程序作为进程来管理，并提供如 `ps` 和 `kill` 等工具来监控和控制它们。

---

## 最佳实践
- **选择一个现代的 Shell**：尽管存在多种 Shell，但 `bash`（Bourne-Again Shell）或 `zsh` 是现代标准，它们提供了比旧版 Shell 更显著的改进（如历史记录和脚本功能）。
- **善用工具**：理解大多数操作是由小而专注的实用工具执行的，这是 Unix 哲学的核心部分。
