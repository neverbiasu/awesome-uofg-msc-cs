## 概要
- **目标**：学习 Vim 编辑器的基本操作，并理解如何使用它在 UNIX 环境中编写、编译和运行 C 程序。
- **范围**：涵盖 Vim 的核心模式和命令，以及基本的 C 语言工具链工作流程（使用 Vim 编辑，使用 GCC 编译）。

## 学习目标
1. **理解** Vim 的模式化特性（普通模式、插入模式、可视模式）。
2. **执行** 基本的文本编辑：创建、保存、退出、复制、粘贴和删除文本。
3. **使用** `gcc` 编译一个用 Vim 编写的简单 C 程序。
4. **遵循** 在命令行上的标准“编辑-编译-运行”周期。

## 关键知识点

### 1. Vim 入门
- **动机**：Vim 是一个强大的、以键盘为中心的文本编辑器，它预装在大多数 UNIX 系统上，是命令行开发和服务器管理的基本工具。
- **核心概念**：
  - **模式化编辑**：与大多数编辑器不同，Vim 在不同的模式下工作。主要模式有：
    - **普通模式 (Normal Mode)**：默认模式。用于导航和发布命令（如删除或复制文本）。按 `Esc` 键可返回此模式。
    - **插入模式 (Insert Mode)**：用于输入文本。按 `i`（在光标前插入）、`a`（在光标后追加）或 `o`（在下方打开新行）进入此模式。
    - **可视模式 (Visual Mode)**：用于选择文本。按 `v` 键进入此模式。
  - **基本工作流程**：编辑文件的基本流程是：
    1. 打开文件：`vim filename.c`
    2. 进入插入模式：按 `i`
    3. 输入您的代码。
    4. 返回普通模式：按 `Esc`
    5. 保存并退出：输入 `:wq` 并按 Enter。
- **小结**：使用 Vim 的关键是理解其模式化特性。始终清楚自己处于哪种模式。

---

### 2. Vim 核心命令（在普通模式下）
- **动机**：在没有鼠标的情况下高效地执行常见的编辑任务。
- **核心概念**：
  - **保存与退出**：
    - `:w`：写入（保存）文件。
    - `:q`：退出。如果有未保存的更改则会失败。
    - `:wq`：写入并退出。
    - `:q!`：不保存退出（放弃更改）。
  - **编辑**：
    - `dd`：删除当前行。
    - `yy`：Yank（复制）当前行。
    - `p`：在光标后粘贴复制/删除的内容。
    - `u`：撤销上一个操作。
    - `x`：删除光标下的字符。
  - **导航**：虽然箭头键可用，但传统的 Vim 导航在普通模式下使用 `h`（左）、`j`（下）、`k`（上）和 `l`（右）。
- **小结**：学习这些基本命令使您能够执行所有基本的文本编辑操作。

---

### 3. C 语言工具链工作流程
- **动机**：了解在 UNIX 系统上将 C 源代码转换为可执行程序的标准过程。
- **核心概念**：该周期包括三个主要步骤：
    1. **编辑**：使用像 Vim 这样的文本编辑器编写您的源代码。
       - `vim hello.c`
    2. **编译**：使用像 GCC（GNU 编译器集合）或 Clang 这样的编译器将源代码翻译成机器码。`-o` 标志指定输出可执行文件的名称。
       - `gcc hello.c -o hello`
    3. **运行**：执行编译后的程序。
       - `./hello`
- **示例**：让我们创建、编译并运行一个 “Hello, World!” 程序。
  1.  **编辑 `hello.c`**：
      ```c
      #include <stdio.h>

      int main() {
          printf("Hello, World!\n");
          return 0;
      }
      ```
  2.  **编译它**：
      ```bash
      gcc hello.c -o hello
      ```
  3.  **运行它**：
      ```bash
      ./hello
      # 输出: Hello, World!
      ```
- **小结**：“编辑-编译-运行”周期是像 C 这样的编译型语言软件开发的基本工作流程。

## 最佳实践
- **活在普通模式**：尽量将大部分时间花在普通模式下，只在需要输入文本时才进入插入模式。这是通往 Vim 高效之路。
- **经常保存**：养成按 `Esc` 并输入 `:w` 频繁保存工作的习惯。
- **使用编译器警告**：使用 `-Wall` 标志进行编译（例如 `gcc -Wall hello.c -o hello`）以启用所有警告，这可以帮助您及早发现潜在的错误。
