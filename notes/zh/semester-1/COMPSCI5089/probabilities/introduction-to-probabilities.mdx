## 核心定义
*   **实验 (Experiment)**: 具有不确定结果的事件（例如，丢失一艘潜艇）。
*   **结果 (Outcome)**: 实验的结果；世界的某一个特定状态（例如，潜艇在网格坐标[2,3]处）。
*   **样本空间 (Sample Space)**: 实验所有可能结果的集合。
*   **事件 (Event)**: 具有共同属性的部分可能结果的子集（例如，所有位于赤道以南的网格方块）。
*   **概率 (Probability)**: 一个事件的概率是该事件中结果的数量与样本空间中总结果数量的比率。它总是一个介于0和1之间的实数。

## 概率哲学
关于概率的解释主要有两种思想流派。
<Callout title="贝叶斯（拉普拉斯）观点">
  将概率视为**信念的演算**。概率 $$P(A)$$ 衡量我们对事件A为真的*信念程度*。这种观点允许我们在获得新**证据**时更新我们的信念（从**先验**到**后验**）。
</Callout>
<Callout title="频率派观点">
  认为概率是重复事件的**长期频率**。在这种观点下，谈论只能发生一次的事件的概率是没有意义的，比如USS Scorpion号潜艇的位置。
</Callout>

## 概率公理
概率论建立在三个形式化的公理之上。
<Callout title="概率公理">
*   **有界性 (Boundedness)**: 对于任何事件A, $$0 \le P(A) \le 1$$。
*   **归一性 (Unitarity)**: 对于样本空间 $$\sigma$$ 中所有可能结果 $$x$$ 的完整集合，它们的概率之和为1。$$\sum_{x \in \sigma} P(x) = 1$$
*   **加法法则 (Sum Rule)**: 对于任意两个事件A和B，两者之一发生的概率为 $$P(A \lor B) = P(A) + P(B) - P(A \land B)$$。
</Callout>

### 条件概率
条件概率 $$P(A|B)$$ 是指在已知事件B已经发生的情况下，事件A发生的概率。
```math
P(A|B) = \frac{P(A \land B)}{P(B)}
```

## 随机变量与分布
- **随机变量** (例如, $$X$$) 是一个可以取不同值的变量，但我们不知道它的具体值。它可能代表骰子的投掷结果（离散），或一个人的身高（连续）。
- **概率分布** ($$P(X)$$) 定义了一个随机变量不同状态的可能性大小。

### PMF vs. PDF
*   **离散变量** 由**概率质量函数 (PMF)** $$f_X(x)$$ 描述，它给出每个特定结果的概率。对于PMF, $$P(X=x) = f_X(x)$$。
*   **连续变量** 由**概率密度函数 (PDF)** $$f_X(x)$$ 描述，它指定了概率在一定范围内的分布。对于PDF, $$P(X=x) = f_X(x)$$ **不成立**；相反，概率是通过在某个区间上积分得到的。

### 积分归一
任何PMF或PDF在所有可能结果上的总和或积分必须为1。
```math
\sum_i f_X(x_i) = 1 \quad \text{(对于离散PMF)}
```
```math
\int f_X(x) dx = 1 \quad \text{(对于连续PDF)}
```

## 期望
**期望**或**期望值** $$E[X]$$ 是一个随机变量的“平均”值，由每个结果的概率加权。
- 对于连续随机变量: $$E[X] = \int x f_X(x) dx$$
- 对于离散随机变量: $$E[X] = \sum_x x f_X(x)$$
- 随机变量的**均值**就是其期望 $$E[X]$$。
- **方差**是 $$var(X) = E[(X-E[X])^2]$$，衡量的是分布的离散程度。

## 对数概率与似然
为了避免在乘以许多小概率时出现数值下溢，我们经常使用可以相加的**对数概率**。
- **似然** $$L(x_i)$$ 是数据的函数，不是概率。处理**对数似然**通常更方便。
- 概率之积:
  ```math
P(x_1, ..., x_n) = \prod_{i=1}^{n} P(x_i)
```
- 对数概率之和:
  ```math
\log P(x_1, ..., x_n) = \sum_{i=1}^{n} \log P(x_i)
```
