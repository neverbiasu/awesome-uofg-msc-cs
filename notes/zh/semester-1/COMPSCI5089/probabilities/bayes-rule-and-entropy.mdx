## 概要
- **目标**: 理解并应用贝叶斯定理解决涉及条件概率的问题，并能够计算和解释概率分布的熵。
- **范围**: 本笔记涵盖联合概率、边缘概率和条件概率的概念，贝叶斯定理及其应用，以及熵的概念。笔记使用文本分析和瘟疫诊断问题作为示例。

## 学习目标
1. 理解联合概率、边缘概率和条件概率的定义。
2. 能够应用贝叶斯定理来反转条件概率。
3. 理解熵的概念及其与信息和不确定性的关系。
4. 能够计算离散概率分布的熵。

## 关键知识点

### 联合概率、边缘概率和条件概率
- **动机**: 为了模拟多个随机变量之间的关系，我们需要的不仅仅是单个事件的概率。我们需要描述事件组合的概率。
- **核心概念**:
    - **联合概率 `P(X,Y)`**: 两个事件 X 和 Y 同时发生的概率。
    - **边缘概率 `P(X)`**: 单个事件 X 的概率，不考虑其他变量的结果。它可以从联合概率中通过对其他变量的所有结果求和来计算：`P(X) = Σy P(X, y)`。这个过程称为**边缘化**。
    - **条件概率 `P(X|Y)`**: 在事件 Y 已经发生的*前提*下，事件 X 发生的概率。计算公式为 `P(X|Y) = P(X,Y) / P(Y)`。
- **使用场景/模式**:
    - 当我们对事件的共现感兴趣时，使用联合概率，例如看到字符 'h' 跟在 't' 后面的概率。
    - 当我们想知道一个事件的总体概率，而不考虑上下文时，使用边缘概率。
    - 条件概率是预测和推断的基础，例如在给定前一个词的情况下预测句子中的下一个词。
- **示例**:
  在“蝎子”网格示例中，我们有一个 6x8 的网格（48个结果）。
  - 设 X 为事件“行 >= 4”（南），Y 为“列 >= 6”（东）。
  - `P(X) = 24/48 = 0.5` (边缘概率)
  - `P(Y) = 18/48 = 0.375` (边缘概率)
  - `P(X,Y) = 9/48 = 0.1875` (联合概率)
  - `P(X|Y) = P(X,Y) / P(Y) = (9/48) / (18/48) = 0.5` (条件概率)
- **注意事项/最佳实践**:
    - 记住 `P(X|Y)` 和 `P(Y|X)` 是不同的。
    - 对于独立事件，`P(X,Y) = P(X)P(Y)` 且 `P(X|Y) = P(X)`。这是一个特例，通常不成立。
- **小结**: 联合概率、边缘概率和条件概率是推理多个变量及其依赖关系的基石。

### 贝叶斯定理
- **动机**: 通常，我们可以很容易地测量 `P(B|A)`（给定事件A，观察到证据B的概率），但我们真正想知道的是 `P(A|B)`（我们看到证据B，事件A发生的概率）。贝叶斯定理提供了一种“反转”条件概率的方法。
- **核心概念**:
    - **贝叶斯定理**: `P(A|B) = (P(B|A) * P(A)) / P(B)`
    - **术语**:
        - `P(A|B)`: **后验概率** - 我们想知道的。
        - `P(B|A)`: **似然** - 事件产生证据的可能性。
        - `P(A)`: **先验概率** - 我们在看到证据之前对事件的信念。
        - `P(B)`: **证据** (或边缘似然) - 观察到证据的总概率。
- **使用场景/模式**:
    - 医学诊断：给定阳性测试结果（证据），患有某种疾病（事件）的概率是多少？
    - 垃圾邮件过滤：给定电子邮件中的单词（证据），它是垃圾邮件（事件）的概率是多少？
    - 统计推断：在观察数据后更新我们对假设的信念。
- **示例**: 瘟疫X问题。
  - `P(瘟疫)` (先验) = 1/100,000
  - `P(阳性|瘟疫)` (似然) = 0.95 (95% 准确率, 5% 假阴性)
  - `P(阳性|无瘟疫)` = 0.05 (5% 假阳性)
  - 我们想找到 `P(瘟疫|阳性)` (后验)。
  - 使用贝叶斯定理，结果出奇地低，大约是 1/5263。
- **注意事项/最佳实践**:
    - 不要忘记分母 `P(B)`。它至关重要，通过对所有可能性进行边缘化来计算：`P(B) = P(B|A)P(A) + P(B|非A)P(非A)`。
    - 注意“基础率谬误”：即使有强有力的证据 `P(B|A)`，低的先验概率 `P(A)` 也可能意味着后验概率 `P(A|B)` 仍然很低。
- **小结**: 贝叶斯定理是在新证据面前更新信念的基本工具，使我们能够从先验概率转向后验概率。

### 熵
- **动机**: 我们如何量化概率分布中的“惊奇”或“不确定性”？一个平坦、均匀的分布是高度不可预测的，而一个急剧峰值的分布则是非常可预测的。
- **核心概念**:
    - **熵 `H(X)`**: 衡量随机变量平均不确定性或“信息内容”的指标。对于离散变量，它是对数概率的期望值。
    - **公式**: `H(X) = -Σ P(x) * log₂(P(x))`
    - 单位通常是**比特**。一比特的熵对应于一次公平硬币投掷的不确定性。
- **使用场景/模式**:
    - 在信息论中，它给出了从给定分布中编码消息所需的最少比特数。
    - 在机器学习中，它用于决策树（信息增益）和衡量模型预测的“惊奇”程度。
- **示例**: 抛硬币。
  - 对于公平硬币 (`q=0.5`)，`H(X) = -0.5*log₂(0.5) - 0.5*log₂(0.5) = 1` 比特。这是双结果事件可能的最大熵，代表最大的不确定性。
  - 对于有偏硬币 (`q=0.1`)，熵较低，`H(X) ≈ 0.47` 比特，因为结果更可预测。
- **注意事项/最佳实践**:
    - 对数的底决定了单位（底为2是比特，底为e是奈特）。
    - 熵总是非负的。`H(X) >= 0`。
- **小结**: 熵量化了概率分布的不确定性，值越高表示越惊奇和不可预测。

## 最佳实践
- **区分 `P(A|B)` 和 `P(B|A)`**: 它们是不同的，通过贝叶斯定理联系在一起。混淆它们是一个常见的错误。
- **注意基础率**: 在贝叶斯推理中，即使有看似强有力的证据，低的先验概率也会对最终的后验概率产生巨大影响。
- **使用对数似然**: 在计算长序列事件的似然时，使用对数概率的总和（对数似然）来避免因乘以许多小概率而导致的数值下溢。
- **熵作为惊奇的度量**: 使用熵来推理系统的可预测性。贝叶斯更新后熵的下降意味着知识的增加。
