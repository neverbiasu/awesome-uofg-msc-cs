## 概述

向量是线性代数中的一个基本概念，在机器学习和数据科学中是数据的“通用语言”(*lingua franca*)。它们提供了一种数学结构来表示、比较和操作数据点。本页涵盖了向量的核心概念，包括其定义、标准运算（加法、标量乘法）、衡量其大小的方法（范数）及其几何属性（内积）。

## 什么是向量？

向量可以通过几种方式来理解：
- **作为数字元组：** 一个有序的实数列表，如 $$[x_1, x_2, ..., x_n]$$。
- **作为空间中的一个点：** 坐标系中的一个位置。例如，向量 $$[5, 7]$$ 代表了二维平面中的一个点。
- **作为从原点出发的箭头：** 空间中的一个方向和大小。

在数据科学的背景下，“空间中的点”这一模型通常最有用，因为它允许我们将数据视为存在于一个几何空间中。

<Callout title="表示法">
- 向量通常用粗体小写字母表示，例如 **x**。
- 所有 n 维实值向量的集合用 $$R^n$$ 表示。
</Callout>

## 基本向量运算

**向量空间**是一个由向量组成的集合，其中定义了两种主要运算：向量加法和标量乘法。

### 向量加法
相同维度的向量可以通过将其对应元素相加（逐元素求和）来进行加法运算。

```math
x + y = [x_1 + y_1, x_2 + y_2, ..., x_n + y_n]
```

### 标量乘法
向量可以与一个标量（一个单一的实数）相乘，这将按该数值缩放向量。这也是一个逐元素的操作。

```math
ax = [ax_1, ax_2, ..., ax_n]
```

### 代码示例：NumPy 中的基本运算

```python
import numpy as np

# 定义两个向量
x = np.array([0, 1, 1])
y = np.array([4, 5, 6])
a = 2

# 加法
print(f"x + y = {x + y}")

# 标量乘法
print(f"a * x = {a * x}")
```

## 衡量向量：范数

**范数**（Norm）是一个函数，它为向量空间中的每个向量赋予一个严格为正的长度或大小。它使我们能够衡量一个向量的“大小”。

### L2 范数（欧几里得范数）
最常见的范数是 L2 范数，也称为向量的欧几里得长度。它对应于向量在空间中的直观长度。

```math
||x||_2 = \sqrt{x_1^2 + x_2^2 + ... + x_n^2}
```

在 NumPy 中，可以直接使用 `np.linalg.norm()` 计算。

```python
x = np.array([1.0, 10.0, -5.0])
# ||x|| = 11.22
print(f"L2 norm of x: {np.linalg.norm(x)}")
```

### 其他范数 (Lp-norms)
范数的概念可以推广到 Lp-范数（或闵可夫斯基范数），其定义为：

```math
||x||_p = (\sum_{i=1}^{n} |x_i|^p)^{1/p}
```

| p | 表示法 | 通用名称 | 用途 |
|---|---|---|---|
| 2 | $$||x||_2$$ | 欧几里得范数 | 标准的空间距离。 |
| 1 | $$||x||_1$$ | 曼哈顿范数 | 衡量网格上的距离（例如城市街区）。 |
| ∞ | $$||x||_\infty$$ | 最大范数 | 获取向量中的最大元素。 |
| 0 | $$||x||_0$$ | “零范数” | 计算非零元素的数量。 |


### 单位向量和归一化
**单位向量**是范数为 1 的向量。它代表一个“纯方向”。任何向量都可以通过除以其范数来归一化为单位向量。

<Callout title="归一化公式">
要使用欧几里得范数对向量 **x** 进行归一化，你可以将其乘以其长度的倒数：
$$
\hat{x} = \frac{x}{||x||_2}
$$
</Callout>

## 向量的几何学：内积

两个向量的**内积**（或点积）决定了它们之间的夹角，是理解它们几何关系的基本运算。

```math
x \cdot y = \sum_{i=1}^{n} x_i y_i
```

内积与**余弦距离**有关，后者衡量两个向量之间的夹角 $$ \theta $$：

```math
\cos(\theta) = \frac{x \cdot y}{||x|| \cdot ||y||}
```
对于单位向量，这简化为 $$ \cos(\theta) = x \cdot y $$。内积为 0 意味着向量是**正交**的（成 90 度角）。

<Callout title="警告：np.inner() vs np.dot()">
在 NumPy 中，对于一维数组（向量），`np.inner(a, b)` 和 `np.dot(a, b)` 计算的是相同的内积。然而，对于二维数组（矩阵），它们的行为有很大差异。对于矩阵乘法，使用 `@` 运算符或 `np.matmul()` 更安全、更清晰。
</Callout>

## 数据科学中的向量

- **数据表示**：数据集通常存储为二维表格，其中每一**行**可以看作是代表单个观测值的特征向量。
- **数据中心化**：一个常见的预处理步骤是通过计算**均值向量**（所有行向量的逐元素均值）并从每个向量中减去它来“中心化”数据集。这使得数据集的均值为零。
- **维度诅咒**：虽然向量功能强大，但在低维空间（例如 d=2 或 d=3）中效果很好的算法，在高维空间中往往会失效。随着维度的增加，空间体积呈指数级增长，导致数据变得稀疏。这使得寻找最近邻等任务变得更加困难。

## 关键要点
- 向量是有序的数字列表，可以表示空间中的点、数据或特征。
- 向量空间定义了**向量加法**和**标量乘法**的规则。
- **范数**（如 L1 和 L2）衡量向量的长度或大小。
- **内积**（点积）衡量两个向量之间的夹角，是正交和投影等概念的基础。
- 在数据科学中，向量用于表示数据点，而像**中心化**这样的操作是常见的预处理步骤。
- 要注意**维度诅咒**，即高维空间具有反直觉的特性，可能使分析变得困难。
