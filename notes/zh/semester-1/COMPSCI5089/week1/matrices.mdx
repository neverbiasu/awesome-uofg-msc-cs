## 概述

矩阵是数字的二维数组，是线性代数和数据科学中的基本工具。它们可以表示数据、方程组，或者最重要的是，表示将向量从一个空间转换到另一个空间的**线性映射**。本页涵盖了矩阵的定义、基本运算，以及它们作为可以缩放、旋转和错切向量空间的算子的作用。

## 什么是矩阵？

矩阵是排列成行和列的数字的矩形网格。一个 $$n \times m$$ 的矩阵有 *n* 行和 *m* 列。

<Callout title="表示法">
- 矩阵通常用粗体大写字母表示，例如 **A**。
- 矩阵 **A** 中第 *i* 行和第 *j* 列的元素写作 $$A_{i,j}$$。
- 所有 $$n \times m$$ 实值矩阵的集合表示为 $$R^{n \times m}$$。
</Callout>

## 基本矩阵运算

### 加法和减法
两个**相同大小**的矩阵可以通过逐元素执行运算来进行加法或减法。

```math
(A+B)_{i,j} = A_{i,j} + B_{i,j}
```

### 标量乘法
矩阵可以与一个标量相乘，这涉及到将矩阵的每个元素都乘以该标量。

```math
(cA)_{i,j} = c \cdot A_{i,j}
```

### 矩阵-向量乘法
将矩阵 **A** 应用于向量 **x**（写作 **Ax**）会转换该向量。这是矩阵列的加权和，其中权重是向量的元素。

如果 **A** 是一个 $$n \times m$$ 矩阵，而 **x** 是一个 *m* 维向量，则结果 **y** 是一个 *n* 维向量。

```math
 y = Ax
```

### 矩阵-矩阵乘法
两个矩阵相乘，**C = AB**，代表了两个线性映射的**复合**。如果 **A** 是 $$p \times q$$ 矩阵，**B** 是 $$q \times r$$ 矩阵，则结果矩阵 **C** 将是 $$p \times r$$ 矩阵。

<Callout title="顺序很重要！">
矩阵乘法是**不可交换的**，这意味着在大多数情况下：
$$ AB \neq BA $$
运算的顺序对应于从右到左读取。例如，在 **BAx** 中，首先将变换 **A** 应用于 **x**，然后将 **B** 应用于结果。
</Callout>

### 转置
矩阵 **A** 的**转置**，表示为 $$A^T$$，是通过交换其行和列形成的。如果 **A** 是 $$n \times m$$ 矩阵，那么 $$A^T$$ 是 $$m \times n$$ 矩阵。

```python
import numpy as np

A = np.array([[1, 2, 3], [4, 5, 6]])
# A 是一个 2x3 矩阵

# A.T 是 3x2 的转置矩阵
print(A.T)
```

## 作为线性映射的矩阵

对矩阵最强大的解释是作为**线性映射**（或线性变换）。如果一个映射满足以下两个属性，则它是线性的：
1.  **可加性**: $$f(x+y) = f(x) + f(y)$$
2.  **齐次性**: $$f(cx) = c \cdot f(x)$$

所有矩阵变换都是线性映射。它们可以表示像缩放、旋转和错切这样的操作，但不能表示平移（因为平移不保留原点）。

## 特殊类型的矩阵

| 类型 | 描述 |
|---|
| **单位矩阵 (I)** | 对角线上为 1，其他位置为 0 的方阵。它相当于数字 1 的矩阵（即 $$AI = IA = A$$）。 |
| **零矩阵** | 所有元素都等于 0 的矩阵。 |
| **对角矩阵** | 只有对角线上的元素可以非零的矩阵。表示沿坐标轴的缩放。 |
| **对称矩阵** | 等于其转置的方阵 ($$A = A^T$$)。协方差矩阵是对称的。 |
| **正交矩阵** | 其转置也是其逆的方阵 ($$A^T = A^{-1}$$)。代表纯旋转。 |

## 矩阵的性质

- **行列式 (det(A))**：一个标量值，表示矩阵使空间扩张或收缩的程度。如果 `det(A) = 0`，则该矩阵是**奇异的**，意味着它至少折叠了一个维度并且不可逆。
- **迹 (Tr(A))**：方阵对角线元素的总和。对于协方差矩阵，迹等于数据中的总方差。
- **秩 (Rank)**：矩阵的非零奇异值的数量，对应于线性独立的列或行的数量。它告诉你输出空间的维度。

## 矩阵的逆和分解

- **逆**：方阵 **A** 的逆，表示为 $$A^{-1}$$，“撤销” **A** 的操作。它仅在矩阵非奇异（即 `det(A) \neq 0`）时存在。
- **特征分解**：将一个方阵分解为其特征值和特征向量。这揭示了矩阵的基本属性，例如其主要作用方向。
- **奇异值分解 (SVD)**：一种更通用的分解方法，适用于*任何*矩阵（不仅仅是方阵）。它是计算线性代数的基石，用于 PCA、降噪等。

## 关键要点
- 矩阵是表示对向量进行线性变换的二维数组。
- 基本运算包括加法、标量乘法和矩阵乘法，其中顺序至关重要。
- 转置 ($$A^T$$) 交换矩阵的行和列。
- 像单位矩阵、对角矩阵和对称矩阵这样的特殊矩阵具有重要的属性和用途。
- **行列式**和**迹**是方阵的重要标量属性。
- **矩阵分解**（如特征分解和 SVD）是分析矩阵的强大技术，并且是许多数据科学算法（如 PCA）的核心。
