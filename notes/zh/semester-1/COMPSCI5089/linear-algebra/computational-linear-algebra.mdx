## 图作为矩阵
许多现实世界的系统可以被建模为由连接的节点（顶点）和连接（边）组成的网络。这在数学上可以表示为图 $$G = (V, E)$$。

**邻接矩阵** $$A$$ 是一个用于表示有限图的方阵。矩阵的元素指示图中顶点对是否相邻。
- 对于无权图，如果存在从顶点 $$i$$ 到 $$j$$ 的边，则 $$A_{ij} = 1$$，否则为 $$0$$。
- 对于**加权图**，$$A_{ij}$$ 表示连接的权重。

### 从矩阵中获取图属性
- **出度**（离开顶点的边）：每行的总和。
- **入度**（进入顶点的边）：每列的总和。
- **无向图**：矩阵是对称的（$$A = A^T$$）。

## 流分析：离散问题建模
我们可以使用矩阵来模拟动态系统，例如在配送站之间流动的包裹。

- **状态向量 $$x_t$$**：表示系统在时间 $$t$$ 状态的向量（例如，每个配送站的包裹比例）。
- **邻接矩阵 $$A$$**：表示系统如何从一个步骤演变到下一个步骤的线性映射。

下一个时间步 $$t+1$$ 的状态可以计算为：
$$x_{t+1} = A^T x_t$$

这使我们能够使用连续数学的工具来分析离散问题。如果我们想知道7天后的状态，我们可以计算：
$$x_7 = (A^T)^7 x_0$$

<Callout title="向量化的力量">
  通过用向量和矩阵表示问题，我们可以利用GPU等优化硬件来执行这些计算，速度远超离散步骤的迭代。
</Callout>

## 特征值和特征向量
线性变换的特征向量是一个非零向量，当该线性变换应用于它时，其方向不变，最多只发生标量缩放。对应的标量因子就是特征值。

$$Av = \lambda v$$

- $$v$$: 矩阵A的特征向量。
- $$\lambda$$: 对应于v的特征值。

特征向量代表了矩阵变换的“基本”或“特征”方向。沿着这些方向，矩阵只对向量进行缩放，而不进行旋转。

### 稳态与主特征向量
在流网络中，如果我们反复应用变换矩阵，系统通常会进入一个**稳态**，此时分布不再改变。这个稳态对应于矩阵的**主特征向量**（与最大特征值相关联的特征向量）。

### 幂迭代法
幂迭代法是一种寻找矩阵主特征向量的算法。它通过将一个随机向量反复乘以矩阵并对结果进行归一化来工作。

```python
# 幂迭代法示例
import numpy as np

def power_iteration(A, num_simulations: int):
    # 理想情况下选择一个随机向量
    # 为了使此过程可复现，我们从一个全为1的向量开始
    b_k = np.ones(A.shape[1])

    for _ in range(num_simulations):
        # 计算矩阵向量乘积 Ab
        b_k1 = np.dot(A, b_k)

        # 计算范数
        b_k1_norm = np.linalg.norm(b_k1)

        # 重新归一化向量
        b_k = b_k1 / b_k1_norm

    return b_k

# 最终的 b_k 就是主特征向量
```

## 矩阵分解

### 特征分解
特征分解是将矩阵分解为其特征值和特征向量的表示形式。对于一个方阵 $$A$$，其形式为：

$$A = Q\Lambda Q^{-1}$$

- $$Q$$: 列为 $$A$$ 的特征向量的矩阵。
- $$\Lambda$$: 对角线元素为相应特征值的对角矩阵。

<Callout title="并非总是可行">
特征分解仅适用于*可对角化*的方阵。
</Callout>

### 主成分分析 (PCA)
PCA是一种统计过程，它使用特征分解将一组可能相关的变量的观测值，转换为一组称为**主成分**的线性不相关变量。

数据的**协方差矩阵**的特征向量就是主成分。它们指向数据中方差最大的方向。特征值表示每个主成分捕获了多少方差。这对于降维非常有用。

## 矩阵求逆
一个方的、非奇异矩阵 $$A$$ 的逆是 $$A^{-1}$$，定义为：

$$A^{-1}A = I$$

(其中 $$I$$ 是单位矩阵)

求逆使我们能够“撤销”矩阵变换。它对于求解线性方程组至关重要：

如果 $$Ax = y$$，则 $$x = A^{-1}y$$。

<Callout title="奇异性" type="warn">
一个矩阵只有在**非奇异**时才有逆，这意味着它的**行列式不为零**。奇异矩阵会压缩至少一个空间维度，导致信息丢失，使变换不可逆。
</Callout>

## 奇异值分解 (SVD)
SVD是计算线性代数的“动力源泉”。它是特征分解的推广，适用于**任何** $$m \times n$$ 矩阵。

$$A = U\Sigma V^T$$

- $$U$$: 一个 $$m \times m$$ 的正交矩阵（左奇异向量）。代表旋转。
- $$\Sigma$$: 一个 $$m \times n$$ 的对角矩阵（奇异值）。代表缩放。
- $$V^T$$: 一个 $$n \times n$$ 的正交矩阵（右奇异向量）。代表旋转。

SVD表明，任何矩阵变换都可以分解为三个基本操作的序列：**旋转、缩放、再旋转**。

### SVD的应用
- **伪逆**：SVD可用于计算任何矩阵的伪逆 $$A^+$$，即使对于非方阵或奇异矩阵，也能为线性系统提供近似解。
- **矩阵近似**：通过仅保留最大的奇异值，我们可以构造原始矩阵的低秩近似，这对于压缩和降噪至关重要。
- **秩和条件数**：非零奇异值的数量给出了矩阵的**秩**。最大奇异值与最小奇异值的比率给出了**条件数**，它衡量矩阵求逆对数值误差的敏感度。

## 数据白化
白化是一种预处理步骤，它转换数据集，使其特征不相关且具有单位方差。白化后数据的协方差矩阵是单位矩阵。这通常使用SVD或特征分解来“球形化”数据，这是许多算法的要求。
