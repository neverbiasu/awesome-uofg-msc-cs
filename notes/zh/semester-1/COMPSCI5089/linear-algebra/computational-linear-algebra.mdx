## 概要
- **目标**: 学习如何以计算方式表示和求解线性方程组，这是各种科学领域的常见任务。
- **范围**: 本笔记涵盖线性系统的矩阵表示法以及 NumPy 的 `linalg.solve` 函数的使用。

## 学习目标
1. 以矩阵形式 `Ax = b` 表示线性方程组。
2. 理解高斯消元法等求解方法的高级概念。
3. 使用 `numpy.linalg.solve` 函数高效地找到解向量 `x`。

## 关键知识点

### 1. 求解线性方程组
- **动机**: 许多现实世界的问题，从电路分析到经济建模，都可以描述为线性方程组。求解未知变量是一项常见的计算任务。
- **核心概念**:
  - **矩阵形式 `Ax = b`**: 一种紧凑表示线性方程组的方式，其中 **A** 是系数矩阵，**x** 是未知变量向量，**b** 是常数向量。
  - **高斯消元法**: 一种经典的求解线性系统的算法，通过将矩阵 **A** 转换为上三角形式，从而通过回代直接求解。虽然基础，但在实践中通常不直接使用，而是倾向于更稳健的库函数。
  - **`numpy.linalg.solve`**: NumPy 中的一个高度优化且数值稳定的函数，可直接求解方程 `Ax = b` 以得到 `x`。
- **示例**:
  ```python
  # 方程组:
  # 2x + 3y = 8
  # 4x + 1y = 6
  import numpy as np

  # 矩阵 A (系数)
  A = np.array([[2, 3], [4, 1]])

  # 向量 b (常数)
  b = np.array([8, 6])

  # 求解 x (即向量 [x, y])
  x = np.linalg.solve(A, b)
  # x 的结果将是 [1., 2.]
  ```
- **注意事项/最佳实践**:
  - 仅当矩阵 **A** 是方阵且非奇异（即其行列式不为零）时，才存在唯一解。
  - 为了性能和数值稳定性，强烈推荐使用 `np.linalg.solve(A, b)`，而不是计算 A 的逆再与 b 相乘 (`np.linalg.inv(A) @ b`)。
- **小结**: 以矩阵形式表示线性系统使我们能够利用像 NumPy 这样强大而高效的计算工具来寻找解。

- 在生产代码中，始终使用专用的线性代数库函数（如 `numpy.linalg.solve`）来求解方程组。
