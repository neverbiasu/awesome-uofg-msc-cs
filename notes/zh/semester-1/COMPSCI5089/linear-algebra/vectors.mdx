## 概要
- **目标**: 理解向量的基本属性和运算，这是机器学习中的主要数据结构。
- **范围**: 本笔记涵盖向量的定义、基本算术运算（加法、标量乘法）和点积。

## 学习目标
1. 定义向量和标量并区分它们。
2. 执行向量加法和标量乘法。
3. 计算两个向量的点积并理解其属性。

## 关键知识点

### 1. 向量基础
- **动机**: 在机器学习中，数据点（如图像或用户画像）通常表示为向量。理解向量运算对于操作和分析这些数据至关重要。
- **核心概念**:
  - **向量**: 同时具有大小和方向的对象。可以表示为一组数字。
  - **标量**: 单个数字，只有大小没有方向。
  - **向量加法**: 两个向量的逐元素相加。向量必须具有相同的维度。
  - **标量乘法**: 将向量的每个元素乘以一个标量。
  - **点积**: 两个数字序列的对应元素乘积之和。对于向量 **a** 和 **b**，计算公式为 `a · b = Σ(a_i * b_i)`。
- **示例**:
  ```python
  # 向量表示
  # 向量可以表示为 Python 列表或 NumPy 数组。
  vector_a = [1, 2, 3]
  vector_b = [4, 5, 6]

  # 标量
  scalar_c = 2

  # 点积示例
  # (1*4) + (2*5) + (3*6) = 4 + 10 + 18 = 32
  dot_product_result = 32
  ```
- **注意事项/最佳实践**:
  - 点积满足交换律: `a · b = b · a`。
  - 点积对向量加法满足分配律: `a · (b + c) = a · b + a · c`。
- **小结**: 向量是表示数据的基本构建块。基本运算允许有意义的操作，而点积是衡量相似性和投影的关键工具。

## 最佳实践
- 在 Python 中使用像 NumPy 这样的库进行向量运算，因为它们为性能做了高度优化。
- 在尝试加法或点积之前，始终确保向量具有相同的维度。
