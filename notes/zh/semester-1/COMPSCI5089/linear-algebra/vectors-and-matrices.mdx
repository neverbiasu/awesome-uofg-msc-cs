## NumPy 中的核心概念

### NumPy 中的向量
- 在 NumPy 中，向量表示为一维数组。

```python
import numpy as np

# 从列表创建向量
v = np.array([1, 2, 3])

# 检查其形状 (结果为 (3,))
print(v.shape)
```

### NumPy 中的矩阵
- 矩阵表示为二维数组。

```python
import numpy as np

# 从列表的列表创建 2x3 矩阵
M = np.array([[1, 2, 3], [4, 5, 6]])

# 检查其形状 (结果为 (2, 3))
print(M.shape)
```

### 创建特殊矩阵
- NumPy 提供了便捷的函数来创建常见类型的矩阵。

```python
# 一个 3x3 的全零矩阵
zeros = np.zeros((3, 3))

# 一个 2x4 的全一矩阵
ones = np.ones((2, 4))

# 一个 3x3 的单位矩阵 (对角线为1，其余为0)
eye = np.eye(3)
```

## 向量属性与运算

### 向量加法
- 两个相同维度的向量可以通过将其对应分量相加来进行加法运算。
- 如果 $$v = [v_1, v_2]$$ 且 $$w = [w_1, w_2]$$，那么 $$v + w = [v_1 + w_1, v_2 + w_2]$$。

### 标量乘法
- 用一个标量乘以一个向量，就是用该标量乘以向量的每一个分量。
- 如果 $$a$$ 是一个标量且 $$v = [v_1, v_2]$$，那么 $$a * v = [a * v_1, a * v_2]$$。

### 向量范数 (大小)
- 范数是一个函数，它为向量空间中的每个向量赋予一个严格为正的长度或大小。
- **L1 范数 (曼哈顿距离)**: 各分量绝对值之和。
  - $$\parallel v \parallel_1 = \sum_i |v_i|$$
- **L2 范数 (欧几里得距离)**: 各分量平方和的平方根。这是测量向量长度最常用的方法。
  - $$\parallel v \parallel_2 = \sqrt{\sum_i v_i^2}$$
- **L-无穷大范数**: 向量各分量绝对值中的最大值。
  - $$\parallel v \parallel_\infty = \max_i |v_i|$$

### 点积
- 两个向量的点积是一个标量值，它衡量了它们的几何关系。
- $$v \cdot w = \sum_i (v_i * w_i)$$
- **正交性**: 如果两个非零向量的点积为零，则它们相互**正交**（垂直）。
  - $$v \cdot w = 0$$

## 矩阵属性与运算

### 矩阵加法
- 两个相同维度的矩阵可以通过将其对应元素相加来进行加法运算。
- 如果 $$C = A + B$$，那么 $$C_{ij} = A_{ij} + B_{ij}$$。

### 标量乘法
- 用一个标量乘以一个矩阵，就是用该标量乘以矩阵的每一个元素。
- 如果 $$C = sA$$，那么 $$C_{ij} = s * A_{ij}$$。

### 矩阵转置
- 矩阵的**转置**，记作 $$A^T$$，是通过将其行变为列，列变为行形成的。
- 如果 $$B = A^T$$，那么 $$B_{ij} = A_{ji}$$。

### 矩阵-向量乘法
- 一个矩阵可以与一个向量相乘，产生一个新的向量。这代表了对空间中的一个点应用线性变换。
- 如果 $$\mathbf{y} = A\mathbf{x}$$，那么 $$\mathbf{y}$$ 的第 $$i$$ 个元素是 $$A$$ 的第 $$i$$ 行与向量 $$\mathbf{x}$$ 的点积。
