# COMPSCI 5100: 面向数据科学家的机器学习与人工智能
本课程介绍了从数据中学习的一般理论以及几种流行的机器学习方法。该模块侧重于在各种领域中使用 scikit-learn 等标准库的机器学习技术的实际应用，以及训练和验证机器学习模型的良好实践。
<Accordions>
  <Accordion title="课程基本信息">
    **教学团队:**
    - Dr. Ali Gooya ([ali.gooya@glasgow.ac.uk](mailto:ali.gooya@glasgow.ac.uk))
    - Dr. Fani Deligianni ([Fani.Deligianni@glasgow.ac.uk](mailto:Fani.Deligianni@glasgow.ac.uk)) (办公时间：周五 12:00-14:00)
    **课程目标:**
    1. 解释用于回归、分类和聚类的数据学习过程。
    2. 使用 Python 和 scikit-learn 等库实现和应用机器学习算法。
    3. 解释常用算法的优缺点。
    4. 理解损失函数的影响。
    5. 展示对主要机器学习应用领域的知识。
    6. 展示在数据驱动建模过程中的熟练程度。
