## 概要
- **目标**：学习通过约束模型复杂度来防止过拟合的技术。
- **范围**：本笔记涵盖岭回归（L2）和Lasso回归（L1）正则化的理论和应用，包括如何使用交叉验证来选择正则化强度。

## 学习目标
1.  解释正则化作为解决过拟合问题的动机。
2.  描述岭回归（L2惩罚）如何作用以收缩模型权重。
3.  描述Lasso回归（L1惩罚）的工作原理及其如何用于特征选择。
4.  使用 `scikit-learn` 实现岭回归和Lasso回归。
5.  使用交叉验证来选择最优的正则化超参数（λ或alpha）。

## 关键概念

### 1. 过拟合与权重过大的问题
- **动机**：正如在高阶多项式中看到的，过拟合训练数据的复杂模型通常具有极大（正或负）的权重。这些大权重导致模型函数剧烈波动，以捕捉包括噪声在内的每个数据点。
- **思路**：如果我们能阻止模型的权重变得过大，我们就可以控制其复杂度并减少过拟合。

### 2. 正则化：对损失函数进行惩罚
- **核心概念**：正则化通过向原始损失函数添加一个**惩罚项**来工作。这个惩罚项是模型权重的一个函数。新的正则化损失函数是：
  `L_reg = L_data + L_penalty`
  - `L_data` 是原始的均方误差（MSE）。
  - `L_penalty` 惩罚过大的权重。
  - 模型现在必须在很好地拟合数据（最小化 `L_data`）和保持其权重较小（最小化 `L_penalty`）之间找到平衡。

### 3. 岭回归（L2 正则化）
- **核心概念**：岭回归使用权重的**L2范数**作为其惩罚项。惩罚是权重的平方和，由一个超参数 `λ`（lambda）缩放。
  `L_penalty = λ * Σ_{k=1 to K} w_k² = λ * ||w||²`
- **效果**：L2惩罚迫使权重变小，但很少将它们精确地强制为零。它将所有权重朝零收缩，从而产生一个更平滑、更不复杂的模型函数。
- **`λ` 超参数**：`λ`（在 `scikit-learn` 中称为 `alpha`）控制正则化的强度。
  - 如果 `λ = 0`，则与普通最小二乘法相同。
  - 随着 `λ` 的增加，权重被越来越多地收缩，导致模型更简单（更高偏差，更低方差）。
- **示例**：
  ```python
  # 示例：将岭回归应用于8阶多项式
  from sklearn.linear_model import Ridge
  from sklearn.pipeline import make_pipeline
  from sklearn.preprocessing import PolynomialFeatures

  # 创建一个流水线
  model = make_pipeline(PolynomialFeatures(8), Ridge(alpha=0.001))
  
  # 拟合模型
  model.fit(x_reshaped, t_reshaped)
  ```

### 4. Lasso 回归（L1 正则化）
- **核心概念**：Lasso回归使用权重的**L1范数**作为其惩罚项。惩罚是权重的绝对值之和，由 `λ` 缩放。
  ```math
  L_\text{penalty} = \lambda \sum_{k=1}^{K} |w_k| = \lambda \|w\|_1
  ```
- **关键属性：稀疏性**：L1惩罚有一个独特的效果：它可以迫使模型的某些权重变为**精确的零**。这意味着模型有效地忽略了相应的特征。
- **用例：特征选择**：因为Lasso可以将权重归零，所以它对于自动特征选择非常有用，特别是当您有许多特征并怀疑并非所有特征都有用时。
- **示例**：
  ```python
  # 示例：应用Lasso回归
  from sklearn.linear_model import Lasso

  model = make_pipeline(PolynomialFeatures(8), Lasso(alpha=0.0001))
  model.fit(x_reshaped, t_reshaped)
  
  # 我们可以检查模型的系数，看哪些是零
  # print(model.named_steps['lasso'].coef_)
  ```

### 5. 选择正则化参数 `λ`
- **动机**：`λ` 的选择至关重要。如果 `λ` 太小，模型仍会过拟合。如果 `λ` 太大，模型将过于简单并将欠拟合（无法捕捉基本趋势）。
- **最佳实践**：将 `λ` 视为一个超参数，并使用**交叉验证**来找到产生最低平均验证误差的值。您可以测试一系列 `λ` 值（例如，0.0001, 0.001, 0.01, 0.1, 1, 10）以找到最优值。

## 最佳实践
- **特征缩放**：正则化对输入特征的尺度很敏感。在应用岭回归或Lasso回归之前，对特征进行缩放（例如，使其具有零均值和单位方差）是标准做法。`scikit-learn` 的 `Ridge` 和 `Lasso` 有一个 `normalize=True` 参数可以处理这个问题，或者您可以在流水线中使用 `StandardScaler`。
