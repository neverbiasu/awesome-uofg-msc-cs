## 概要
- **目标**：理解如何为单个输入特征和连续目标变量之间的线性关系建模。
- **范围**：本笔记涵盖简单线性模型的定义、损失函数（MSE）的概念以及模型拟合的实际实现。

## 学习目标
1.  从数学上定义线性回归模型。
2.  解释损失函数在寻找最佳模型参数中的作用。
3.  使用 `scikit-learn` 将线性回归模型拟合到数据。
4.  解释已拟合模型的参数（斜率和截距）。

## 关键概念

### 1. 线性模型
- **动机**：我们通常假设输入和输出之间存在简单的直线关系。例如，根据年份预测未来的奥运会百米赛跑夺冠时间。
- **核心概念**：该关系通过直线方程建模：
  ```math
  t = f(x; w_0, w_1) = w_0 + w_1x
  ```
  - `t` 是目标变量（例如，夺冠时间）。
  - `x` 是输入特征（例如，年份）。
  - `w_0` 是 y 轴截距（当 `x=0` 时 `t` 的值）。它使直线上下平移。
  - `w_1` 是与 `x` 相关的斜率或权重。它控制直线的陡峭程度。
- **学习目标**：找到最优的参数值（`w_0`, `w_1`），使直线最佳地拟合训练数据。

### 2. 损失函数
- **动机**：为了找到“最佳”直线，我们需要一种方法来数值化地衡量给定直线对数据的拟合程度。如果一条直线的预测值接近于实际数据点，那么它就是“好”的。
- **核心概念**：**平方损失**（或平方误差）衡量单个数据点 `n` 的误差：
  ```math
  L_n = (t_n - f(x_n; w_0, w_1))^2
  ```
  这是真实目标 `t_n` 与模型预测 `f(x_n)` 之间的垂直距离的平方。
- **总体损失**：为了获得整个数据集的单一误差度量，我们对所有 `N` 个数据点的平方损失进行平均。这被称为**均方误差（MSE）**：
  ```math
  L = \frac{1}{N} \sum_{n=1}^{N} (t_n - f(x_n; w_0, w_1))^2
  ```
<Callout type="info" title="最佳实践">
  训练的目标是找到最小化此 MSE 值的参数 `w_0` 和 `w_1`。
</Callout>

### 3. 使用 Scikit-Learn 进行模型拟合
- **动机**：手动计算最小化损失的参数既繁琐又复杂。像 `scikit-learn` 这样的库可以自动化这个过程。
- **使用模式**：`sklearn.linear_model.LinearRegression` 对象可以自动将模型拟合到数据。
- **示例**：
  ```python
  # 示例：将模型拟合到奥运会百米赛跑数据
  # 假设 'x' 是年份的 NumPy 数组，'t' 是时间的数组。
  from sklearn.linear_model import LinearRegression
  import numpy as np

  # 为 scikit-learn 重塑数据：需要是二维数组
  x_reshaped = x[:, np.newaxis]
  t_reshaped = t[:, np.newaxis]

  # 创建并拟合模型
  reg = LinearRegression().fit(x_reshaped, t_reshaped)

  # 最优参数存储在模型对象中
  w_0 = reg.intercept_[0]  # 截距
  w_1 = reg.coef_[0][0]    # 斜率

  # 对 2012 年进行预测
  prediction_2012 = reg.predict(np.array([[2012]]))
  ```
- **小结**：`.fit()` 方法执行优化以找到最佳的 `w_0` 和 `w_1`。生成的 `reg` 对象是一个训练好的模型，可用于预测。

## 模型假设
- **线性关系**：假设 `x` 和 `t` 之间的关系是线性的。
- **连续性**：假设在训练数据中观察到的趋势将在未来继续。
<Callout type="warn" title="权衡">
  虽然线性回归的假设在技术上可能不正确，但该模型在合理范围内进行预测仍然非常有用。
</Callout>

## 关键要点
- 线性回归使用参数 `w_0`（截距）和 `w_1`（斜率）对线性关系进行建模。
- 均方误差（MSE）用于量化模型误差，目标是最小化它。
- `scikit-learn` 自动化了寻找最优参数的过程。
- 模型假设线性关系和趋势的连续性。
