## 概要
- **目标**：学习如何为非线性关系建模，并选择一个能很好地泛化到新数据的模型。
- **范围**：本笔记涵盖多项式回归、过拟合的概念，以及使用验证集和K-折交叉验证进行模型选择的方法。

## 学习目标
1.  构建多项式特征以拟合非线性数据。
2.  识别并解释过拟合问题。
3.  使用验证集来选择最优的模型复杂度（例如，多项式阶数）。
4.  实现K-折交叉验证以进行稳健的模型评估。

## 关键概念

### 1. 多项式回归
- **动机**：简单线性回归无法捕捉数据中的曲线。如果潜在关系不是一条直线，我们需要一个更灵活的模型。
- **核心概念**：我们可以通过添加原始特征 `x` 的幂作为新特征来扩展线性回归。模型变为：
  ```math
  t = w_0 + w_1x + w_2x^2 + \dots + w_Kx^K
  ```
  这仍然被认为是**线性模型**，因为它在参数 `w` 上是线性的。我们只是将一个线性模型拟合到数据的非线性变换上。
- **示例**：为二阶多项式创建设计矩阵。
  ```python
  # 示例：手动创建多项式特征
  import numpy as np
  
  def make_polynomial(x, maxorder):
      """创建一个包含多项式特征的设计矩阵。"""
      X = np.ones_like(x) # 偏置项 (对应 w_0)
      for i in range(1, maxorder + 1):
          X = np.hstack((X, x**i))
      return X
  
  # x_train 是单特征值的列向量
  # X_poly 将包含 1, x, x^2 的列
  X_poly = make_polynomial(x_train, 2)
  
  # 此矩阵随后可用于 sklearn.linear_model.LinearRegression
  ```

### 2. 过拟合（Overfitting）
- **动机**：随着模型复杂度（例如，多项式阶数 `K`）的增加，训练误差总是会减小。然而，一个过于复杂的模型可能会学习到训练数据中的噪声，而不是潜在的趋势。
- **核心概念**：**过拟合**指模型在训练数据上表现极好，但在新的、未见过的数据上表现很差。该模型具有高方差。过拟合的模型泛化能力差。
- **视觉线索**：过拟合的多项式曲线通常表现出剧烈波动，尤其是在数据范围的边缘。

### 3. 使用验证集进行模型选择
- **动机**：由于训练误差不是模型选择的好指标，我们需要另一种方法来估计模型在真实世界中的表现。
- **核心概念**：我们可以将数据分成两部分：
  1.  **训练集**：用于拟合模型参数（`w`）。
  2.  **验证集**：用于评估训练好的模型并选择其复杂度（如多项式阶数 `K` 等超参数）。
- **使用模式**：
  1.  在**训练集**上训练多个模型（例如，阶数为 1, 2, 3, ... 8 的多项式）。
  2.  在**验证集**上评估每个模型。
  3.  选择**验证误差最低**的模型。这个模型被期望具有最好的泛化能力。

### 4. K-折交叉验证
- **动机**：简单的训练/验证集划分可能对数据的分割方式很敏感。不同的划分可能导致选出不同的“最佳”模型。
- **核心概念**：**K-折交叉验证（CV）**为模型的性能提供了更稳健的估计。其过程如下：
  1.  随机打乱数据集。
  2.  将数据集分成 `K` 个组（或“折”）。
  3.  对每一折：
      a.  将该折作为**测试集**。
      b.  将其余 `K-1` 折作为**训练集**。
      c.  在训练集上拟合模型，并在测试集上进行评估。
  4.  最终性能是 `K` 次评估分数的平均值。
- **示例**：使用 `scikit-learn` 执行10折交叉验证。
  ```python
  # 示例：对三阶多项式模型进行10折交叉验证
  from sklearn.linear_model import LinearRegression
  from sklearn.preprocessing import PolynomialFeatures
  from sklearn.pipeline import make_pipeline
  from sklearn.model_selection import cross_val_score
  
  # 创建一个流水线，首先创建多项式特征，然后拟合线性模型
  model = make_pipeline(PolynomialFeatures(3), LinearRegression())
  
  # 执行10折交叉验证
  # 使用 'neg_mean_squared_error' 是因为 cross_val_score 期望一个效用分数（越高越好）
  scores = cross_val_score(model, x_reshaped, t_reshaped, cv=10, scoring='neg_mean_squared_error')
  ```

## 最佳实践
- **避免使用测试集进行模型选择**：最终的测试集应该只在最后使用一次，用于报告最终选定模型的性能。
- **谨慎选择K值**：K的常见选择是5或10。更大的K值计算成本更高，但能提供更稳健的估计。
