## 关键要点
- **HTML (超文本标记语言)** 使用标签和元素系统提供了网页的基本结构。
- **CSS (层叠样式表)** 用于控制HTML元素的表现、样式和布局，实现了内容与设计的分离。
- **Bootstrap** 是一个流行的前端框架，提供预构建的组件和强大的网格系统，以促进快速、响应式和移动优先的Web开发。
- **Web可持续性** 是现代Web开发中的一个重要考虑因素，专注于通过优化代码、减少数据传输和高效利用资源来最小化碳足迹。
- **最佳实践**：使用语义化的HTML，利用外部CSS样式表以提高可维护性，并遵循“移动优先”等原则来创建高效且易于访问的网站。

## HTML 简介

HTML，即 **超文本标记语言 (HyperText Markup Language)**，是用于创建和组织网页内容标准语言。它使用一套“标记”标签来描述文档中的不同元素。

### 基本 HTML 文档结构

一个 HTML 文档是一个包含标签的纯文本文档。其基本结构如下：

```html
<!DOCTYPE html>
<html>
  <head>
    <title>页面标题</title>
  </head>
  <body>
    <h1>这是一个标题</h1>
    <p>这是一个段落。</p>
  </body>
</html>
```

- **`<!DOCTYPE html>`**：声明文档类型。
- **`<html>`**：页面的根元素。
- **`<head>`**：包含关于文档的元信息，例如标题。
- **`<body>`**：包含在浏览器中显示的可见页面内容。

### 常用 HTML 元素

- **标题 (Headings)**：`<h1>` 到 `<h6>` 定义了标题，其中 `<h1>` 最为重要。搜索引擎使用这些标题来索引页面内容。
- **段落 (Paragraphs)**：`<p>` 定义一个段落。浏览器会自动在段落周围添加外边距。
- **换行 (Line Breaks)**：`<br>` 是一个空元素（没有闭合标签），它强制进行换行。
- **列表 (Lists)**：`<ul>`（无序列表）和 `<ol>`（有序列表）与 `<li>`（列表项）一起使用来创建列表。
- **分区 (Divisions)**：`<div>` 是一个块级容器，用于对内容进行分组和分块，通常与CSS一起用于样式设计。

<Callout title="开发哲学：HTML 优先">
  Web开发中的一个通用准则：
  1. 如果能用HTML实现，就用HTML。
  2. 如果用HTML实现不了，就用CSS。
  3. 如果用HTML或CSS都实现不了，就用JavaScript。
</Callout>

## 使用层叠样式表 (CSS) 进行样式设计

CSS是一种样式表语言，用于描述用HTML编写的文档的呈现方式。它允许开发者将内容结构（HTML）与视觉样式分离开来，从而提高了可维护性、性能和灵活性。

### CSS 规则语法

一条CSS规则由一个**选择器**和一个**声明块**组成。

```css
/* 选择器 { 属性: 值; } */

p {
  color: blue;
  font-size: 16px;
}

h1, h2, h3 {
  color: red;
}

/* ID选择器针对唯一元素 */
#main-header {
  border-bottom: 1px solid black;
}

/* 类选择器针对所有具有特定类的元素 */
.warning {
  font-weight: bold;
}
```

### 将 CSS 应用于 HTML

有三种方式可以将CSS应用于HTML文档：

1.  **内联CSS (Inline CSS)**：直接在HTML元素上使用`style`属性。（破坏了内容与表现的分离，通常应避免）。
    ```html
    <p style="color: red;">这是一个红色段落。</p>
    ```
2.  **嵌入式CSS (Embedded CSS)**：在HTML文档的`<head>`部分内，将CSS规则放置在`<style>`标签中。
3.  **外部CSS (External CSS)**：将CSS规则放在一个单独的`.css`文件中，然后从HTML文档中链接它。**这是最佳实践。**
    ```html
    <head>
      <link rel="stylesheet" href="styles.css" type="text/css">
    </head>
    ```

### 盒子模型、层叠与特异性

- **盒子模型 (The Box Model)**：每个HTML元素都是一个矩形盒子。这个盒子由**内容 (content)**、**内边距 (padding)**、**边框 (border)** 和**外边距 (margin)** 组成。CSS属性控制着这些部分的尺寸和外观。
- **继承 (Inheritance)**：子孙元素会继承其父元素的样式属性。
- **特异性 (Specificity)**：当多条CSS规则应用于同一元素时，浏览器会使用一个特异性分数来决定哪条规则胜出。ID选择器 (`#id`) 比类选择器 (`.class`) 更具体，而类选择器又比元素选择器 (`p`) 更具体。
- **层叠 (Cascade)**：如果规则具有相同的特异性，那么在样式表中最后定义的规则会胜出。这种“层叠”的特性正是CSS名字的由来。

### 使用 CSS 进行页面布局

在过去，HTML表格曾被用于页面布局，但这现在被认为是错误的做法。现代方法使用`float`、`position`等CSS属性，以及像**Flexbox**和**Grid**这样的新型布局系统，通过`<div>`元素创建复杂且响应式的布局。

## Bootstrap 简介

Bootstrap是一个流行的、免费且开源的前端框架，用于开发响应式、移动优先的网站。它包括预设样式的CSS组件和JavaScript插件。

**Bootstrap的优势：**
- **易于使用**：通过预定义的类快速构建布局。
- **响应式特性**：其网格系统能自动适应不同屏幕尺寸（桌面、平板、手机）的布局。
- **移动优先方法**：核心样式首先为小屏幕设计，然后向上扩展。
- **跨浏览器兼容性**：确保在现代浏览器中拥有一致的外观和体验。

要开始使用，您可以访问其官网 [getbootstrap.com](https://getbootstrap.com/) 并遵循他们的教程。

## 前端开发中的Web可持续性

互联网贡献了全球约4%的排放量。作为开发者，我们可以采取一些实践来创建更具可持续性、更节能的网站。

<Callout title="可持续Web设计原则">
  根据 [可持续Web宣言 (Sustainable Web Manifesto)](https://www.sustainablewebmanifesto.com/)，产品和服务应该使用清洁能源，消耗最少的能源，并对所有人开放。
</Callout>

### 关键指南

<Steps>
  <Step title="优化与压缩">
    压缩你的HTML、CSS和JavaScript文件，以移除不必要的空白和注释。这可以减小文件大小并提高加载速度。
  </Step>
  <Step title="正确使用HTML">
    编写有效的、语义化的HTML。臃肿或已弃用的标记会浪费数据，并在传输和渲染过程中增加能耗。避免使用像`<center>`或`<font>`这样已弃用的元素；应改用CSS。
  </Step>
  <Step title="避免代码重复">
    使用CSS类来应用可重用的样式，而不是重复内联样式。这可以提高可维护性并减小文件大小。
  </Step>
  <Step title="适应用户偏好和设备">
    使用CSS媒体查询创建响应式布局，以适应不同的设备。同时，尊重用户的偏好，如`prefers-reduced-data`（偏好减少数据）或`prefers-color-scheme`（偏好颜色方案，如暗黑模式），以节省能源。
  </Step>
</Steps>

<Callout title="开发指南：移动优先">
  一种可持续的设计方法是“移动优先”。从最小的屏幕尺寸开始设计，这迫使你优先考虑核心内容并优化性能。然后，逐步为更大的屏幕增强设计。一个关键方面是设定一个**页面权重预算**，以保持你的页面轻量和快速。
</Callout>
