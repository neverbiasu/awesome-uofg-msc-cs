# COMPSCI 5057: 人机交互设计与评估

本课程介绍人机交互（HCI）的原理和实践，重点关注以用户为中心的设计方法论、可用性评估技术和界面设计原则。

<Accordions>
  <Accordion title="课程信息">
    **学习目标：**
    1. 理解HCI的基本原理和理论
    2. 应用以用户为中心的设计方法
    3. 进行可用性评估和用户研究
    4. 设计有效且可访问的用户界面
    5. 分析和改进现有界面设计
  </Accordion>
  <Accordion title="课程结构与考核">
    **课程结构：**
    - 讲座：理论基础
    - 实验：设计练习和原型制作
    - 项目：用户研究和界面设计

    **考核方式：**
    - 课程作业
    - 设计项目
    - 期末考试
  </Accordion>
</Accordions>
