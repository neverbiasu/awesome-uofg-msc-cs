## 概要

- **目标**：全面介绍 COMPSCI5012 Internet Technology (ITECH) 课程，明确学习目标、教学团队、课程结构及考核方式。
- **范围**：课程大纲、时间表、评估标准（个人作业、小组项目、考试）以及学术诚信要求。

## 学习目标

1. **了解** 课程的核心目标：掌握分布式 Web 应用的设计、开发与部署。
2. **熟悉** 课程结构：Lecture、Lab 及自学安排。
3. **明确** 评估方式：Lab Quizzes (30%)、小组项目 (50%) 和期末考试 (20%)。
4. **掌握** 沟通渠道与学术行为准则。

## 关键知识点

### 1. 课程目标 (Course Aims)

- **核心关键词**：Web 应用开发 (Web Application Development)。
- **主要内容**：
  - 了解 Web 应用开发的持续发展。
  - 推广分布式 Web 应用的**规范化设计** (Disciplined Design)。
  - 理解分布式系统的背景与原理。
  - 掌握 Web 应用中的**消息传递与协议** (Messaging and Protocols)。
  - 培养**实现与部署** (Implement and Deploy) 分布式 Web 应用的能力。
  - 强调**可访问性** (Accessibility) 和 **可持续性** (Sustainability)。

### 2. 课程结构与资源

- **教学团队**：
  - **讲师**：Dr Nikela Papadopoulou (专注于低碳与可持续计算)。
  - **助教**：Ghadeer Alsharif, Zhaohan Meng, Kangheng Liang, Shuhao Zhang。
- **教材与工具**：
  - **框架**：Django (Python)。
  - **前端**：HTML, CSS。
  - **版本控制**：Git & GitHub。
  - **参考书**："Tango with Django"。

![Recommended Textbook](/images/COMPSCI5012/L0-Welcome_to_the_course-005.jpg)

### 3. 评估方式 (Assessments)

- **个人作业 (30%)**：
  - 3 次 Lab Quizzes (每次 10%)。
  - 形式：15 分钟，一次性机会 (One-shot)。
  - 时间：周四开放，下周二截止。
- **小组作业 (50%)**：
  - 内容：使用 Django 设计、开发并部署一个 Web 应用。
  - **Phase 1 (15%)**：设计规范 (Design Specification)。
  - **Phase 2 (35%)**：实现 (Implementation) + 视频演示 (5%) + 应用程序 (30%)。
  - **分组**：3 人一组，必须在 Moodle 上注册。
- **期末考试 (20%)**：
  - 时间：4 月/5 月。

### 4. 沟通与支持

- **单向通知**：Moodle。
- **双向交流**：
  - Lecture 和 Lab 期间当面提问。
  - 课外使用 **Padlet** 提问。
  - **禁止** 直接私信讲师或助教（除非涉及个人隐私或小组严重纠纷）。

![Padlet for Q&A](/images/COMPSCI5012/L0-Welcome_to_the_course-007.jpg)

## 最佳实践

- **积极参与**：参加 Lecture，并在 Lab 中寻求助教的一对一帮助。
- **尽早开始**：小组项目工作量大，建议尽早规划设计与开发。
- **学术诚信**：严禁抄袭 (Plagiarism) 和作弊。使用 GenAI 需注明出处，且不能替代个人的原创工作。
- **利用资源**：遇到困难时，通过 Padlet 或 Lab 寻求帮助，不要独自在该过程中挣扎。
