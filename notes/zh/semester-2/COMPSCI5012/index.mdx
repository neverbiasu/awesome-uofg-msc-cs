# COMPSCI 5012: 互联网技术

本课程介绍Web应用程序的设计与开发，涵盖系统架构、数据库建模、信息架构等核心概念，以及使用Django框架进行实际开发。

<Accordions>
  <Accordion title="课程基本信息">
    **课程目标:**
    1. 理解Web应用程序的系统架构设计
    2. 掌握数据库建模和ER图设计
    3. 学习信息架构和用户体验设计
    4. 使用Django框架开发Web应用
    5. 理解前后端分离和API设计
  </Accordion>
  <Accordion title="课程结构与考核">
    **课程结构:**
    - 讲座：介绍理论知识和设计概念
    - 实验：Django框架实践开发
    - 小组项目：团队协作开发Web应用

    **考核:**
    - 小组项目作业
    - 个人报告
  </Accordion>
</Accordions>
