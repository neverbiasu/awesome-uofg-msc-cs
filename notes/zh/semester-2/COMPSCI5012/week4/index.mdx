## 概要
- 主题: 网络通信基础, HTTP, IPC, REST

## 学习目标
1. 理解网络通信的基本原理 (OSI vs TCP/IP)。
2. 掌握 HTTP 协议及其核心方法 (GET vs POST)。
3. 理解进程间通信 (IPC) 协议，特别是 RESTful APIs。
4. 了解如何提升 Web 应用的性能与可持续性。
