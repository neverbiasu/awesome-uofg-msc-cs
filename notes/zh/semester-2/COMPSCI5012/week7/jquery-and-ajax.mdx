## 核心要点
AJAX 通过允许页面异步更新，在不要求重新加载整个页面的情况下与服务器交换数据，彻底改变了 Web。

## JQuery：写得更少，做得更多
JQuery 是一个快速、小型且功能丰富的 JavaScript 库。

### 为什么选择 JQuery？
-   **浏览器兼容性**：自动处理跨浏览器的不一致性。
-   **简化语法**：简洁的类似 CSS 的选择器（例如：`$('.my-class').hide()`）。
-   **链式操作**：允许在同一个选择结果上运行多个方法。

## AJAX (异步 JavaScript 和 XML)
AJAX 不是一种编程语言，而是一种使用现有标准的技术。

### AJAX 的工作原理
1.  发生事件（例如：点击按钮）。
2.  `XMLHttpRequest`（或现代的 `fetch`）向服务器发送请求。
3.  服务器处理请求并返回数据（通常是 JSON）。
4.  JavaScript 在不重新加载的情况下更新页面内容。
<Steps>

### AJAX 生命周期
1.  **请求**：客户端发送后台请求。
2.  **等待**：用户继续与页面交互。
3.  **回调**：服务器响应，触发 JS 函数。
4.  **更新**：修改部分 DOM。
</Steps>

## JSON (JavaScript 对象表示法)
虽然 AJAX 中的 'X' 代表 XML，但大多数现代应用程序使用 **JSON** 进行数据交换，因为它更轻量且与 JS 原生兼容。

## 出卷人视角：技术细微差别

### 异步性
-   **错误**：期望 AJAX 调用的数据在下一行代码中立即可用。
-   **现实**：你必须在 `.then()` 块内或 `await` 之后处理数据。

### UX 与 AJAX
-   **优势**：平滑、类应用的体验。
-   **劣势**：如果处理不当，可能会破坏“后退”按钮功能和书签功能（需要使用 History API）。
