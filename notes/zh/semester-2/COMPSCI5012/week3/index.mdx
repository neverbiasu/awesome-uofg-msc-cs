## 总结

本周通过涵盖前端的核心技术为 Web 开发奠定基础：用于结构的 HTML、用于表现的 CSS 以及用于响应式布局的 Bootstrap。

<Accordions>
  <Accordion title="HTML5 语义化">
    理解文档对象模型 (DOM) 和语义化标签（`<nav>`、`<header>`、`<article>`），以实现更好的可访问性和 SEO。
  </Accordion>
  <Accordion title="CSS 布局">
    掌握**盒模型 (Box Model)**（外边距、边框、内边距、内容）。介绍 **Flexbox** 和 **Grid** 等现代布局系统。
  </Accordion>
  <Accordion title="Bootstrap 框架">
    使用基于组件的框架来加速开发。**12 列网格系统**、实用类以及导航栏和卡片等预构建组件。
  </Accordion>
</Accordions>
