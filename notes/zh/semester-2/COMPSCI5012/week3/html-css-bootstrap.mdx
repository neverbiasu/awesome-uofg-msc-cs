## 核心要点
HTML 提供语义结构，CSS 定义表现形式，而 Bootstrap 等框架能够快速创建响应式的、移动优先的界面。

## 1. HTML5：语义化结构
HTML (超文本标记语言) 是 Web 内容的骨架。

### 核心原则
-   **内容与表现分离**：使用 HTML 定义它“是什么”（语义），使用 CSS 定义它“看起来像什么”。
-   **文档对象模型 (DOM)**：浏览器对 HTML 页面的层次化表示。

## 2. CSS：样式与布局
CSS (层叠样式表) 描述了 HTML 元素应如何显示。

### 盒模型 (Box Model)
每个 HTML 元素都被视为一个盒子。
-   **内容 (Content)**：文本/图像。
-   **内边距 (Padding)**：内容周围的空白区域（在边框内）。
-   **边框 (Border)**：内边距和内容周围的区域。
-   **外边距 (Margin)**：边框外部的空白区域。
<Callout type="info">
**特定细微差别**：`box-sizing: border-box` 通过将内边距和边框包含在元素的总宽度/高度内，使布局计算变得更加容易。
</Callout>

## 3. 使用 Bootstrap 进行响应式设计
Bootstrap 是一个前端框架，提供栅格系统和预设样式的组件。

### 栅格系统 (Grid System)
-   使用 **12 列系统**。
-   **容器 (Containers)** 包含行，**行 (Rows)** 包含列 (`col-*`)。
-   **断点 (Breakpoints)** (sm, md, lg, xl) 允许在不同屏幕尺寸上采用不同的布局。

## 4. 出卷人视角：技术细微差别

### CSS 选择器优先级 (Specificity)
-   内联样式 > ID > 类/属性 > 元素。
-   *考试技巧*：如果多条规则应用于同一个元素，则最“具体”的规则胜出，无论顺序如何。

### 响应式 (Responsive) vs. 自适应 (Adaptive)
-   **响应式**：随着屏幕尺寸变化而变化的流式布局（CSS 媒体查询）。
-   **自适应**：针对特定设备类别设计的固定布局（例如：一个用于移动端，一个用于桌面端）。
