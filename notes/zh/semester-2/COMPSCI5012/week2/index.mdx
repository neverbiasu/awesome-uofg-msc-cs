## 总结

本周介绍了用于构建可扩展 Web 应用的工具。定义了什么是 Web 框架（相对于库），并深入探讨了 Django——一个高级 Python Web 框架，解释了其特定的架构模式 (MVT)。

<Accordions>
  <Accordion title="框架 vs. 库">
    **控制反转 (Inversion of Control)**：关键区别。库是你调用的工具；框架调用你的代码。为什么框架对复杂的 Web 应用至关重要（安全性、可扩展性、速度）。
  </Accordion>
  <Accordion title="架构模式">
    **MVC (模型-视图-控制器)**：行业标准模式。
    **MVT (模型-视图-模板)**：Django 的变体。
    - **Model**：数据访问层。
    - **View**：业务逻辑（控制器）。
    - **Template**：表现层（视图）。
  </Accordion>
  <Accordion title="Django 基础">
    Django 中的请求生命周期：`URLconf` -> `View` -> `Model` -> `Template` -> `Response`。设置项目、创建应用以及映射 URL。
  </Accordion>
</Accordions>
