## 概要
本周内容涵盖 Web 开发的复杂性、WAFs 的作用、MVC 架构，并介绍 Django 框架。
- 节奏：tAPP + 实验（如适用）
- 主题：Web 应用框架、Django、MVC 架构、框架与库

## 本周安排（按顺序）
| 环节 | 主题 | 说明 |
|---|---|---|
| 讲座 1 | Web 开发复杂性 | 理解现代 Web 开发的挑战。 |
| 讲座 2 | 框架与库 | 区分框架和库，及其特点。 |
| 讲座 3 | MVC 架构 | 探索模型-视图-控制器设计模式。 |
| 讲座 4 | Django 简介 | 深入了解 Django 框架、其设计理念和架构。 |

## 学习目标
1. 理解 Web 开发的复杂性以及为何需要框架。
2. 将您的架构设计元素映射到 Django 模块。
