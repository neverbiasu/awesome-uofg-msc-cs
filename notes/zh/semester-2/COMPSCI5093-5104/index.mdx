# COMPSCI 5093/5104: 安全软件工程

本课程涵盖安全软件工程的原理和实践，包括安全风险分析、安全开发生命周期以及构建能够抵御攻击的软件系统。

<Accordions>
  <Accordion title="课程基本信息">
    **学习目标:**
    1. 理解软件开发中的安全风险
    2. 应用安全编码实践
    3. 在软件开发生命周期中实施安全措施
    4. 分析和缓解安全漏洞
    5. 设计和构建安全的软件系统
  </Accordion>
  <Accordion title="课程结构与考核">
    **课程结构:**
    - 讲座：安全概念和最佳实践
    - 实验：安全实现的实践操作
    - 作业：实际安全任务

    **考核:**
    - 课程作业
    - 期末考试
  </Accordion>
</Accordions>
