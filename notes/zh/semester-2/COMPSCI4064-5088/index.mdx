# COMPSCI 4064/5088: 大数据技术

本课程介绍大数据的核心概念和技术，涵盖从硬件基础到分布式计算框架的完整知识体系，重点学习Hadoop和Spark等主流大数据处理工具。

<Accordions>
  <Accordion title="课程基本信息">
    **课程目标:**
    1. 理解大数据的定义和特征
    2. 掌握硬件基础和扩展策略
    3. 学习MapReduce编程模型
    4. 熟练使用Hadoop和Spark框架
    5. 理解批处理和流处理的区别
  </Accordion>
  <Accordion title="课程结构与考核">
    **课程结构:**
    - 视频讲座：理论知识讲解
    - 实验：大数据工具实践
    - 作业：编程练习

    **考核:**
    - 课程作业
    - 期末考试
  </Accordion>
</Accordions>
