# Apache Hadoop

Hadoop是一个用于大型数据集分布式存储和处理的开源框架。由Doug Cutting和Mike Cafarella于2005年创建，灵感来自Google的MapReduce和GFS论文。

## Hadoop生态系统概览

```
┌─────────────────────────────────────────────────────────────┐
│                    HADOOP 生态系统                          │
├─────────────────────────────────────────────────────────────┤
│  Pig    │  Hive   │  Sqoop  │  Flume  │  Oozie  │ Zookeeper│
│ (脚本)  │  (SQL)  │ (RDBMS) │ (日志)  │(工作流) │  (协调)  │
├─────────────────────────────────────────────────────────────┤
│                      MapReduce / YARN                       │
│                       (处理框架)                             │
├─────────────────────────────────────────────────────────────┤
│                          HDFS                               │
│                      (分布式存储)                            │
└─────────────────────────────────────────────────────────────┘
```

## 核心组件

### 1. HDFS（Hadoop分布式文件系统）

分布式存储层，设计用于：
- 大文件（GB到TB）
- 流式数据访问
- 商用硬件
- 一次写入、多次读取模式

**架构**：
- **NameNode**：管理文件系统元数据
- **DataNode**：存储实际数据块

### 2. MapReduce

处理框架（在上一节中介绍）：
- 批处理范式
- Map和Reduce阶段
- 自动并行化

### 3. YARN（又一个资源协调器）

资源管理层：
- **ResourceManager**：全局资源调度器
- **NodeManager**：每节点资源管理器
- **ApplicationMaster**：每应用程序协调器

## Hadoop 1.x vs 2.x 架构

### Hadoop 1.x

```
┌─────────────────────────────────┐
│          JobTracker             │  ← 单点故障
│   (作业调度 + 资源管理)          │
├─────────────────────────────────┤
│  TaskTracker  │  TaskTracker    │
│   (Map/Reduce任务)              │
├─────────────────────────────────┤
│             HDFS                │
└─────────────────────────────────┘
```

**问题**：
- JobTracker负载过重（调度 + 监控）
- 可扩展性有限（约4,000节点）
- 仅支持MapReduce

### Hadoop 2.x（使用YARN）

```
┌─────────────────────────────────────────────┐
│              ResourceManager                │
│              (全局调度)                      │
├─────────────────────────────────────────────┤
│ NodeManager  │ NodeManager  │ NodeManager   │
│   Container  │   Container  │   Container   │
├─────────────────────────────────────────────┤
│                   HDFS                      │
└─────────────────────────────────────────────┘

应用程序：MapReduce、Spark、Tez、Storm...
```

**改进**：
- 分离资源管理和作业调度
- 支持多种处理框架
- 更好的可扩展性（约10,000节点）

## Hadoop作业执行过程

### 逐步执行

1. **作业提交**
   - 客户端向ResourceManager提交作业
   - 作业包括：JAR、配置、输入路径

2. **资源分配**
   - ResourceManager为ApplicationMaster分配容器
   - ApplicationMaster为任务请求容器

3. **任务执行**
   - Map任务在有数据的节点上运行（局部性）
   - 中间输出写入本地磁盘
   - Shuffle将数据传输到reducer

4. **输出写入**
   - Reduce任务写入HDFS
   - 向客户端报告作业完成

### 执行时间线

```
时间 →
├── 输入分片 ──→ Map阶段 ──→ Shuffle ──→ Reduce阶段 ──→ 输出
│
│   [分片1] ──→ [Map 1] ──┐
│   [分片2] ──→ [Map 2] ──┼──→ [Shuffle/Sort] ──→ [Reduce 1] ──→ [Part 1]
│   [分片3] ──→ [Map 3] ──┘                   └──→ [Reduce 2] ──→ [Part 2]
```

## 输入和输出

### InputFormat

定义如何读取输入数据：

| 格式 | 描述 |
|------|------|
| TextInputFormat | 逐行文本文件 |
| KeyValueTextInputFormat | Tab分隔的键值 |
| SequenceFileInputFormat | 二进制键值格式 |
| NLineInputFormat | 每个分片N行 |

### OutputFormat

定义如何写入输出：

| 格式 | 描述 |
|------|------|
| TextOutputFormat | Tab分隔文本 |
| SequenceFileOutputFormat | 二进制序列文件 |
| MultipleOutputs | 多个输出文件 |

## 编写Hadoop作业（Java）

```java
public class WordCount {

    public static class TokenizerMapper
            extends Mapper<LongWritable, Text, Text, IntWritable> {

        private final static IntWritable one = new IntWritable(1);
        private Text word = new Text();

        public void map(LongWritable key, Text value, Context context)
                throws IOException, InterruptedException {
            StringTokenizer itr = new StringTokenizer(value.toString());
            while (itr.hasMoreTokens()) {
                word.set(itr.nextToken());
                context.write(word, one);
            }
        }
    }

    public static class IntSumReducer
            extends Reducer<Text, IntWritable, Text, IntWritable> {

        public void reduce(Text key, Iterable<IntWritable> values, Context context)
                throws IOException, InterruptedException {
            int sum = 0;
            for (IntWritable val : values) {
                sum += val.get();
            }
            context.write(key, new IntWritable(sum));
        }
    }

    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "word count");

        job.setJarByClass(WordCount.class);
        job.setMapperClass(TokenizerMapper.class);
        job.setCombinerClass(IntSumReducer.class);
        job.setReducerClass(IntSumReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

## Hadoop Streaming

使用任何语言运行MapReduce：

```bash
hadoop jar hadoop-streaming.jar \
    -input /input/path \
    -output /output/path \
    -mapper mapper.py \
    -reducer reducer.py
```

**Python Mapper**：
```python
#!/usr/bin/env python
import sys
for line in sys.stdin:
    for word in line.strip().split():
        print(f"{word}\t1")
```

**Python Reducer**：
```python
#!/usr/bin/env python
import sys
from collections import defaultdict

counts = defaultdict(int)
for line in sys.stdin:
    word, count = line.strip().split('\t')
    counts[word] += int(count)

for word, count in counts.items():
    print(f"{word}\t{count}")
```

## Hadoop命令

```bash
# HDFS命令
hdfs dfs -ls /path              # 列出文件
hdfs dfs -put local remote      # 上传文件
hdfs dfs -get remote local      # 下载文件
hdfs dfs -cat /path/file        # 查看文件
hdfs dfs -rm -r /path           # 删除

# 运行MapReduce作业
hadoop jar myapp.jar MainClass /input /output

# 检查作业状态
mapred job -list
mapred job -status job_id
```

## 优势与局限

### 优势

| 优势 | 描述 |
|------|------|
| 可扩展性 | 可扩展到数千个节点 |
| 容错性 | 自动从故障中恢复 |
| 成本效益 | 在商用硬件上运行 |
| 灵活性 | 处理任何数据类型 |
| 生态系统 | 丰富的工具和集成 |

### 局限性

| 局限性 | 描述 |
|--------|------|
| 仅批处理 | 高延迟，非实时 |
| 磁盘I/O | 大量磁盘使用减慢处理速度 |
| 复杂性 | 学习曲线陡峭 |
| 以Java为中心 | 其他语言需要Streaming变通 |

<Callout type="info">
Hadoop MapReduce的许多局限性被Apache Spark解决，Spark提供内存处理和更灵活的编程模型。
</Callout>
