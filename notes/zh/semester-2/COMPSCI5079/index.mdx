# COMPSCI 5079: 密码学与安全开发

本课程涵盖密码学和安全软件开发的基础知识，包括对称和非对称加密、哈希函数、数字签名和安全编码实践。

<Accordions>
  <Accordion title="课程基本信息">
    **学习目标:**
    1. 理解基础密码学概念和算法
    2. 实现加密和解密系统
    3. 应用安全编码实践
    4. 分析安全漏洞和威胁
    5. 设计安全的软件系统
  </Accordion>
  <Accordion title="课程结构与考核">
    **课程结构:**
    - 讲座：密码学理论和安全概念
    - 实验：实现练习
    - 作业：实际安全任务

    **考核:**
    - 期中作业
    - 课程作业
    - 期末考试
  </Accordion>
</Accordions>
