# 信息论基础
信息论是密码学的理论基础之一，由克劳德·香农（Claude Shannon）在1948年创立。它提供了度量信息和分析密码系统安全性的数学框架。

## 信息与熵

### 信息量
一个事件的信息量与其发生的概率成反比。概率越小的事件，发生时提供的信息量越大。
**自信息定义**：
对于概率为 $P(x)$ 的事件 $x$，其自信息为：
$$I(x) = -\log_2 P(x) = \log_2 \frac{1}{P(x)}$$
单位为比特（bit）。
<Callout type="info">
直觉理解：抛硬币正面朝上（概率0.5）的信息量是1比特；而骰子掷出6（概率1/6）的信息量约为2.58比特。
</Callout>

### 熵 (Entropy)
熵是信息量的期望值，衡量随机变量的不确定性。
**香农熵定义**：
$$H(X) = -\sum_{x \in X} P(x) \log_2 P(x) = \sum_{x \in X} P(x) \log_2 \frac{1}{P(x)}$$
**性质**：
1. $H(X) \geq 0$（熵非负）
2. 当所有事件等概率时，熵最大
3. 确定性事件的熵为0

### 熵的计算示例
**均匀分布**：对于 $n$ 个等概率事件：
$$H(X) = \log_2 n$$
- 公平硬币：$H = \log_2 2 = 1$ 比特
- 公平骰子：$H = \log_2 6 \approx 2.58$ 比特
- 256个等概率符号：$H = \log_2 256 = 8$ 比特

## 联合熵与条件熵

### 联合熵
两个随机变量 $X$ 和 $Y$ 的联合熵：
$$H(X, Y) = -\sum_{x,y} P(x, y) \log_2 P(x, y)$$

### 条件熵
在已知 $Y$ 的条件下，$X$ 的不确定性：
$$H(X|Y) = -\sum_{x,y} P(x, y) \log_2 P(x|y)$$
**链式法则**：
$$H(X, Y) = H(Y) + H(X|Y) = H(X) + H(Y|X)$$

### 互信息
互信息度量两个随机变量共享的信息量：
$$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$
$$I(X; Y) = H(X) + H(Y) - H(X, Y)$$

## 密码学中的应用

### 密钥熵
密钥的安全强度与其熵直接相关：
| 密钥类型 | 熵 |
|--|
| 128位随机密钥 | 128比特 |
| 8字符小写密码 | ≈37.6比特 |
| 8字符混合密码 | ≈52.4比特 |
<Callout type="warn">
弱密码的熵远低于其长度暗示的安全性。字典攻击利用了实际密码熵低于理论最大值这一事实。
</Callout>

### 唯一解距离
唯一解距离（Unicity Distance）是使密文能够唯一确定明文所需的最小密文长度：
$$U = \frac{H(K)}{D}$$
其中：
- $H(K)$ 是密钥空间的熵
- $D$ 是明文语言的冗余度（每个字符）
**英语的冗余度**约为 1.0-1.5 比特/字符，这意味着英语文本包含大量可预测的结构。

### 完美保密性
**定义**：一个加密系统具有完美保密性，当且仅当密文不泄露关于明文的任何信息：
$$P(M|C) = P(M)$$
或等价地：
$$H(M|C) = H(M)$$
**香农定理**：完美保密性要求：
$$H(K) \geq H(M)$$
即密钥的熵必须至少等于消息的熵。

### 一次性密码本 (One-Time Pad)
一次性密码本是唯一已知的完美保密系统：
**条件**：
1. 密钥与明文等长
2. 密钥完全随机
3. 密钥只使用一次
**加密**：$C = M \oplus K$
**解密**：$M = C \oplus K$
<Callout type="warn">
一次性密码本虽然理论上完美，但实际应用受限于密钥分发和管理的困难。
</Callout>

## 密码分析与信息论

### 冗余度与攻击
自然语言的冗余度使得密码分析成为可能：
- **频率分析**：利用字母频率分布
- **模式识别**：利用常见词汇和语法结构
- **已知明文攻击**：利用已知的明文-密文对

### 混淆与扩散
香农提出了两个设计安全密码的原则：
**混淆 (Confusion)**：
- 使密钥与密文的关系复杂化
- 实现方式：替换操作（S-box）
**扩散 (Diffusion)**：
- 将明文的统计特征分散到密文中
- 实现方式：置换操作（P-box）
现代分组密码（如AES）通过多轮结合混淆和扩散来实现安全性。

## 信息论安全 vs 计算安全
| 特性 | 信息论安全 | 计算安全 |
|||---|
| 熵 | 衡量密钥强度和随机性 |
| 条件熵 | 分析信息泄露 |
| 完美保密性 | 理论安全上界 |
| 冗余度 | 密码分析的基础 |
| 混淆与扩散 | 现代密码设计原则 |
