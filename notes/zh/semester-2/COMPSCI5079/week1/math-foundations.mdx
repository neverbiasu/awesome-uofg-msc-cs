# 数学基础

密码学建立在坚实的数学基础之上。本节介绍密码学中常用的数学概念。

## 模运算 (Modular Arithmetic)

模运算是密码学的核心数学工具。

### 基本定义

对于整数 $a$、$b$ 和正整数 $n$，如果 $n$ 整除 $(a - b)$，则称 $a$ 和 $b$ 关于模 $n$ 同余：

$$a \equiv b \pmod{n}$$

### 模运算性质

1. **加法**：$(a + b) \mod n = ((a \mod n) + (b \mod n)) \mod n$
2. **乘法**：$(a \times b) \mod n = ((a \mod n) \times (b \mod n)) \mod n$
3. **幂运算**：$a^k \mod n = (a \mod n)^k \mod n$

<Callout type="info">
模运算保持加法和乘法的结构，这使得它非常适合密码学应用。
</Callout>

### 模逆元

如果存在整数 $b$ 使得 $a \times b \equiv 1 \pmod{n}$，则称 $b$ 是 $a$ 关于模 $n$ 的逆元。

**条件**：$a$ 关于模 $n$ 有逆元，当且仅当 $\gcd(a, n) = 1$。

### 扩展欧几里得算法

用于计算最大公约数和模逆元：

```python
def extended_gcd(a, b):
    if a == 0:
        return b, 0, 1
    gcd, x1, y1 = extended_gcd(b % a, a)
    x = y1 - (b // a) * x1
    y = x1
    return gcd, x, y
```

## 素数与互素

### 素数

素数是只能被1和自身整除的正整数（大于1）。

**密码学重要性**：
- RSA算法依赖大素数
- 素数用于生成有限域

### 欧拉函数 φ(n)

欧拉函数 $\phi(n)$ 表示小于 $n$ 且与 $n$ 互素的正整数个数。

**计算公式**：
- 如果 $p$ 是素数：$\phi(p) = p - 1$
- 如果 $p$、$q$ 是不同素数：$\phi(pq) = (p-1)(q-1)$

### 欧拉定理

如果 $\gcd(a, n) = 1$，则：

$$a^{\phi(n)} \equiv 1 \pmod{n}$$

**费马小定理**（欧拉定理的特例）：

如果 $p$ 是素数且 $\gcd(a, p) = 1$，则：

$$a^{p-1} \equiv 1 \pmod{p}$$

## 多项式运算

### GF(2) 上的多项式

在密码学中，常在 $GF(2)$（二元有限域）上进行多项式运算。

**特点**：
- 系数只能是 0 或 1
- 加法等同于 XOR 运算
- 没有进位

### 多项式模运算

类似于整数模运算，多项式也可以进行模运算：

$$f(x) \mod g(x)$$

### 不可约多项式

在 $GF(2)$ 上不能分解的多项式称为不可约多项式，类似于素数在整数中的角色。

**AES 使用的不可约多项式**：

$$m(x) = x^8 + x^4 + x^3 + x + 1$$

## 群、环、域

### 群 (Group)

一个集合 $G$ 和运算 $\cdot$ 构成群，需满足：
1. **封闭性**：$a, b \in G \Rightarrow a \cdot b \in G$
2. **结合律**：$(a \cdot b) \cdot c = a \cdot (b \cdot c)$
3. **单位元**：存在 $e$ 使得 $a \cdot e = e \cdot a = a$
4. **逆元**：每个元素都有逆元

### 环 (Ring)

环是具有两个运算（加法和乘法）的代数结构，加法构成交换群，乘法满足结合律和分配律。

### 域 (Field)

域是乘法也构成交换群的环（除零元外）。

<Callout type="info">
有限域（Galois域）在密码学中尤为重要，AES 在 $GF(2^8)$ 上运算。
</Callout>

## 离散对数问题

给定素数 $p$、生成元 $g$ 和 $y = g^x \mod p$，求 $x$ 的问题称为离散对数问题（DLP）。

**重要性**：
- Diffie-Hellman 密钥交换的安全性基于 DLP
- ElGamal 加密基于 DLP
- DSA 签名基于 DLP

## 总结

| 概念 | 应用 |
|------|------|
| 模运算 | 所有密码算法 |
| 欧拉函数 | RSA |
| 多项式运算 | AES |
| 离散对数 | DH、ElGamal、DSA |
| 有限域 | AES、ECC |
