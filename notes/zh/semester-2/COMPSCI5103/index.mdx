# COMPSCI 5103: 深度学习

本课程深入介绍深度学习的理论和实践，涵盖神经网络基础、卷积神经网络、循环神经网络等核心技术，以及使用PyTorch进行模型开发。

<Accordions>
  <Accordion title="课程基本信息">
    **课程目标:**
    1. 理解神经网络的基本原理
    2. 掌握反向传播和梯度下降算法
    3. 学习CNN、RNN等深度学习架构
    4. 使用PyTorch框架实现深度学习模型
    5. 理解正则化、优化等训练技巧
  </Accordion>
  <Accordion title="课程结构与考核">

    - 项目：深度学习应用开发
