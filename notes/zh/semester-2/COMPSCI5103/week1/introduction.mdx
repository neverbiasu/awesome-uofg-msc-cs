# 深度学习导论

深度学习是机器学习的一个子集，使用具有多层的人工神经网络来学习具有多个抽象层次的数据表示。

## 什么是深度学习？

### 定义

深度学习是一类机器学习算法，其特点是：
- 使用多层神经网络
- 学习数据的层次化表示
- 自动从原始数据中发现特征

### 与AI和ML的关系

```
人工智能 (AI)
    └── 机器学习 (ML)
            └── 深度学习 (DL)
```

| 层次 | 描述 |
|------|------|
| AI | 能够执行需要人类智能的任务的系统 |
| ML | 无需显式编程即可从数据中学习的系统 |
| DL | 使用多层深度神经网络的机器学习 |

<Callout type="info">
深度学习通过在图像识别、语音识别和自然语言处理等任务中达到人类水平或更好的性能，彻底改变了人工智能领域。
</Callout>

## 深度学习的历史

### 重要里程碑

| 年份 | 事件 |
|------|------|
| 1943 | McCulloch & Pitts：第一个神经元数学模型 |
| 1958 | Rosenblatt：感知机 |
| 1986 | Rumelhart等：反向传播 |
| 2006 | Hinton：深度信念网络 |
| 2012 | AlexNet赢得ImageNet（深度学习突破） |
| 2014 | Goodfellow提出GAN |
| 2017 | Transformer架构（Attention is All You Need） |
| 2022+ | 大语言模型（GPT、Claude等） |

### AI寒冬与复兴

深度学习经历了兴趣减退的时期（"AI寒冬"），原因包括：
- 计算能力有限
- 训练数据不足
- 梯度消失问题

复兴的推动因素：
- **GPU计算**：大规模并行处理
- **大数据**：用于训练的大型数据集
- **算法进步**：更好的架构和训练技术

## 神经网络基础

### 生物学启发

人工神经网络受到生物神经元的启发：

| 生物学 | 人工 |
|--------|------|
| 树突 | 输入 |
| 细胞体 | 求和 + 激活 |
| 轴突 | 输出 |
| 突触 | 权重 |

### 人工神经元（感知机）

单个神经元的计算：

$$y = f\left(\sum_{i=1}^{n} w_i x_i + b\right) = f(\mathbf{w}^T \mathbf{x} + b)$$

其中：
- $x_i$：输入特征
- $w_i$：权重
- $b$：偏置
- $f$：激活函数
- $y$：输出

### 激活函数

| 函数 | 公式 | 用途 |
|------|------|------|
| Sigmoid | $\sigma(x) = \frac{1}{1+e^{-x}}$ | 二分类（输出层） |
| Tanh | $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 隐藏层（传统） |
| ReLU | $\max(0, x)$ | 隐藏层（最常用） |
| Softmax | $\frac{e^{x_i}}{\sum_j e^{x_j}}$ | 多分类 |

### 多层网络

深度神经网络由以下部分组成：
- **输入层**：接收原始特征
- **隐藏层**：学习表示（"深度"部分）
- **输出层**：产生预测

```
输入 → [隐藏层1] → [隐藏层2] → ... → [隐藏层n] → 输出
```

<Callout type="info">
"深度"一词指的是拥有多个隐藏层。具有2个以上隐藏层的网络通常被认为是"深度"的。
</Callout>

## 为什么深度学习有效

### 通用逼近定理

具有单个隐藏层的神经网络可以逼近任何连续函数，只要有足够多的神经元。

### 层次化特征学习

深度网络在多个层次学习特征：

**示例：图像识别**
- 第1层：边缘、角点
- 第2层：纹理、模式
- 第3层：部件（眼睛、车轮）
- 第4层：对象（人脸、汽车）

### 端到端学习

传统机器学习：
```
原始数据 → [特征工程] → [ML模型] → 预测
```

深度学习：
```
原始数据 → [深度神经网络] → 预测
```

深度学习自动学习特征，消除了手动特征工程。
