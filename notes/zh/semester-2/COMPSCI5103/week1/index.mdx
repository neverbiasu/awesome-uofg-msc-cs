## 关键知识点

### 深度学习概述

- **深度学习定义**：使用多层神经网络从数据中自动学习特征表示的机器学习方法
- **与传统ML的区别**：
  - 传统ML：需要人工特征工程
  - 深度学习：自动学习特征层级

- **深度学习的优势**：
  - 自动特征提取
  - 处理非结构化数据（图像、文本、音频）
  - 在大数据上表现优异

- **深度学习的挑战**：
  - 需要大量数据
  - 计算资源密集
  - 模型可解释性较差

### 神经网络基础

- **生物神经元启发**：
  - 树突（Dendrites）→ 输入
  - 细胞体（Cell Body）→ 处理
  - 轴突（Axon）→ 输出

- **人工神经元（Perceptron）**：
  ```
  输入: x₁, x₂, ..., xₙ
  权重: w₁, w₂, ..., wₙ
  偏置: b
  输出: y = f(∑(wᵢ * xᵢ) + b)
  ```

- **网络结构**：
  - **输入层（Input Layer）**：接收原始数据
  - **隐藏层（Hidden Layers）**：特征提取和转换
  - **输出层（Output Layer）**：产生最终预测

### 激活函数

- **为什么需要激活函数？**
  - 引入非线性
  - 没有激活函数，多层网络等价于单层线性变换

- **常见激活函数**：

  | 函数 | 公式 | 特点 |
  |------|------|------|
  | Sigmoid | σ(x) = 1/(1+e⁻ˣ) | 输出(0,1)，易梯度消失 |
  | Tanh | tanh(x) = (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 输出(-1,1)，零中心 |
  | ReLU | f(x) = max(0, x) | 计算简单，解决梯度消失 |
  | Leaky ReLU | f(x) = max(αx, x) | 解决ReLU死亡问题 |
  | Softmax | exp(xᵢ)/∑exp(xⱼ) | 多分类输出概率 |

### 前向传播

- **过程**：
  1. 输入数据进入输入层
  2. 逐层计算：z = Wx + b，然后 a = f(z)
  3. 最终输出层产生预测

- **矩阵表示**：
  ```
  Z⁽ˡ⁾ = W⁽ˡ⁾A⁽ˡ⁻¹⁾ + b⁽ˡ⁾
  A⁽ˡ⁾ = f(Z⁽ˡ⁾)
  ```

### 损失函数

- **回归任务**：均方误差（MSE）
  ```
  L = (1/n) ∑(yᵢ - ŷᵢ)²
  ```

- **分类任务**：交叉熵（Cross-Entropy）
  ```
  L = -∑ yᵢ log(ŷᵢ)
  ```

## 代码示例

```python
import torch
import torch.nn as nn

# 简单的前向传播示例
class SimpleNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

# 创建模型
model = SimpleNN(input_size=10, hidden_size=64, output_size=2)
```
