## 概要

- **目标**：掌握 Apache Spark 中最常用的基础转换操作（Transformations），理解其工作原理及应用场景。
- **范围**：涵盖 `map`, `filter`, `flatMap`, `mapPartitions`, `sample` 等转换操作，以及 Action 的基本概念和 UDF（用户自定义函数）的使用。

## 学习目标

1. **区分** Transformations 和 Actions 的概念及用途。
2. **掌握** `map` 和 `flatMap` 的区别与用法。
3. **理解** `mapPartitions` 的性能优势及使用场景。
4. **运用** `filter` 进行数据清洗。
5. **了解** 如何在 Java/Scala 中定义和使用 UDF 接口。

## 关键知识点

### 1. Transformations vs Actions

Spark 的操作分为两大类：

- **Transformations (转换)**：
  - **定义**：将一个（或多个）RDD 转换为另一个 RDD 的操作。
  - **特性**：**惰性求值 (Lazy Evaluation)**。调用时不立即执行，只是记录操作记录。
  - **示例**：`map`, `filter`, `flatMap`。
  - **输入/输出**：`RDD1 -> Transformation -> RDD2`。

- **Actions (动作)**：
  - **定义**：触发实际计算的操作，通常返回结果到 Driver 或写入外部存储。
  - **特性**：**立即执行 (Eager Execution)**。
  - **示例**：`collect` (返回 Java List), `count`, `reduce`, `saveAsTextFile`。
  - **输入/输出**：`RDD -> Action -> Result (Object/File)`。

### 2. 常用基础转换 (Basic Transformations)

#### `map(func)`
- **描述**：对源 RDD 的**每个元素**应用函数 `func`，返回一个新的 RDD。
- **函数签名**：`record1 -> record2` (一对一)。
- **应用场景**：数据清洗、格式转换、字段提取。
- **并行性**：不同分区的数据并行处理。

#### `flatMap(func)`
- **描述**：类似 `map`，但每个输入元素可以映射到 **0 个或多个** 输出元素。
- **函数签名**：`record1 -> Iterator<record2>` (一对多)。
- **应用场景**：分词（将一行文本拆分为多个单词）、展平嵌套结构。

#### `filter(func)`
- **描述**：保留使函数 `func` 返回 `true` 的元素，丢弃返回 `false` 的元素。
- **函数签名**：`record1 -> boolean`。
- **应用场景**：数据过滤、异常值剔除。

#### `mapPartitions(func)`
- **描述**：类似 `map`，但函数 `func` 是作用在**每个分区 (Partition)** 的迭代器上，而不是每个元素上。
- **函数签名**：`Iterator<record1> -> Iterator<record2>`。
- **应用场景**：需要高昂初始化成本的操作（如数据库连接）。每个分区只初始化一次连接，而不是每个元素一次。
- **注意**：输入分区必须至少包含一条记录。

#### `mapPartitionsWithIndex(func)`
- **描述**：类似 `mapPartitions`，但函数 `func` 多接收一个分区索引参数。
- **函数签名**：`(index, Iterator<record1>) -> Iterator<record2>`。
- **应用场景**：需要知道数据所在分区的场景，或基于分区号进行特殊处理。

#### `sample(withReplacement, fraction, seed)`
- **描述**：对数据进行随机采样。
- **参数**：
  - `withReplacement`: 是否放回采样。
  - `fraction`: 采样比例。
  - `seed`: 随机数种子。
- **应用场景**：数据探索、近似计算、测试集生成。相当于随机 `filter`。

### 3. 自定义函数 (User-Defined Functions)

Spark (Java/Scala API) 使用特定的接口类来定义转换逻辑：

- **MapFunction**: 用于 `map`。
- **FlatMapFunction**: 用于 `flatMap`。
- **FilterFunction**: 用于 `filter`。

在使用 PySpark 或 Databricks 时，这些操作会被转换为底层的 Spark 函数调用。

## 最佳实践

- **优先使用 mapPartitions**：如果初始化操作（如建立网络连接、解析大对象）开销很大，使用 `mapPartitions` 代替 `map` 可以显著提升性能。
- **慎用 collect**：`collect` Action 会将所有结果拉取到 Driver 内存中。如果数据集很大，会导致 Driver OOM (Out Of Memory)。仅在结果集很小时使用。
- **合理使用 flatMap**：`flatMap` 会产生更多对象，注意内存压力。
